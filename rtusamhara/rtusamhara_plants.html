Ṛtusaṃhāra — 季節集 対訳

読みもの

花でひらくインドの詩

『季節集』の十の植物──詩人たちが植物に託したもの

インドの古典詩を読みはじめると、まず植物の名前の多さに驚きます。マンゴー、アショーカ、カダンバ、ケータキー、キンシュカ……。日本ではなじみのない名前ばかりですが、詩人たちはこうした花の名前を、ただの景色としてではなく、一語で読者の心を動かす「合図」として使っています。桜と聞けば日本人が散りぎわの美しさやはかなさを思い浮かべるように、古代インドの読者は、花の名を聞いただけで季節の空気や恋の気分、ときには神話の一場面まで思い浮かべることができました。

サンスクリット詩論では、こうした約束事を「詩人の決まり（kavisamaya）」と呼びます。また、心を動かす詩の「味わい（rasa）」を生み出す要素の一つに、感情を燃え立たせる外界の事物（uddīpana「点火するもの」）が数えられています。花や月や風は、登場人物の恋心に火をつけ、読者の心にも同じ火を移すための装置なのです。

カーリダーサ作と伝えられる『季節集（Ṛtusaṃhāra）』は、夏から春まで六つの季節を詠った小さな詩集で、こうした植物の「辞書」としてもうってつけです。ここでは、この詩集に登場する植物のなかから十種を選び、詩がそれぞれの植物にどんなイメージを託しているのかをたどってみます。引用した詩句は、本サイトの『季節集』対訳で前後の文脈とともに読むことができます。

1蓮──太陽と月に恋する花

padma, kamala, paṅkaja / utpala / kumuda　ハス・スイレンの仲間

インドの詩でいちばん多く登場する花を一つ挙げるなら、間違いなく蓮です。ただし、サンスクリット語には「蓮」をひとまとめにする言葉はあまり使われず、詩人たちは種類を細かく描き分けます。朝日とともに開く紅や白の蓮（padma、kamala）、青い睡蓮（utpala）、そして月の出とともに開き、夜明けに閉じる白い睡蓮（kumuda）です。

この「昼の花」と「夜の花」の対比が、詩人の想像力をかきたてました。昼の蓮は太陽の恋人、夜の睡蓮は月の恋人。だから太陽が昇れば蓮はほほえみ、月が沈めば睡蓮はしぼみます。『季節集』の秋の歌は、これを恋人と別れた女性の姿に重ねます。

kumudam api gate 'staṃ līyate candrabimbe / hasitam iva vadhūnāṃ proṣiteṣu priyeṣu
白睡蓮もまた、月が沈むとしぼんでしまう──恋人が旅に出てしまった妻たちの微笑みのように。（3.23）

蓮はまた、人の体を描く基本の語彙でもあります。「蓮の顔」「蓮の目」「蓮の手」「蓮の足」──美しい人の体はほとんど蓮でできていると言ってよいほどです。青い睡蓮はとくに黒く澄んだ瞳にたとえられます。

一方で、蓮は泥の中から生まれて泥に染まらない花として、宗教的な象徴にもなりました。『バガヴァッド・ギーター』は、行為の結果に執着しない人を「水に濡れない蓮の葉のように、罪に汚されない」（5.10）と言います。富と美の女神ラクシュミーは蓮の上に座り、創造神ブラフマーはヴィシュヌの臍から伸びた蓮から生まれます。恋の比喩から宇宙の始まりまで、蓮ほど広い世界を背負った花はほかにありません。

2マンゴー──愛神のいちばん鋭い矢

cūta, āmra, sahakāra　マンゴー

日本では果物として知られるマンゴーですが、インドの詩で主役になるのは実よりも、春先に枝いっぱいにつく小さな花の房と、赤い若葉です。マンゴーの花が咲くと、春が来たのだとわかります。

インドの愛の神カーマ（愛神）は、サトウキビの弓に花の矢をつがえて人の心を射る神です。その矢は五本とされ、蓮・アショーカ・マンゴー・ナヴァマッリカー（ジャスミンの一種）・青い睡蓮がそれにあたります。なかでもマンゴーの花は最上の矢とされました。『季節集』の春の歌は、春そのものを、マンゴーの花を矢に、蜂の列を弓弦にした戦士として登場させます（6.1）。

マンゴーの花には、コーキラ（オニカッコウ）という鳥がつきものです。この鳥は春になると高く澄んだ声で鳴き、その声もまた恋心をかきたてるものとされました。コーキラはカラスの巣に卵を産んで育てさせるため、「他者に養われるもの（parabhṛta）」という別名をもっています。インドの詩人はこうした生き物の習性までよく観察していました。

花ざかりのマンゴーをいちばん恐れるのは、家を遠く離れた旅人です。春の歌の終わり近くに、こんな一節があります。

netre nimīlayati roditi yāti śokaṃ / ghrāṇaṃ kareṇa viruṇaddhi virauti coccaiḥ
〔恋人と別れた旅人は、花咲くマンゴーの木を見て〕目を閉じ、泣き、悲しみに沈み、手で鼻をふさぎ、声高く嘆く。（6.26）

目を閉じるのは花を見たくないから、鼻をふさぐのは香りをかぎたくないから。美しい季節ほど、ひとりでいる人には残酷なのです。

3アショーカ──「憂いなし」という名の憂い

aśoka, kaṅkeli　ムユウジュ（無憂樹）

アショーカは春に、幹や根もとから直接、珊瑚のように赤い花の房をつける木です。名前は「憂い（śoka）がない」という意味で、仏教にも縁の深い木として、日本では「無憂樹」とも呼ばれます。

詩人たちは、この名前をそのまま使った言葉遊びが大好きでした。「憂いを払う」はずの木が、恋する人にはかえって憂いをもたらす、というのです。

kurvanty aśokā hṛdayaṃ saśokaṃ / nirīkṣyamāṇā navayauvanānām
アショーカの木々は、見つめる若い女たちの心を「憂いあるもの」にする。（6.16）

アショーカには、もう一つ有名な「詩人の決まり」があります。美しい女性に足で蹴られると花を咲かせる、というものです。カーリダーサの戯曲『マーラヴィカーとアグニミトラ』には、なかなか咲かないアショーカの木に花を咲かせようと、ヒロインがその幹を足で蹴る場面があります。植物が人間の、それも美しい女性の働きかけに応えて花開くという発想には、人と自然の境目がとても薄い世界観が表れています。

『ラーマーヤナ』で、魔王ラーヴァナにさらわれたシーター姫が閉じこめられるのも「アショーカの林」でした。憂いを知らぬはずの林で、最も深く憂える人が暮らす。インドの読者は、その皮肉を名前ひとつで感じ取ったはずです。

4カダンバ──雨にふるえる喜び

kadamba, nīpa　クビナガタマバナノキ

雨季の花の代表がカダンバです。オレンジ色の丸い玉のような花をつけ、その表面には細い花糸がびっしりと立っています。最初の雨が降ると、この花が一斉に咲きます。

インドの詩では、喜びに打ち震えると体じゅうの毛が逆立つ（総毛立つ）とされ、恋人に触れられた喜びの表現として好んで使われます。そして、毛羽立ったようなカダンバの花は、まさにその「総毛立ち」の姿に見立てられました。雨季の歌では、雨に打たれて熱を冷まされた森が、カダンバの花で「喜びにふるえているかのよう」だと詠われます（2.23）。同じ詩節では、風に揺れる枝が「踊り」、白いケータキーの蕾が「笑う」とされ、森全体がひとりの人間のように喜んでいます。

カダンバは女性たちの髪飾りや耳飾りにもなりました（2.20）。また、クリシュナ神の伝説では、ヤムナー河のほとりのカダンバの木がたびたび舞台になります。雨季、恋、そして神の戯れ。カダンバはそれらすべてをつなぐ木です。

5ケータキー──白い笑いと嘘の伝説

ketakī　アダン（タコノキの仲間）

ケータキーは、剣のようにとがった葉をもつ低木で、雨季に白っぽい細長い苞（ほう）に包まれた花をつけます。その香りはきわめて強く、いまでも香料に使われています。

インドの詩では、笑いの色は「白」と決まっています。笑うと白い歯がこぼれるからです。そのため、針のように尖った白いケータキーの蕾は、森の「笑い」に見立てられました。

hasitam iva vidhatte sūcibhiḥ ketakīnām
〔森は〕ケータキーの尖った蕾で、笑っているかのようだ。（2.23）

また、雨季の風はケータキーの花粉を運んで、旅に出た男たちの心を奪います（2.26）。香りはインドの詩で、記憶と恋しさを呼び覚ます力の強い感覚です。

この花には神話もあります。ブラフマー神とヴィシュヌ神が、どちらが偉いかを言い争った物語です。二人は、突然現れた果てしない光の柱（シヴァ神の現れ）の端を見つけようとします。そのときケータキーの花は、ブラフマーが柱の頂上に着いたという嘘の証言をしました。そのためシヴァの怒りを買い、シヴァの礼拝には使われなくなったといいます。美しく香り高い花が、同時に「嘘つきの花」でもある。花のイメージは一つに定まらず、文脈によって表情を変えるのです。

6カーシャ──秋の花嫁の白い衣

kāśa　ワセオバナの類（ススキに似たイネ科の草）

雨季が終わり、雲が晴れると、川辺や野原は一面、カーシャの白い穂で覆われます。日本のススキに似た景色ですが、インドの詩人がそこに見たのは寂しさではなく、華やかな「白」でした。

『季節集』の秋の歌は、秋を新しい花嫁として登場させます。

kāśāṃśukā vikacapadmamanojñavaktrā …
prāptā śarannavavadhūr iva rūparamyā
カーシャの花を衣とし、咲いた蓮を愛らしい顔として……秋が新妻のようにやって来た。（3.1）

カーシャの白い穂は花嫁の衣、蓮は顔、白鳥の声は足輪の音、実りかけて穂を垂れる稲はうつむく体です。秋の歌ではこのあとも、月、白鳥、白い睡蓮、白い花の木と、「白いもの」が次々と並べられます（3.2）。秋は白の季節なのです。

この感覚はいまも生きています。ベンガル地方では、カーシャの白い穂が揺れはじめると、秋の大祭ドゥルガー・プージャーが近いことを人々は知ります。サタジット・レイの映画『大地のうた』で、幼い姉弟が一面のカーシャの原を駆け抜けて汽車を見にゆく場面を覚えている方もいるでしょう。

7キンシュカ──野を焼く炎、香りのない美

kiṃśuka, palāśa　ハナモツヤクノキ（「森の炎」）

春の終わり、葉の落ちた枝いっぱいに、燃えるような朱色の花をつける木があります。英語で「森の炎（flame of the forest）」と呼ばれるキンシュカです。

詩人たちは、この花に二つの姿を見ました。一つは炎です。春の歌では、キンシュカの林に覆われた大地が「赤い衣をまとった新妻」のように輝きます（6.19）。秋の花嫁が白い衣だったのと、ちょうど対になっています。もう一つは、曲がった花の形から連想される「オウムのくちばし」です。kiṃśuka という名前自体、「いくらか（kiṃ）オウム（śuka）に似たもの」と俗に解釈されてきました。

kiṃ kiṃśukaiḥ śukamukhacchavibhir na bhinnam
オウムのくちばしのように赤いキンシュカの花に、〔若者の心は〕すでに裂かれていないというのか。（6.20）

オウムのくちばしは、恋する者の心を「裂く」武器にもなります。ただし、キンシュカには香りがありません。格言集には「容姿と若さに恵まれ、名家に生まれても、学問のない者は輝かない。香りのないキンシュカの花のように」という一句があります。見た目は華やかでも中身がない、というたとえです。

この花は暮らしのなかでも身近でした。春の色かけ祭りホーリーで使う色粉は、もとはこの花から作られたといいます。また、18世紀の「プラッシーの戦い」のプラッシー（パラーシー）という地名は、この木の別名パラーシャに由来すると言われます。

8カルニカーラ──創造主の不公平

karṇikāra　金色の花をつける春の木（同定には諸説あり）

カルニカーラは、春に輝くような黄金色の花をつける木です。名前のなかに「耳（karṇa）」という語を含み、詩のなかでは女性たちが耳飾りにする花として登場します（6.5）。

この花も、キンシュカと同じく香りがありません。カーリダーサは叙事詩『クマーラサンバヴァ（王子の誕生）』で、この欠点にこんな感想を添えています。

prāyeṇa sāmagryavidhau guṇānāṃ / parāṅmukhī viśvasṛjaḥ pravṛttiḥ
色はこれほど見事なのに、香りがないことが、カルニカーラを見る心を痛ませる。思えば世界の創り主は、一つのものにあらゆる美点をそろえて与えることを、たいてい避けるものなのだ。（『クマーラサンバヴァ』3.28）

完全なものはこの世にない、という嘆きです。しかし裏返せば、だからこそ人は欠けたものに心を寄せるのかもしれません。『季節集』では、カルニカーラの黄金色は恋する者の心を「焼く」炎の色でもあります（6.20）。一つの花をめぐって、恋の歌と人生への思索とが隣り合っているのが、インドの詩の面白さです。

9ジャスミン──白い歯、白い微笑み、白い名声

mālatī, kunda, mallikā, yūthikā　ジャスミンの仲間

インドの夜をいちばん香らせる花といえば、ジャスミンの仲間でしょう。詩には何種類ものジャスミンが登場し、季節ごとに咲く種類が違います。雨季から秋にはマーラティー、冬から春にはクンダ、春にはナヴァマッリカーといった具合です。

ジャスミンの役割は、何よりもまず「白」と「髪飾り」です。女性たちは豊かな黒髪を白い花で埋めつくします（3.19）。黒い髪と白い花の対比が、詩人の目をとらえました。

なかでもクンダの花は、白い歯と微笑みにたとえられる定番の花です。春の歌では、女性たちの笑いのように白いクンダの花が庭を照らし、世を捨てた聖者の心さえ奪います。

cittaṃ muner api haranti nivṛttarāgaṃ / prāg eva rāgamalināni manāṃsi yūnām
〔クンダに照り映える庭園は〕執着を離れた聖者の心さえ奪う。まして情に汚れた若者たちの心は言うまでもない。（6.23）

サンスクリット詩の決まりでは、笑いだけでなく、名声も、善い行いも「白い」ものとされます。白いジャスミンは、見た目の美しさだけでなく、明るく清らかなもの全般を呼び出す花でもあるのです。8世紀の劇作家バヴァブーティの恋愛劇『マーラティーとマーダヴァ』のヒロインの名前が、この花の名マーラティーであることも付け加えておきましょう。

10プリヤング──女性の体そのものとしての蔓

priyaṅgu, śyāmā　しなやかな蔓草（同定には諸説あり）

最後は、あまり目立たない植物を取り上げます。プリヤングは「シャーマー」とも呼ばれる蔓草で、詩のなかではしなやかな女性の体、とくに腕にたとえられます。秋の歌では、花の重みにたわむシャーマーの蔓が、飾りをつけた女性たちの腕の美しさを「奪う」とされます（3.18）。

冬の歌で、この蔓は恋人と別れた女性の姿になります。

priye priyaṅguḥ priyaviprayuktā / vipāṇḍutāṃ yāti vilāsinīva
〔冷たい風に揺さぶられ、実りを迎えた〕プリヤングは、愛しい人よ、恋人と引き離された女のように青白くなってゆく。（4.10）

priye priyaṅguḥ priya- と「プリヤ（愛しい）」の音を三度重ねた、耳に心地よい一句です。インドの詩では、恋人と離れた人は青白くやせ細るものとされ、冬に色あせる蔓がその姿に重ねられています。

カーリダーサの『メーガドゥータ（雲の使者）』では、遠く離れた妻を恋しがる主人公が、「シャーマーの蔓のなかにあなたの体を、怯えた鹿の目にあなたの眼差しを見る」と嘆きます。また「詩人の決まり」によれば、プリヤングは美しい女性に触れられると花を咲かせるとされました。アショーカの場合と同じく、植物と女性の体はたがいに映し合い、呼び合う関係にあるのです。

おわりに──植物は心の鏡

十の植物をたどってみると、インドの古典詩に共通する考え方が見えてきます。

まず、自然は人間の心から切り離された「背景」ではありません。花が咲けば恋心が燃え、花が散れば別れの悲しみがつのります。森は喜びにふるえて笑い、季節は花嫁や戦士や王の姿で現れます。人の体は蓮やジャスミンや蔓でできていて、木は女性に蹴られたり触れられたりして花を開きます。人と自然とは、同じ一つの感情の世界に住んでいるのです。

次に、一つの植物には一つの意味だけが割り当てられているわけではありません。アショーカは「憂いなし」でありながら憂いを生み、ケータキーは笑いの花でありながら嘘の花でもあります。キンシュカとカルニカーラは、美しさと欠けたところをあわせもっています。決まった約束事があるからこそ、詩人はそれをずらしたり裏返したりして、新しい驚きを生み出すことができました。

日本の和歌が桜や紅葉に託してきたものと、インドの詩人がマンゴーやアショーカに託したものとは、どこが似ていて、どこが違うのでしょうか。花の名前を手がかりに、ぜひ『季節集』の本文を開いてみてください。二千年近く前の詩人たちが見ていた季節の色と香りが、きっと少し身近に感じられるはずです。

※ 植物の和名・学名との対応には、研究者のあいだで説が分かれるものがあります（とくにカルニカーラ、プリヤングなど）。ここでは代表的な説に従いました。詩句の訳は本サイトの対訳によります（『クマーラサンバヴァ』の一節は本稿のための訳）。
