Uttararāmacarita — Caturtho'ṅkaḥ

Act IV — The Meeting of Kausalyā and Janaka
ウッタララーマチャリタ 第四幕 — カウサリヤーとジャナカの邂逅
Miśra-viṣkambhaka — 混合序幕
(tataḥ praviśatas tāpasau.)
Ekaḥ — Saudhātake dṛśyatām aya bhūyiṣṭha-saṃnidhāpitātithijanasya samadhi-kārambha-ramaṇīyatā bhagavato Vālmīker āśramapadasya.
（二人の修行者が登場する。）
第一の修行者 — サウダータキよ、大勢の客人が集まり、もてなしの準備が格別に美しいヴァールミーキ尊者の僧院の様子をご覧なさい。
【1】 nīvāraudana-maṇḍam uṣṇa-madhuraṃ sadyaḥ-prasūtā-priyā-
pītābhyadhikaṃ tapovana-mṛgaḥ paryāptam ācāmati /
gandhena sphuratā manāg anusṛto bhaktes ya sarpiṣmataḥ
karkhandhū-phala-miśra-śāka-pacanāmodaḥ paristīryate //
【1】 苦行林の鹿は、産まれたばかりの牝鹿が飲んだ残りの、
温かく甘い野生米の粥の上澄みを、満ち足りるまで飲む。
醍醐入りの飯の立ち昇る香りにそっと誘われ、
棗の実を混ぜた野菜煮の薫りが辺り一面に広がる。
Saudhātakiḥ — Svāgatam aneka-prakārāṇāṃ jīrṇa-kūrcānām anadhyāya-kāraṇānām.
サウダータキ — さまざまな白髯の年寄りたちが休日の原因になってくれたことは、まことに歓迎だ。
Prathamaḥ — (vihasya.) Apūrvaḥ ko'pi te bahumāna-hetur guruṣu, Saudhātake.
第一の修行者 — （笑って。） 長老方への敬意に何か珍しい理由があるのだな、サウダータキよ。
Saudhātakiḥ — Bho Dāṇḍāyana, kiṃ-nāmadheya eṣa mahataḥ strī-sārthasya dhuraṃdharo 'dy ātithir āgataḥ.
サウダータキ — ねえダーンダーヤナ、大勢の婦人たちを率いて今日やって来た客人の名は何というのだ。
Dāṇḍāyanaḥ — Dhik prahasanam. Nanv ayam Ṛṣyaśṛṅgāśramād Urundhatī-puraskṛtān Mahārāja-Daśarathasya dārān adhiṣṭhāya bhagavān Vasiṣṭhaḥ prāptaḥ. Tat kim evaṃ pralapasi.
ダーンダーヤナ — 冗談はよせ。これはリシュヤシュリンガの僧院から、アルンダティーを先頭にダシャラタ大王の妃たちを伴って、ヴァシシュタ尊者がお越しになったのだ。何をたわごとを言っているのだ。
Saudhātakiḥ — Huṃ, Vasiṣṭhaḥ.
Dāṇḍāyanaḥ — Atha kim.
Saudhātakiḥ — Mayā punar jñātaṃ vyāghro vṛko vaiṣa iti.
サウダータキ — ふん、ヴァシシュタか。
ダーンダーヤナ — そうだとも。
サウダータキ — 僕はまた虎か狼かと思ったよ。
Dāṇḍāyanaḥ — Āḥ kim uktaṃ bhavati.
Saudhātakiḥ — Yena parāpatiteniva sā vārākī kapilā kalyāṇī maḍamaḍāyitā.
ダーンダーヤナ — 何だと、それは。
サウダータキ — だって来るなり、あの可哀想な茶色の雌牛がむしゃむしゃ食べられてしまったではないか。
Dāṇḍāyanaḥ — "Samāṃso madhuparkaḥ" ity āmnāyaṃ bahumanyamānāḥ śrotriyāyāgatāya vatsatarīṃ mahokṣaṃ vā nirvapanti gṛhamedhinaḥ. Taṃ hi dharmaṃ dharma-sūtra-kārāḥ samāmananti.
Saudhātakiḥ — Bho nigṛhīto'si.
Dāṇḍāyanaḥ — Katham iva.
ダーンダーヤナ — 「マドゥパルカ（蜜の供物）には肉を伴うべし」という聖典の教えを重んじて、来訪した学識ある婆羅門に、家長たちは若牛か大牡牛を供するのだ。法典の著者たちもこの法を説いている。
サウダータキ — おや、やられたな。
ダーンダーヤナ — どういうことだ。
Saudhātakiḥ — Yenāgateṣu Vasiṣṭha-miśreṣu vatsatarī viśasitā. Adyaiva paryagatasya rājarṣer Janakasya bhagavatā Vālmīkinā dadhi-madhubhyām eva nirvartito madhuparkaḥ. Vatsatarī punar visarjitā.
サウダータキ — ヴァシシュタ尊者がお着きの時には若牛が殺されたのに、今日到着した王仙ジャナカに対しては、ヴァールミーキ尊者は乳酪と蜜だけでマドゥパルカを用意し、若牛は放してやったではないか。
Kale注: madhuparka（マドゥパルカ）は蜜を主成分とする歓迎の供物。ヴェーダの教えでは肉を伴うべきとされるが、ジャナカはシーターの悲運を聞いて以来、肉食を断った vaikhānasa（林棲者）となっていたため、ヴァールミーキは乳酪と蜜のみでもてなした。dharmasūtrakāra はアーパスタンバなどの法典著者を指す。
Dāṇḍāyanaḥ — Sa tadaiva devyāḥ Sītāyās tādṛśaṃ daiva-durvipākam upaśrutya vaikhānasaḥ saṃvṛttaḥ. Tathāsya katipaye saṃvatsarāś Candradvīpa-tovane tapas tapyamānasya.
ダーンダーヤナ — あの方はシーター妃のあのような残酷な運命を聞いた時から林棲者となられたのだ。そしてチャンドラドヴィーパの苦行林で修行されて幾年も経つ。
Dāṇḍāyanaḥ — Ciraṃtana-priya-suhṛdaṃ bhagavantaṃ Prācetasaṃ draṣṭum.
ダーンダーヤナ — 古くからの親友であるプラーチェータサ（ヴァールミーキ）尊者を訪ねるためにお越しになったのだ。
Dāṇḍāyanaḥ — Tad ayaṃ brahmavādī purāṇa-rājarṣir Janakaḥ Prācetasa-siddāv upāsya saṃpraty āśramasya bahir vṛkṣa-mūlam adhiṣṭhati.
ダーンダーヤナ — さて、このブラフマンの説法者であり、古の王仙であるジャナカは、プラーチェータサとヴァシシュタに敬意を表してから、今は僧院の外の樹の根元に座っておられる。
【2】 ya eṣa hṛdi nityānuṣaktena sītā-śokena tapyate /
antaḥ-prasūta-dahano jaran iva vanaspatiḥ //
【2】 心に絶えず巣くうシーターへの嘆きに焼かれるこの方は、
内に火を孕んだ老木のようである。
(iti niṣkrāntau.)
Miśra-viṣkambhaḥ.
（二人退場。）
混合序幕おわり。
Janaka praviśati — ジャナカの登場
(tataḥ praviśati Janakaḥ.)
（ジャナカが登場する。）
【3】 apatye yat tādṛg duritam abhavat tena mahatā
viṣaktas tīvreṇa vraṇita-hṛdayena vyathayatā /
paṭu-dhārāvāhī nava iva cireṇāpi hi na me
nikṛntann armāṇi krakaca iva manyur viramati //
【3】 わが子にあのような災禍が降りかかったこと——
その大いなる、激しい、心を抉る苦しみに囚われ、
鋭く流れ落ちて、長き時を経てなお新しきもののように、
急所を断ち切る鋸のごとく、わが悲嘆は止むことがない。
Kale注: krakaca（鋸）の比喩はジャナカの悲嘆の鋭さと持続性を表す。paṭu-dhārāvāhī は「鋭利に、絶え間なく流れるように」の意。manyu は「悲嘆」（śoka）と「怒り」（kopa）の両義を持つ。ジャナカの嘆きが年月を経ても新鮮であり続けることを nava iva（新しきもののように）が強調する。
Janakaḥ — Kaṣṭam. Evaṃ nāma jarayā duḥkhena ca durāsadena bhūyaḥ Parākā-Sāṃtapana-prabhṛtibhis tapobhir uttaraṃ saṃdhātur anavasṭambho nādyāpi mama dagdha-dehaḥ patati.
ジャナカ — 嗚呼、なんという苦しみか。老齢と、耐え難い悲嘆と、さらにパラーカやサーンタパナなどの苦行によって、もはやこの呪われた身体が倒れないのは不思議なことだ。
【4】 aniyata-rudita-smitaṃ virāja-
t-katipaya-komala-danta-kuḍmalāgram /
vadana-kamalaṃ śiśoḥ smarāmi
skhalad-asamañju-jalpitaṃ ca te //
【4】 気まぐれに泣いたり笑ったりしていた、
いくつかの柔らかな歯の蕾が輝く、
幼き日のお前の蓮のような顔を思い出す——
つたないたどたどしい、けれども愛らしいおしゃべりとともに。
【5】 tvaṃ vahnir munayo Vasiṣṭha-gṛhiṇī Gaṅgā ca yasyā vidu-
r māhātmyaṃ yadi vā Raghoḥ kula-gurur devaḥ svayaṃ Bhāskaraḥ /
vidyāṃ vāg iva yām asūta bhavatī tad-vṛttam yā daivataṃ
tasyās tvad-duhitus tathā viśasanaṃ kiṃ dāruṇe 'mṛṣyathāḥ //
【5】 汝も、火神も、聖仙たちも、ヴァシシュタの妻も、ガンガーも知る、
いや、ラグの家の師にして神なる太陽自らも知る、
その偉大さを。学問を弁才天が生んだように汝が生んだ、
神格なるその娘の、かくも残酷な殺害を、なぜ汝は耐え忍んだのか。
Kale注: この偈でジャナカは大地（vasundhare）に呼びかけ、シーターの偉大さを火神・聖仙・アルンダティー・ガンガー・太陽神が皆知っているのに、なぜ彼女の破滅を許したのかと詰問する。vidyāṃ vāg iva yām asūta bhavatī は「弁才天が学問を生んだように、汝（大地）がシーターを生んだ」の意。シーターはヤジュニャの地（devayajana-saṃbhavā）から生まれた。
(nepathye.) Ita itaḥ, bhagavatī-mahādevyau.
Janakaḥ — (dṛṣṭvā.) Aye Gṛṣṭinā upadiśyamāna-mārgā bhagavaty Arundhatī. (utthāya.) Kāṃ punar mahādevīty āha. (nirūpya.) Hā hā, katham iyaṃ Mahārāja-Daśarathasya dharma-dārāḥ priyasakhī me Kausalyā. Ka etāṃ pratyeti saiveyam iti.
（舞台裏から。） こちらへ、こちらへ。尊者と大妃さまがお越しです。
ジャナカ — （見て。） おお、グリシュティに道を案内されたアルンダティー尊者だ。（立ち上がって。） しかし誰を「大妃」と呼んだのか。（よく見て。） ああ、なんとダシャラタ大王の正妃、わが親友カウサリヤーではないか。もはや誰がこの方をかつてのご本人と認めようか。
【6】 āsīd iyaṃ Daśarathasya gṛhe yathā Śrīḥ
Śrīr eva vā kim upamāna-padena saiṣā /
kaṣṭaṃ batānyad iva daiva-vaśena jātā
duḥkhātmakaṃ kim api bhūtam aho vipākaḥ //
【6】 この方はダシャラタの宮殿で吉祥天のようであった——
いや、喩えを用いるまでもなく、吉祥天そのものであった。
嗚呼、運命の力に変じて、まるで別人のように、
悲しみそのもののような存在となった。ああ、運命の結末よ。
【7】 ya eva me janaḥ pūrvam āsīn mūrto mahotsavaḥ /
kṣate kṣāram ivāsahyaṃ jātaṃ tasyaiva darśanam //
【7】 かつて私にとって祝祭そのものの化身であった人の、
まさにその人を見ることが今や、
傷口に塩を塗るように耐え難いものとなった。
(tataḥ praviśaty Arundhatī, Kausalyā, Kañcukī ca.)
Arundhatī — Nanu bravīmi, draṣṭavyaḥ svayam upetyaiva Vaideha ity eṣa vaḥ kula-guroḥ ādeśaḥ. Ata eva cāhaṃ preṣitā. Tat ko'yaṃ pade pade mahān adhyavasāyaḥ.
（アルンダティー、カウサリヤー、門番が登場する。）
アルンダティー — 申し上げているでしょう、自ら出向いてヴァイデーハ（ジャナカ）に会うように、というのが家門の師のお言いつけです。だからこそ私も遣わされたのです。それなのにこの一歩ごとの躊躇はいったいどうしたことですか。
【8】 saṃtāna-vāhinīny api mānuṣāṇāṃ duḥkhāni sad-bandhu-viyoga-jāni /
dṛṣṭe jane preyasi duḥkha-hāni
srotaḥ-sahasrair iva saṃplāvante //
【8】 人の世の悲しみは、愛する親族との別離から生まれ、
絶え間なく流れ続けるものなれど、
愛しき人を目にした時、その悲嘆は堰を切り、
千の流れとなって溢れ出すのだ。
【9】 eṣa vaḥ ślādhya-saṃbandhī Janakānāṃ kulodvahaḥ /
Yājñavalkyo munir yasmai brahma-pārāyaṇaṃ jagau //
【9】 この方こそ、あなた方の誉れ高き親族、ジャナカ家の柱石。
聖仙ヤージュニャヴァルキヤがこの方にブラフマンの至高の教えを説いた。
Kale注: Yājñavalkya はブリハダーラニヤカ・ウパニシャッドにおいてジャナカの師として頻繁に言及される古代の大聖者・哲学者。brahma-pārāyaṇam は「ヴェーダの完全な学習」、ここではウパニシャッドを含むブラフマンの最高知識の意。
【10】 yayā pūtaṃmanyo nidhir api pavitrasya mahasa-
ḥ patis te pūrveṣām api khalu gurūṇāṃ gurutamaḥ /
trilokī-māṅgalyam avanitala-līnena śirasā
jagad-vandyāṃ devīm uṣasam iva vande bhagatīm //
【10】 汝によって浄化されたと自認する、清浄なる光輝の宝庫なるご主人は、
古の師たちの中でもっとも尊い師である。
三界に吉祥をもたらす方よ、地に伏した頭で、
暁の女神（ウシャス）のごとき、世界が崇める尊者に礼拝いたします。
Arundhatī — Paraṃ te jyotiḥ prakāśatām. Ayaṃ tvāṃ punātu devaḥ parorajā ya eṣa tapati.
Janakaḥ — Ārya Gṛṣṭe, apy anāmayam asyāḥ prajā-pālakasya mātuḥ.
アルンダティー — 至高の光が汝に現れんことを。塵を超越した輝く神が汝を浄めんことを。
ジャナカ — （門番に。） 民を守る王の母上は、ご息災でいらっしゃるか。
Kale注: ジャナカの prajā-pālakasya mātuḥ（民を守る者の母の）という問いかけには辛辣な皮肉が含まれる。ラーマは priyā-pālaka（妻を守る者）ではなく prajā-pālaka（民を守る者）に過ぎないという含意である——忠実な妻を見捨てながら臣民の意を重んじたラーマへの非難。
【11】 śiśur vā śiṣyā vā yad asi mama tāt tiṣṭhatu tathā
viśuddher utkārṣas tvayi tu mama bhaktiṃ draḍhayati /
śiśutvaṃ strītvaṃ vā bhavatu nanu vandyāsi jagatāṃ
guṇāḥ pūjā-sthānaṃ guṇiṣu na ca liṅgaṃ na ca vayaḥ //
【11】 お前が私の弟子であれ子であれ、それはさておき——
お前の清浄さの卓越が、私の敬慕を確かなものにする。
子供であれ女であれ、実にお前は世界が敬うべき存在。
徳ある者にあっては、徳こそが崇敬の対象——性別でも年齢でもない。
Kale注: アルンダティーのこの言葉は劇全体の重要な思想的声明。guṇāḥ pūjāsthānaṃ guṇiṣu na ca liṅgaṃ na ca vayaḥ（徳ある者において、徳こそが崇敬の根拠であり、性別でも年齢でもない）は、クマーラサンビャヴァ V.16 の na dharmavṛddheṣu vayaḥ samīkṣyate（法において成熟した者には年齢は問われない）、同 VI.12 の strīpumān ity anāsthā（男か女かは問題ではない）と共通する理念を示す。
【12】 sa rājā tat saukhyaṃ sa ca śiśu-janas te ca divasāḥ
smṛtāv āvirbhūtaṃ tvayi suhṛdi dṛṣṭe tad akhilam /
vipāke ghore 'smin matha khalu vimūḍhā tava sakhī
puraṃdhrīṇāṃ cittaṃ kusuma-sukumāraṃ hi bhavati //
【12】 あの王、あの幸福、あの子供たち、あの日々——
友なる貴方を目にした途端、それらすべてが記憶の中に蘇った。
この恐ろしき運命の結末の中で、貴方の友は気を失ったのです。
貞淑な婦人の心は、まことに花のように繊細なのですから。
【13】 sa saṃbandhī ślāghyaḥ priya-suhṛd asau tac ca hṛdayaṃ
sa cānandaḥ sākṣād api ca nikhilaṃ jīvita-phalam /
śarīraṃ jīvo vā yad adhikam ato 'nyat priyataraṃ
mahārājaḥ śrīmān kim iva mama nāsīd Daśarathaḥ //
【13】 誉れ高き親族であり、愛しき友であり、心そのものであり、
喜びの化身であり、生の果実のすべてであり、
身体であり、魂であり、それ以上に愛しきもの——
栄光のダシャラタ大王は、私にとって何でなかったろうか。
【14】 yad asyāḥ patyur vā rahasi paramaṃ bhūṣitam abhū-
d abhūvaṃ dampatyoḥ pṛthag aham upālambha-viṣayaḥ /
prasāde kope vā tad anu mad-adhīno vidhir abhū-
d alaṃ vā tat smṛtvā dahati yad avaskandya hṛdayam //
【14】 この方か夫のどちらかに密かに深刻な不和があれば、
私は夫婦それぞれから苦情を聞く役目であった。
その後の和解も怒りも、私の裁量に委ねられていた。
しかしもう、それを思い出すのはやめよう——心を踏みにじって焼くのだから。
【15】 suhṛd iva prakaṭayya sukha-pradaṃ prathamam eka-rasām anukūlatām /
punar akāṇḍa-vivartana-dāruṇo vidhir aho viśinaṣṭi mano-rujam //
【15】 運命は最初、友のように心地よい一途な好意を見せておきながら、
やがて突然の裏切りによって残酷なものとなり、
ああ、心の苦痛をいっそう鋭くするのだ。
Kausalyā — (āśvasya.) Hā vatse Jānaki kutrāsi. Smarāmi te nava-vivāha-lakṣmī-parigraha-eka-maṇḍalaṃ prasphurac-chuddha-vihasitaṃ mugdha-mukha-puṇḍarīkam. Āsphurac-candra-candrikā-sundarair aṅgaiḥ punar api me jāte udyotayotsaṅgam.
カウサリヤー — （息を吹き返して。） ああ、ジャーナキよ、どこにいるの。新婚の吉祥にのみ彩られた、清らかな微笑みが輝くお前の無垢な蓮の顔を思い出す。月光のように美しい肢体でもう一度、私の膝を照らしておくれ、わが子よ。
【16】 pañca-prasūter api tasya rājñaḥ priyo viśeṣeṇa Subāhu-śatruḥ /
vadhū-catuṣke 'pi yathaiva Śāntā priyā tanūjāsya tathaiva Sītā //
【16】 五人の子を持つ王にとって、スバーフの敵（ラーマ）が格別に愛しかった。
四人の嫁の中でも、シャーンターが娘として愛されたように、
この方（ジャナカ）にとってシーターもまた同様であった。
Kale注: pañca-prasūti（五人の子）はラーマ・ラクシュマナ・バラタ・シャトルグナの四王子とシャーンター。スバーフ（Subāhu）はヴィシュヴァーミトラの祭祀を妨害した羅刹で、ラーマに討たれた（ラグヴァンシャ XI.29参照）。vadhū-catuṣka は四人の嫁、すなわちシーター・ウールミラー・マーンダヴィー・シュルタキールティ。
【17】 kanyāyāḥ kila pūjayanti pitaro jāmātṛ-jaṃ janaṃ

【28】 yadi te santy evaṃ keyam atha vibhīṣikā /
kim uttair ebhir adhunā tāṃ patākāṃ harāmi vaḥ //
【28】 クシャトリヤがいるのなら、この脅しは何だ。
もうそんな言葉は要らぬ——その旗を奪い取ってやろう。
Lavaḥ — Bho bho baṭavaḥ, parivṛtya loṣṭhair abhighnanto nayatainam aśvam. Eṣa rohitānāṃ madhye vairākaś caratu.
ラヴァ — おい少年たち、馬を取り囲んで土塊を投げながら連れて行け。この哀れな馬を鹿の群れの中で草を食ませてやれ。
Baṭavaḥ — Kumāra kṛtam anenāśvena. Tarjayanti visphutira-śastrāḥ kumāram āyudhīya-śreṇayaḥ. Dūre cāśrama-padam itas tad ehi hariṇa-pluteḥ palāmahe.
Lavaḥ — (vihasya.) Kiṃ nāma visphuranti śastrāṇi. (iti dhanur āropayan.)
少年たち — お友達、馬のことはもういいよ。武器をひらめかせた兵士たちが脅してくる。僧院はここから遠い。さあ、鹿のように跳ねて逃げよう。
ラヴァ — （微笑んで。） 武器がきらめくだと。（弓に弦を張りながら。）
【29】 jyā-jihvayā valayitotkaṭa-koṭi-daṃṣṭra-
m udgāri-ghora-ghana-gharghar-ghoṣam etat /
grāsa-prasakta-hasad-antaka-vaktra-yantra-
jumbhā-viḍambi-vikaṭodaram astu cāpam //
【29】 弦という舌が巻きつき、突き出た先端が牙のごとく、
恐ろしく深く轟くうなりを発するこの弓よ——
獲物を飲み込もうとして口を開く死神の大口を、
その恐ろしい腹の空洞が模すがよい。
Kale注: 張られた弓を死神ヤマの大口に喩える壮大な比喩。jyā（弦）は jihvā（舌）に、弓の先端の koṭi は daṃṣṭra（牙）に、弓と弦の間の空間は antaka-vaktra（死神の口）の vikaṭodara（恐ろしい空洞）に見立てられる。頭韻（ghora-ghana-gharghar-ghoṣa）の連続がヴィーラ・ラサ（勇壮の情趣）を強める。クシェーメーンドラの『アウチティヤヴィチャーラチャルチャー』にも引用される名句。
(iti yathocitaṃ parikramya niṣkrāntāḥ sarve.)
（各自しかるべく歩き回って退場する。）
