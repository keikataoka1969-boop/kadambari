§18 連声（Sandhi）とは p.12

Sandhi（सम्「共に」＋ धा「置く、結ぶ」から）とは、直接に接触する 2 つの文字が融合することをいう。

परः संनिकर्षः संहिता ।「文字の極度の近接が saṃhitā である」Pāṇ. I.4.109
(a)

Saṃhitā すなわち連声は、1 つの語（pada）の内部構造、前置詞（接頭辞）と語根の結合、および複合語（समास）では必須である。一方、文の中、すなわち文中の別々の語の語末と語頭とのあいだでは、書き手の意志に任される。

संहितैकपदे नित्या नित्या धातूपसर्गयोः ।
नित्या समासे वाक्ये तु सा विवक्षामपेक्षते ॥連声の適用についての規則を述べた詩節Sid. Kau.
連声は「語の内部・接頭辞＋語根・複合語」では必須、文中の語と語のあいだでは任意。

I　母音連声 स्वरसन्धिSvarasandhi, or the combination of final and initial vowels（語末と語頭の母音の結合）

§19 同類母音の長音化（सवर्णदीर्घ） pp.12–13

短または長の単母音の後に、同類の（短または長の）母音が続くと、両者に代わってその同類の長母音が置かれる。

अकः सवर्णे दीर्घः ।Pāṇ. VI.1.101
दैत्य + अरिः = दैत्यारिः「ダイティヤ（悪魔）の敵」※ अत्र + आसीत् = अत्रासीत्「ここにいた」 यदा + अभवत् = यदाभवत्「〜であったとき」 विद्या + आतुरः = विद्यातुरः知識を得ようと熱望する（者） कवि + इन्द्रः = कवीन्द्रः詩人の王※ अपि + ईक्षते = अपीक्षते「〜もまた見る」 श्री + ईशः = श्रीशःシュリーの主（ヴィシュヌ） भानु + उदयः = भानूदयः日の出 साधु + ऊचुः = साधूचुः「よし」と彼らは言った चमू + ऊर्जः = चमूर्जः軍の力 कर्तृ + ऋजुः = कर्तॄजुः行為者は正直だ कृ + ऋकारः = कॄकारः होतृ + ऌकारः = होतॄकारः祭官が発音する ऌ 字（長い ऌ はないので、両者に代えて長い ॠ を置く）
(a)

ऋ または ऌ の後に短い ऋ または ऌ が続くときは、両者に代えて短い ऋ／ऌ を置いてもよい（任意）。

ऋति सवर्णे ऋ वा । ऌति सवर्णे ऌ वा ।上記の経に対する Vārttika
同類の母音どうし ➜ 長母音 1 つ（अ+अ＝आ、इ+ई＝ई …）。

§20 Guṇa 化（गुणसन्धि） pp.13–17

अ または आ の後に、短または長の इ, उ, ऋ, ऌ が続くと、後者に対応する Guṇa（§15）が両者の位置を占める。

आद्गुणः ।Pāṇ. VI.1.87
उप + इन्द्रः = उपेन्द्रःウペーンドラ（ヴィシュヌ） परम + ईश्वरः = परमेश्वरः最高の主 रमा + इच्छा = रमेच्छाラマー（ラクシュミー）の願い यथा + ईप्सितम् = यथेप्सितम्望みのままに हित + उपदेशः = हितोपदेशः有益な教え कृष्ण + ऊरुः = कृष्णोरुःクリシュナの腿 गङ्गा + उदकम् = गङ्गोदकम्ガンガーの水 महा + ऊरुः = महोरुः大きな腿（をもつ） कृष्ण + ऋद्धिः = कृष्णर्द्धिःクリシュナの繁栄 महा + ऋषिः = महर्षिः大聖仙 तव + ऌकारः = तवल्कारःあなたが発音する ऌ 字
(a)

子音の後に同類の子音が続くとき（鼻音・半母音・ह を除く）、前者は任意で脱落する。たとえば कृष्ण + ऋद्धिः は一般規則で कृष्णर्द्धिः となり、次にこの規則により कृष्णर् + द् + ध् + इः の द् が落ちて कृष्णर्धिः となる。さらに第 3 の形 कृष्णर्द्द्धिः もある（§22 (d) 参照）。

झरो झरि सवर्णे ।Pāṇ. VIII.4.65
(b)

半母音の後に来る 5 類の子音は任意で重ねられる。したがって तवल्कारः は तवल्क्कारः にもなり、さらに半母音の重複（§22 (c)）と合わせて、全部で 4 形となる。

तवल्कारः基本形
तवल्क्कारःक を重ねる
तवल्ल्कारःल を重ねる
तवल्ल्क्कारः両方を重ねる

※ 4 形の綴りは OCR で崩れていたため、規則から再構成した。

例外：Guṇa ではなく Vṛddhi になる場合

एत्येधत्यूठ्सु ।Pāṇ. VI.1.89この経の前半（एति・एधति）は §21 (a) に対する「例外の例外」となる。
प्रादूहोढोढ्येषैष्येषु । अक्षादूहिन्यामुपसंख्यानम् । स्वादीरेरिणोः । ऋते च तृतीयासमासे । प्रवत्सतरकम्बलवसनार्णदशानामृणे ।上記の経に対する Vārttika
(a)

अ で終わる語の後に ऊह्（वह् の代替形 ऊठ्）が続くとき、および प्र の後に ऊह, ऊढ, ऊढि が続くとき。

प्रष्ठ + ऊहः = प्रष्ठौहः主たる推論（または प्रष्ठवाह्「軛に慣らされた若い雄牛」の対格複数） प्र + ऊहः = प्रौहः主要な推理 प्र + ऊढः = प्रौढः十分に成長した प्र + ऊढिः = प्रौढिः成熟 प्र + ऊढवान् = प्रोढवान्ただしこれは Guṇa（ऊढवान् は経に挙げられていないため）
(b)
अक्ष + ऊहिनी = अक्षौहिणी完全な軍団（न् から ण् への変化は後で説明する）

本来は、戦車 21,870、同数の象、馬 65,610、歩兵 109,350 から成る軍隊をいう。

अक्षौहिण्याः प्रसंख्याता रथानां द्विजसत्तमाः ।
संख्या गणिततत्त्वज्ञैः सहस्राण्येकविंशतिः ॥
शतान्युपरि चैवाष्टौ तथा भूयश्च सप्ततिः ।
गजानां च परीमाणमेतदेव विनिर्दिशेत् ॥
ज्ञेयं शतसहस्रं तु सहस्राणि नवैव तु ।
नराणामपि पञ्चाशच्छतानि त्रीणि चानघाः ॥
पञ्चषष्टिसहस्राणि तथाश्वानां शतानि च ।
दशोत्तराणि षट् प्राहुर्यथावदिह संख्यया ॥Mahābhārata, Ādiparvan 2.23–26
(c)

स्व の後に、いずれも ईर्「行く」から派生した ईर と ईरिन् が続くとき。

स्व + ईरः = स्वैरः勝手気ままにふるまう者、わがままな स्व + ईरिणी = स्वैरिणी（奔放な女）。ほかに स्वैरम्、स्वैरी（स्वेन ईरितुं शीलमस्य「自分の意のままに動くのを常とする者」）
(d)

अ の後に ऋत が続き、具格の Tatpuruṣa 複合語を成すとき。

सुख + ऋतः = सुखार्तः幸福に恵まれた（सुखेन ऋतः） परम + ऋतः = परमर्तःただしこれは Guṇa：「最も尊ぶべき」（परमश्चासौ ऋतश्च、具格 Tat. ではない）
(e)

語 ऋण が प्र, वत्सतर, कम्बल, वसन, ऋण（および दश）の後に来るとき。

प्र + ऋणम् = प्रार्णम्主たる負債 वत्सतर + ऋणम् = वत्सतरार्णम्子牛のための負債 ऋण + ऋणम् = ऋणार्णम्前の借金を返すために作った負債 दश + ऋणः = दशार्णः国名（字義は「10 の砦をもつ国」）。また दशार्णा नदी（10 の川が流れ込む川）
(f)

अ で終わる接頭辞の後に、ऋ で始まる語根が続くとき。ただしその語根が名詞起源動詞（denominative）ならば、Vṛddhi は任意。

उपसर्गादृति धातौ । वा सुप्यापिशलेः ।Pāṇ. VI.1.91–92
उप + ऋच्छति = उपार्च्छति近づく。同様に प्रार्च्छति प्र + ऋषभीयति = प्रर्षभीयति ／ प्रार्षभीयति雄牛のようにふるまう（名詞起源動詞なので任意） उप + ॠकारीयति = उपर्कारीयतिॠ が長いので Vṛddhi にならない प्र + ऌकारीयति = प्रल्कारीयति ／ प्राल्कारीयतिऌ 字を大いに欲する（ऌ は文法上 ऋ と同類とみなされる）
अ/आ ＋ इ・उ・ऋ・ऌ ➜ Guṇa（ए・ओ・अर्・अल्）。ただし प्रौढः・अक्षौहिणी などは Vṛddhi になる例外。

§21 Vṛddhi 化（वृद्धिसन्धि） pp.15–17

अ または आ の後に ए／ऐ が続くと ऐ が、ओ／औ が続くと औ が、それぞれ両者に代わって置かれる。

वृद्धिरेचि ।Pāṇ. VI.1.88
कृष्ण + एकत्वम् = कृष्णैकत्वम्クリシュナとの一体性 देव + ऐश्वर्यम् = देवैश्वर्यम्神の威光 सा + एव = सैव彼女だけが भव + औषधम् = भवौषधम्生と再生（輪廻）に対する薬 विद्या + औत्सुक्यम् = विद्यौत्सुक्यम्知識への渇望

例外

(a)

अ で終わる接頭辞の後に、ए または ओ で始まる語根が続くと、（Vṛddhi ではなく）ए／ओ が置かれる（pararūpa、後音への同化）。ただし語根が名詞起源動詞ならば Vṛddhi は任意。

एङि पररूपम् ।Pāṇ. VI.1.94
प्र + एजते = प्रेजते激しく震える उप + ओषति = उपोषति近くの何かを焼く उप + एडकीयति = उपेडकीयति ／ उपैडकीयति名詞起源動詞なので任意 प्र + ओघीयति = प्रोघीयति ／ प्रौघीयति同上
例外の例外語根 इ「行く」または एध्「増す」の、ए で始まる形が अ の後に来るとき、また第 4・6・9 類の इष् から派生した एष・एष्य が प्र の後に来るときは、Vṛddhi となる（§20 の Vārttika 参照）。
उप + एति = उपैति近づく उप + एधते = उपैधते増す उप + इतः = उपेतःただし語根が इ で始まる形なので Guṇa अव + इहि → अव + आ + इहि = अवेहि「知れ」。अवैहि ではない（एहि は आ + इहि だから） मा भवान् प्र + इदिधत् = प्रेदिधत्Guṇa の例 प्र + एषः = प्रैषः送ること、指図 प्र + एष्यः = प्रैष्यः召使い。ただし ईष् 由来なら प्रेषः, प्रेष्यः
(b)

अ の後に、不定の意味の एव が続くときは、両者に代わって ए が置かれる。

एवे चानियोगे ।Vārttika
क्व + एव = क्वेव भोक्ष्यसे今日はいったいどこで食事をするのか？（場所が確定していない） तव + एव = तवैव（もちろん）あなたの家で食事をします（確定しているので Vṛddhi）
(c)

अ の後に ओम् と आ（接頭辞 आङ्）が続くと、अ が脱落する。

ओमाङोश्च ।Pāṇ. VI.1.95
शिवाय + ओं नमः = शिवायों नमःシヴァに帰命す शिव + एहि（आ + इहि） = शिवेहिシヴァよ、来たれ
(d)

複合語において、語末の अ の後に ओतु「猫」または ओष्ठ「下唇」が続くときは、Vṛddhi は任意。

ओत्वोष्ठयोः समासे वा ।Vārttika
स्थूल + ओतुः = स्थूलोतुः ／ स्थूलौतुः太った猫 बिम्ब + ओष्ठः = बिम्बोष्ठः ／ बिम्बौष्ठःビンバの実のような（赤い）唇（をもつ）
(e)

次の語は、複合語の中で特定の語が後に続くと、語末の母音、または語末の子音とその前の母音が脱落する（शकन्ध्वादि 群）。

शकन्ध्वादिषु पररूपं वाच्यम् ।Vārttika
शक + अन्धुः = शकन्धुःシャカ族の国の井戸 कर्क + अन्धुः = कर्कन्धुः（カルカは国名） कुल + अटा = कुलटा家から家へ渡り歩く女、身持ちの悪い女 सीमन् + अन्तः = सीमन्तः髪の分け目（頭頂の両側に髪を分けてできる白い線）。ただし「境界の最後の線、限界」の意味なら सीमान्तः मनस् + ईषा = मनीषा願い。同様に लाङ्गलीषा「犂の轅」、हलीषा पतत् + अञ्जलिः = पतञ्जलिः『マハーバーシュヤ』（Pāṇini 経への大注釈）の著者の名。字義は「合掌して崇めるにふさわしい者」、伝承では「ある聖仙が Sandhyā 礼拝で太陽に水を捧げたとき、その掌から落ちた者」 सार + अङ्गः = सारङ्गः斑のある皮をもつカモシカ、ある種の鳥。ただし साराङ्गः は「美しい体をもつ者」

これは Ākṛtigaṇa（例示的な語群）である。つまり、同様の形成をもち文法的説明を要するが、実際には群に挙げられていない語も、ここに分類してよい。例：मार्त + अण्डः = मार्तण्डः（मृताण्ड から。字義は「死んだ卵から生まれた者」、太陽）。

原注अत् で終わる擬音語の後に इति が続くときも同様である。例：पटत् + इति = पटिति。ただし 1 音節の語では起こらない（श्रत् + इति = श्रदिति）。語が反復されるときは、त् だけが任意で脱落する：पटत्पटत् + इति = पटत्पटेति または पटत्पटदिति。
अ/आ ＋ ए・ऐ ➜ ऐ、＋ ओ・औ ➜ औ（Vṛddhi）。接頭辞＋語根（प्रेजते）などは例外。

§22 半母音化（यण्सन्धि） pp.17–18

短または長の इ, उ, ऋ, ऌ の後に異類の母音が続くと、それぞれ य्, व्, र्, ल् に置き換えられる。

इको यणचि ।Pāṇ. VI.1.77
इति + आह = इत्याह「〜と彼は言う」 सुधी + उपास्यः = सुध्युपास्यः賢者に崇められる者 मधु + अरिः = मध्वरिःマドゥの敵、すなわちヴィシュヌ धातृ + अंशः = धात्रंशः創造主の部分 ऌ + आकृतिः = लाकृतिःऌ 字のような形
注意上の語のいくつかは、結合すると複数の形をとりうる。以下の規則と §20 の (a)(b) は、本来は次の節（子音連声）に属するが、混乱を避けるためここで扱う。普通の学習者は、本条の (b) 以外は読み飛ばしてよい。
(a)

母音の後にある子音（ह を除く）は、後に母音が続かなければ、任意で重ねられる。

अनचि च ।Pāṇ. VIII.4.47
(b)

鼻音・半母音以外の子音の後に、軟音の無気音または有気音（各類の第 3・第 4 字）が続くと、前の子音はその類の軟音の無気音（第 3 字）に変わる。

झलां जश् झशि ।Pāṇ. VIII.4.53
(c)

5 類の子音（ञ を除く）の後にある半母音は、任意で重ねられる。

यणो मयो द्वे वाच्ये ।Vārttika
(d)

母音の後の र् または ह् に続く子音（ह を除く）は、任意で重ねられる。

अचो रहाभ्यां द्वे ।Pāṇ. VIII.4.46
हरि + अनुभवः = हर्यनुभवः ／ हर्य्यनुभवःハリの体験（一般規則で हर्य् + अनुभवः、ついで本規則で य् を重ねる） न + हि + अस्ति = न ह्यस्ति ／ न ह्य्यस्ति実に無い
इ・उ・ऋ・ऌ ＋ 異類の母音 ➜ य्・व्・र्・ल्（इति+आह＝इत्याह）。

§23 任意の非結合 pp.18–19

(a)

語末の短または長の इ, उ, ऋ, ऌ の後に異類の母音が続くとき、複合語の中でなければ、任意で結合しない。結合しないときは、長母音は短くされる。

इकोऽसवर्णे शाकल्यस्य ह्रस्वश्च ।Pāṇ. VI.1.127
चक्री + अत्र = चक्र्यत्र ／ चक्रि अत्र円盤を持つ者（ヴィシュヌ）がここに वापी + अश्वः = वाप्यश्वः井戸の中の馬（複合語なので必ず結合） गौरी + औ = गौर्यौ（औ は語尾。語末ではないので必ず結合）
(b)

語末の短または長の अ, इ, उ, ऋ の後に短い ऋ が続くときも、任意で結合せず、結合しないときは長母音は短くされる。

ऋत्यकः ।Pāṇ. VI.1.128
ब्रह्मा + ऋषिः = ब्रह्मर्षिः ／ ब्रह्म ऋषिःブラーフマナの聖仙 सप्त + ऋषीणाम् = सप्तर्षीणाम् ／ सप्त ऋषीणाम्七聖仙の（複合語的表現）
語末の इ・उ・ऋ は、複合語でなければ連声しなくてもよい（そのとき長母音は短くなる）。

§24 ए ओ ऐ औ ＋ 母音（अयादिसन्धि） pp.19–20

ए, ओ, ऐ, औ の後に母音が続くと、それぞれ अय्, अव्, आय्, आव् に変わる。

एचोऽयवायावः ।Pāṇ. VI.1.78
हरे + ए = हरयेハリのために विष्णो + ए = विष्णवेヴィシュヌのために नै + अकः = नायकः指導者 पौ + अकः = पावकः浄化するもの、すなわち火
(a)

語末にあり、अ または आ の後にある य्・व् は、母音または軟音の子音が続くとき、任意で脱落する。

लोपः शाकल्यस्य ।Pāṇ. VIII.3.19
हरे + एहि = हरयेहि ／ हर एहिハリよ、来たれ विष्णो + इह = विष्णविह ／ विष्ण इहヴィシュヌよ、ここに श्रियै + उद्यतः = श्रियायुद्यतः ／ श्रिया उद्यतः富を得ようと努める गुरौ + उत्कः = गुरावुत्कः ／ गुरा उत्कः師に会うことを切望する
注間にあった子音や Visarga が消えた結果として隣り合った 2 つの母音は、（さらに）融合しない。上の हर एहि が *हरैहि にならないのはこのためである。
(b)

ओ と औ は、य で始まる接尾辞が続くと、それぞれ अव्・आव् になる。

वान्तो यि प्रत्यये ।Pāṇ. VI.1.79
गो + यम् = गव्यम्牛から生じるもの（乳、ギーなど） नौ + यम् = नाव्यम्舟で行ける、航行可能な
N.B.語根の場合、この規則が当てはまるのは、その ओ／औ が当の接尾辞によって生じたものであるときだけである。
धातोस्तन्निमित्तस्यैव ।Pāṇ. VI.1.80
例：लू + य → लो + यम् = लव्यम्「刈り取られるべき」。अवश्य + लू + य = अवश्यलाव्यम्「必ず刈り取られるべきもの」。
(c)

गो の ओ は、後に यूति が続くときも अव् に変わる。ヴェーダでは常に、通常の言語では特定の長さの単位を意味するときに限る。

गोर्यूतौ छन्दस्युपसंख्यानम् । अध्वपरिमाणे च ।Vārttika
गो + यूतिः = गव्यूतिः（距離の単位）4 マイル
(d)

語根 क्षि と जि の ए（Guṇa）は、可能を表す未来受動分詞（potential participle）の य が続くと अय् になる。

क्षय्यजय्यौ शक्यार्थे ।Pāṇ. VI.1.81
क्षे + य = क्षय्यम्減らすことのできるもの जे + य = जय्यम्征服することのできるもの क्षेयम् पापम्ただし「取り除くべき（が、そうできるとは限らない）罪」＝ क्षेतुं योग्यम् では अय् にならない जेयम् मनः「抑えるべき（が、いつも抑えられるとは限らない）心」
ए・ओ・ऐ・औ ＋ 母音 ➜ अय्・अव्・आय्・आव्。語末の य्・व् は落ちてもよい。

§25 語末の ए ओ ＋ अ p.20

語末の ए または ओ の後に अ が続くと、後者は前者に吸収され、その場所にはときに記号 ऽ（Avagraha、§13 (a)）が書かれる。

एङः पदान्तादति ।Pāṇ. VI.1.109
हरे + अव = हरेऽवハリよ、守りたまえ विष्णो + अव = विष्णोऽवヴィシュヌよ、守りたまえ
(a)

ओ で終わる語 गो の後に अ が続くと、その अ は任意で保持される。また母音が続くとき、ओ の代わりに任意で अव が置かれる。ただし इन्द्र と अक्ष が続くときは、必ず ओ を अव に変える。

सर्वत्र विभाषा गोः । अवङ् स्फोटायनस्य । इन्द्रे च ।Pāṇ. VI.1.122–124
語末の ए・ओ ＋ अ ➜ अ が消えて ऽ（हरेऽव）。

§26 連声が起こらない場合 pp.20–22

次の場合には連声は起こらない。

प्लुतप्रगृह्या अचि नित्यम् ।「Pluta と Pragṛhya は母音の前で常に（そのまま）」Pāṇ. VI.1.125

I　いわゆる Pragṛhya（प्रगृह्य）の例外

(a)

両数形（名詞・代名詞・動詞のいずれでも）が ई, ऊ, ए で終わるとき。

ईदूदेद्द्विवचनं प्रगृह्यम् ।Pāṇ. I.1.11
हरी एतौこの 2 人のハリ विष्णू इमौこの 2 人のヴィシュヌ गङ्गे अमूあの 2 つのガンガー पचेते इमौこの 2 人は料理する
(b)

代名詞 अदस् の म् の後に ई または ऊ が来るとき。

अदसो मात् ।Pāṇ. I.1.12
अमी ईशाःあの主たち अमू आसातेあの 2 人は座っている
Ob.ヴェーダの形 अस्मे と युष्मे の ए も、後続の母音と融合しない（शे । Pāṇ. I.1.13）。例：अस्मे इन्द्राबृहस्पती (Ṛg. IV.49.4)。同様に、処格の意味をもつ（が処格語尾で終わらない）ヴェーダの語も、後続の母音の影響を受けない。例：सोमो गौरी अधि श्रितः (Ṛg. IX.12.3)。ここで गौरी は गौर्याम् の意であり、処格語尾が सुपां सुलुक् (Pāṇ. VII.1.39) によって脱落したものである。
(c)

単一の母音から成る小辞（不変化詞）。ただし「少し」または「限界」（排他的・包括的のいずれでも）の意味の आ、および接頭辞として用いられる आ は除く。

निपात एकाजनाङ् ।Pāṇ. I.1.14
इ इन्द्रおお、インドラよ उ उमेशおお、ウマーの主よ आ एवं मन्यसेああ、君はそう考えるのか आ + उष्णम् = ओष्णम्ただし「少し温かい」の आ は連声する
(d)

不変化詞が ओ で終わるとき。また、呼格の名詞の語末の ओ は、後に（ヴェーダ以外の）इति が続くとき、任意で結合する。

ओत् । सम्बुद्धौ शाकल्यस्येतावनार्षे ।Pāṇ. I.1.15–16
अहो ईशाःああ、主たちよ विष्णो + इति = विष्णविति ／ विष्णो इति ／ विष्ण इति最後のものは §24 (a)
N.B.以上の、他と融合しない母音、ときにはそれを含む語そのものが、術語として प्रगृह्य（Pragṛhya）と呼ばれる。

II　Pluta（延長）母音

एहि कृष्ण३ अत्र गौश्चरति来なさい、クリシュナよ。ここで牛が草を食んでいる

母音は次の場合に Pluta となる。

वाक्यस्य टेः प्लुत उदात्तः । प्रत्यभिवादेऽशूद्रे ।Pāṇ. VIII.2.82–83Vārttika：स्त्रियां न । भोराजन्यविशां वेति वाच्यम् ।
(1)

Śūdra 以外の男性からの挨拶に答えて言う文の最後の母音。ただし、その人の名前または家名が実際に言及される場合に限る。

अभिवादये देवदत्तोऽहम्「私デーヴァダッタがご挨拶申し上げます」 आयुष्मान् एधि देवदत्त३「長生きせよ、デーヴァダッタよ」（上の挨拶への返答） भो आयुष्मती भव गार्गि最後の इ は Pluta にならない（女性の名だから） आयुष्मान् एधिこれも Pluta にならない（名前がないから）

ただし文が語 भोः、または Kṣatriya・Vaiśya の名で終わるときは、最後の母音は任意で Pluta になる。

आयुष्मान् एधि भोः ／ भो३ः आयुष्मानेधीन्द्रवर्मन् ／ इन्द्रवर्म३न्（Kṣatriya の名） आयुष्मानेधीन्द्रपालित ／ इन्द्रपालित३（Vaiśya の名）
(2)

遠くの人に呼びかける文の最後の母音。またそのような文で用いられる小辞 हे と है の母音。

दूराद्धूते च । हैहेप्रयोगे हैहयोः ।Pāṇ. VIII.2.84–85
सक्तून् पिब देवदत्त३麦こがしを飲め、デーヴァダッタよ！ हे३ राम ／ राम है३おーい、ラーマ！
両数の ई・ऊ・ए など（Pragṛhya）と Pluta 母音は連声しない。

§27 小辞 उ p.22

小辞 उ は、前に 5 類の子音（ञ を除く）があり、後に母音が続くとき、任意で व् に変わる。

मय उञो वो वा ।Pāṇ. VIII.3.33
किम् + उ + उक्तम् = किम्वुक्तम् ／ किमु उक्तम्何が言われたのか（後者は §26 (c) により結合しない）
小辞 उ は、子音の後・母音の前で व् にしてもよい（किम्वुक्तम्）。

II　子音連声 हल्सन्धिHalsandhi, or the coalescence of final consonants with vowels and consonants（語末の子音と母音・子音との融合）

§28 歯音の口蓋音化・反舌音化 pp.22–23

स् または歯音類の子音が、次のものと接すると変化する。

(a)

श् または口蓋音類の子音と接するとき：歯音はそれに対応する口蓋音に、स् は श् に置き換えられる。

स्तोः श्चुना श्चुः ।「स と तु（歯音類）は、श と चु（口蓋音類）と接すると श と चु になる」Pāṇ. VIII.4.40
हरिस् + शेते = हरिश्शेतेハリは横たわる रामस् + चिनोति = रामश्चिनोतिラーマは集める सत् + चित् = सच्चित्実在と知 शार्ङ्गिन् + जय = शार्ङ्गिञ्जय勝利したまえ、クリシュナよ（シャールンガ弓を持つ者よ）

例外 (1)：श् の後に来る歯音は、対応する口蓋音に変わらない。

शात् ।Pāṇ. VIII.4.44
विश् + नः = विश्नः光輝を広げるもの प्रश् + नः = प्रश्नः問い
(b)

ष् または反舌音類の子音と接するとき：स् は ष् に、歯音はそれに対応する反舌音に置き換えられる。

ष्टुना ष्टुः ।Pāṇ. VIII.4.41
रामस् + षष्ठः = रामष्षष्ठः6 番目のラーマ रामस् + टीकते = रामष्टीकतेラーマは行く तत् + टीका = तट्टीकाそれの注釈 चक्रिन् + ढौकसे = चक्रिण्ढौकसेクリシュナよ、汝は赴く पेष् + ता = पेष्टा挽く者※

例外 (1)：語末にある反舌音類の子音の後に स् または歯音類の子音が来るとき、その स् と歯音は変化しない。ただし नाम्（属格複数語尾）・नवति・नगरी の न् は除く（これらは反舌音化する）。

न पदान्ताट्टोरनाम् ।Pāṇ. VIII.4.42Vārttika：अनाम्नवतिनगरीणामिति वाच्यम् ।
षट् + सन्तः = षट्सन्तः6 人の善人（§39 も参照） षट् + ते = षट्ते彼ら 6 人 ईड् + ते = ईट्टे彼は讃える（ड् が語末ではないので反舌音化する） षट् + नवतिः = षण्णवतिः96 षट् + नगर्यः = षण्णगर्यः6 つの町 सर्पिष् + तमम् = सर्पिष्टमम्最上のギー（例外は反舌音類 टु についてで、ष् は含まないから）
歯音（स त थ द ध न）は、口蓋音と接すれば口蓋音に、反舌音と接すれば反舌音に変わる（同じ列で上下に移るだけ）。

§29 歯音類 ＋ ष् p.23

歯音類の子音の後に ष् が来ても、対応する反舌音には変わらない。

तोः षि ।Pāṇ. VIII.4.43
सन् + षष्ठः = सन्षष्ठः6 番目の善人
§28 (b) の例外：त・न などは後の ष् に引かれない。

§30 鼻音の前の子音 p.23

語末にある子音（ह् と र् を除く）の後に鼻音が来ると、その子音の代わりに、同じ類の鼻音を任意で置くことができる。

यरोऽनुनासिकेऽनुनासिको वा ।Pāṇ. VIII.4.45
एतद् + मुरारिः = एतन्मुरारिः ／ एतद्मुरारिःこのムラーリ（クリシュナ）（後者は §22 (b) による） षट् + मासाः = षण्मासाः ／ षड्मासाः6 か月
N.B.鼻音が接尾辞（語尾）に属する場合は、この変化は必須である。
तद् + मात्रम् = तन्मात्रम्それだけ चित् + मात्रम् = चिन्मात्रम्純粋な知のみ वाक् + मय = वाङ्मय言葉から成る
語 ककुद्मत्（Raghuvaṃśa IV.22 参照）は不規則に作られた形である。
語末の子音 ＋ 鼻音 ➜ 同類の鼻音にしてもよい（接尾辞の鼻音の前では必ず）。

§31 歯音類 ＋ ल् pp.23–24

歯音類の子音の後に ल् が来ると、その子音は ल् に変わる。न् の場合は、鼻音化した ल्ँ がその位置を占める（§16）。

तोर्लि ।Pāṇ. VIII.4.60
तत् + लयः = तल्लयःそれの消滅 विद्वान् + लिखति = विद्वाँल्लिखति学者が書く
त् ＋ ल ➜ ल्ल、न् ＋ ल ➜ ँल्ल（鼻音化した ल）。

§32 उद् ＋ स्था・स्तम्भ् p.24

接頭辞 उद् の後では、स्था と स्तम्भ् の स् が थ् に変わる。

उदः स्थास्तम्भोः पूर्वस्य ।Pāṇ. VIII.4.61
उद् の後の स्था・स्तम्भ् は、स् が消えたような形（उत्थानम्）になる。

§33 閉鎖音 ＋ ह् p.24

各類の最初の 4 字（閉鎖音）の後に来る ह् は、任意でその類の軟音の有気音（第 4 字）に変わる。

झयो होऽन्यतरस्याम् ।Pāṇ. VIII.4.62
वाक् + हरिः = वाग्हरिः ／ वाग्घरिः言葉の主（वाचां हरिः）、ブリハスパティ。まず §22 (b) で वाग्、ついでこの規則で ह् → घ्
क्・त् など ＋ ह ➜ ग्घ・द्ध（ह が前の類の第 4 字になる）。

§34 硬音の前・休止の前 p.24

鼻音・半母音以外の子音は、硬音の子音が続くとその類の第 1 字に変わり、何も続かない（休止の）ときは第 1 字または第 3 字に変わる。

खरि च । वाऽवसाने ।Pāṇ. VIII.4.55–56
वाच् → वाक् ／ वाग्「言葉」の主格単数（休止の前） तद् + पठति = तत्पठति（補例）硬音 प の前で第 1 字
硬音の前 ➜ 第 1 字（無声無気）、文末 ➜ 第 1 字か第 3 字。

§35 閉鎖音 ＋ श् p.24

各類の最初の 4 字のどれかで終わる語の後に श् が来て、さらにその後に母音・半母音・鼻音・ह् が続くとき、श् は任意で छ् に変わる。

शश्छोऽटि ।Pāṇ. VIII.4.63
閉鎖音 ＋ श（＋母音など）➜ च्छ にしてもよい：तच्छिवः。

§36 語末の म् → Anusvāra pp.24–25

語末の म् は、子音が続くと Anusvāra に変わる。

मोऽनुस्वारः ।Pāṇ. VIII.3.23
हरिम् + वन्दे = हरिं वन्देハリに礼拝する गम् + यते = गम्यतेただしこれは変わらない（म् が語末ではないから）

語 सम्राट् は例外である（Pāṇ. VIII.3.25 参照）。

(a)

語末にない न् と म् は、鼻音・半母音・ह् 以外の子音が続くと Anusvāra に変わる。

नश्चापदान्तस्य झलि ।Pāṇ. VIII.3.24
आक्रम् + स्यते = आक्रंस्यते彼は打ち勝つであろう यशान् + सि = यशांसियशस्「名声」の主格複数 मन्यते彼は考える（न् の後が半母音 य なので変わらない） ग्रामान् + गच्छति = ग्रामान्गच्छतिन् が語（文法形）の末尾にあるので変わらない
(b)

後に ह्म が続く म् では、この変化は任意である。ह्न が続くときは न् を、ह्य・ह्व・ह्ल が続くときは鼻音化した य्ँ・व्ँ・ल्ँ を、म् の代わりに任意で置くことができる。

हे मपरे वा । यवलपरे यवला वा ।Pāṇ. VIII.3.26 ほか
किम् + ह्मलयति = किंह्मलयति ／ किम्ह्मलयति何を揺らすのか किम् + ह्नुते = किंह्नुते ／ किन्ह्नुते何を隠すのか किम् + ह्यः = किंह्यः ／ किय्ँह्यःなに、昨日だと！ किम् + ह्वलयति = किंह्वलयति ／ किव्ँह्वलयति किम् + ह्लादयति = किंह्लादयति ／ किल्ँह्लादयति अहम् + आगतः = अहमागतः私は来た（母音の前では変わらない）
語末の म् ＋ 子音 ➜ ं（Anusvāra）。母音の前ではそのまま。

§37 Anusvāra → 後続音と同類の鼻音 p.25

Anusvāra の後に श्・ष्・स्・ह् 以外の子音が続くと、その子音の属する類の鼻音に変わる。語の内部では必ず、語末では任意である。

अनुस्वारस्य ययि परसवर्णः । वा पदान्तस्य ।Pāṇ. VIII.4.58–59
अन्क् + इतः → अंक् + इतः = अङ्कितः印を付けられた（§36 (a) で Anusvāra、ついで本則） अन्च् + इतः = अञ्चितः崇められた कुण्ठितः・शान्तः・गुम्फितः妨げられた・静められた・編まれた त्वम् + करोषि = त्वं करोषि ／ त्वङ्करोषि汝はなす（語末なので任意） संयन्ता ／ सय्ँयन्ता制御する者 संवत्सरः ／ सव्ँवत्सरः年 यं लोकम् ／ यल्ँलोकम्どの世界へ
ं ＋ 閉鎖音 ➜ その類の鼻音（語中は必須、語末は任意）。

§38 ङ्・ण् ＋ 歯擦音 pp.25–26

語末の ङ् と ण् の後に歯擦音が続くと、それぞれ क् と ट् を任意で添える。また、硬音の無気音は、歯擦音の前では任意で硬音の有気音に変わる。

ङ्णोः कुक्टुक् शरि ।Pāṇ. VIII.3.28Vārttika：चयो द्वितीयाः शरि पौष्करसादेरिति वाच्यम् ।
प्राङ् + षष्ठः = प्राङ्षष्ठः ／ प्राङ्क्षष्ठः ／ प्राङ्ख्षष्ठः前に行った 6 番目の人 सुगण् + षष्ठः = सुगण्षष्ठः ／ सुगण्ट्षष्ठः ／ सुगण्ठ्षष्ठः6 番目の優れた計算者
ङ्・ण् ＋ 歯擦音 ➜ ङ्क्・ण्ट्（さらに ङ्ख्・ण्ठ्）を挟んでもよい。

§39 ड्・न् ＋ स्、および鼻音の重複 p.26

語末の ड्（ट् に変わる）または न् の後に स् が続くと、両者の間に त् を任意で挿入する。

डः सि धुट् । नश्च ।Pāṇ. VIII.3.29–30
षड् + सन्तः = षट्सन्तः ／ षट्त्सन्तः6 人の善人 सन् + सः = सन्सः ／ सन्त्सःその善き人
(a)

語末にあり短母音の後にある ङ्・ण्・न् は、母音が続くと重ねられる。

ङमो ह्रस्वादचि ङमुण्नित्यम् ।Pāṇ. VIII.3.32
प्रत्यङ् + आत्मा = प्रत्यङ्ङात्मा個我 सुगण् + ईशः = सुगण्णीशः最良の計算者 सन् + अच्युतः = सन्नच्युतः善きアチュタ（ヴィシュヌ）
短母音 ＋ ङ्・ण्・न् ＋ 母音 ➜ ङ्ङ・ण्ण・न्न（必ず重ねる）。

§40 न् ＋ श् p.26

語末の न् の後に श् が続くと、両者の間に त् を任意で挿入する。

शि तुक् ।Pāṇ. VIII.3.31
न् ＋ श ➜ ञ्श・ञ्च्श・ञ्च्छ・ञ्छ の 4 通り。

§41 न् の反舌音化（णत्व） p.26

同じ語の中で र्・ष्・ऋ（短・長）の後に来る न् は ण् に変わる。両者の間に、母音、ल् 以外の半母音、ह्、喉音類・唇音類の子音、接頭辞 आ、Anusvāra（नुम्）が入っていても変わる。

रषाभ्यां नो णः समानपदे । अट्कुप्वाङ्नुम्व्यवायेऽपि ।Pāṇ. VIII.4.1–2
राम + एन = रामेणラーマによって（र と न の間に आ・म・ए が入っても変わる） पूष् + ना = पूष्णा太陽によって पितृ + नाम् = पितॄणाम्父たちの राम + नाम = राम नामラーマという名（2 つの別の語なので変わらない）

この変化は、न् が語末にあるときは起こらない：रामान्。

पदान्तस्य ।Pāṇ. VIII.4.37
र・ष・ऋ の後の न は、間に「邪魔な音」がなければ ण になる（रामेण）。語末の न は変わらない。

§42 स् の反舌音化（षत्व） p.27

代替音（आदेश）または接尾辞（प्रत्यय）に属し、文法形の末尾にない स् は、अ・आ 以外の母音、半母音、喉音類の子音、ह् の後で ष् に変わる。

अपदान्तस्य मूर्धन्यः । इण्कोः । आदेशप्रत्यययोः ।Pāṇ. VIII.3.55, 57, 59
रामे + सु = रामेषुラーマたちにおいて राम + स्य = रामस्यただし変わらない（स् の前が अ） सुपीः・सुपिसौ変わらない（स् が語 सुपिस् 自体に属し、代替音でも接尾辞でもない）

間に Anusvāra（न् の代わり）・Visarga・歯擦音が入っていても、この変化は起こる。

नुम्विसर्जनीयशर्व्यवायेऽपि ।Pāṇ. VIII.3.58
धनुन्स् + इ = धनूंषि弓（中性 धनुस्）の主格複数（Anusvāra が間に入る） पिपठीः + सु = पिपठीष्षु ／ पिपठीःषु読もうと欲する者たちにおいて（Visarga が間に入る）※
इ・उ・ए などの後の（語尾の）स ➜ ष（रामेषु）。अ・आ の後では स のまま（रामस्य）。

§43 सम्・पुम्・कान् と स् の挿入 pp.27–28

सम् の म् は、語根 कृ の（स् の付いた）形が続くと Anusvāra と Visarga に変わり、その Anusvāra はさらに任意で Anunāsika に変わる。सम्・पुम्・कान् の語末には स् が付加される。

संपुंकानां सो वक्तव्यः ।Vārttika
सम् + कर्ता = संस्कर्ता ／ सँस्कर्ता整える者 संस्स्कर्ता ／ सँस्स्कर्ता（स् を重ねた形）
N.B.संस्कर्ता という語は、いくつもの経が適用されるため 108 通りの形をとりうる。しかし煩瑣で実質的な価値もないので、ここには挙げない。以下の (a)–(d) は初学者は飛ばしてよい。
(a)

पुम् の म् は、歯擦音以外の硬音の子音が続き、さらにその後に母音・半母音・鼻音・ह् が来るとき、任意で鼻音化され、上と同様に स् が付く。

पुमः खय्यम्परे ।Pāṇ. VIII.3.6Vārttika：ख्याञादेशे न ।
पुम् + कोकिलः = पुंस्कोकिलः ／ पुँस्कोकिलः雄のコーキラ鳥 पुंस्पुत्रः ／ पुँस्पुत्रः成人した息子 पुंक्षीरम्・पुंदासः男のための乳・男の召使い（条件に合わないので स् は付かない） पुंख्यानम्男の勘定（例外：ख्या の代替形の前では付かない）
(b)

語末の न्（प्रशान् を除く）は、च्・छ्・ट्・ठ्・त्・थ् が続き、さらにその後に母音・半母音・鼻音・ह् が来るとき、同じ変化を受ける。

नश्छव्यप्रशान् ।Pāṇ. VIII.3.7
शार्ङ्गिन् + छिन्धि = शार्ङ्गिंश्छिन्धि ／ शार्ङ्गिँश्छिन्धिクリシュナよ、断ち切れ（स् は §28 (a) で श्） चक्रिन् + त्रायस्व = चक्रिंस्त्रायस्व ／ चक्रिँस्त्रायस्वクリシュナよ、守りたまえ हन्तिただし変わらない（न् が語末ではない） सन्त्सरुः立派な剣の柄（त् の後が स） प्रशान् तनोति静かな人が広げる（प्रशान् は除外）
(c)

नॄन् の न् は、प् が続くとき任意でこの変化を受ける。

नॄन् पे ।Pāṇ. VIII.3.10
नॄन् + पाहि = नॄंः पाहि ／ नॄँः पाहि ／ नॄन् पाहि人々を守れ※
(d)

反復された कान् の न् も、कान् が続くとき任意でこの変化を受ける。

कानाम्रेडिते ।Pāṇ. VIII.3.12
कान् + कान् = कांस्कान् ／ काँस्कान्誰々を？

また、次の語群を結合するときには、Visarga に代えて स्（または ष्）が置かれる（कस्कादि 群）。

कस्कादिषु च ।Pāṇ. VIII.3.48
कः + कः = कस्कः誰と誰 कौतस्कुतःどこから来た（者） भ्रातुष्पुत्रः兄弟の息子 सद्यस्कालः現在 सर्पिष्कुण्डिकाギーの壺 धनुष्कपालम्弓の端 यजुष्पात्रम्祭祀の器 अयस्कान्तः磁石 तमस्काण्डः・अयस्काण्डः深い闇・鉄の矢 भास्करः・अहस्करः太陽
सम्＋कृ ➜ संस्कृ。पुम्・न्（＋硬音）では स् が割り込む（पुंस्कोकिलः、चक्रिंस्त्रायस्व）。

§44 छ् の前の च् の挿入 p.28

छ् とその前の短母音または長母音との間には、च् が必ず挿入される。ただし語末の長母音（小辞 मा と接頭辞 आ を除く）が前にある場合は任意である。

छे च । आङ्माङोश्च । दीर्घात् । पदान्ताद्वा ।Pāṇ. VI.1.73–76本来は त्（तुक्）が挿入され、§28 によって च् に変わる。
शिव + छाया = शिवच्छायाシヴァの影。同様に स्वच्छाया चेच्छिद्यते何度も切られる（語内なので必須） लक्ष्मी + छाया = लक्ष्मीछाया ／ लक्ष्मीच्छाया語末の長母音なので任意 मा + छिदत् = माच्छिदत्切るなかれ（मा の後は必須） आ + छादयति = आच्छादयति覆う（接頭辞 आ の後は必須）
母音 ＋ छ ➜ च्छ（語末の長母音の後だけは任意）。

III　Visarga 連声 विसर्गसन्धिVisargasandhi（Visarga の融合）

§45 Visarga の成立 pp.28–29

語末の स् と सजुष् の ष् は र्（रु）に変わり、その後に硬音の子音が続くか、何も続かないときは、Visarga に変わる。

ससजुषो रुः । खरवसानयोर्विसर्जनीयः ।Pāṇ. VIII.2.66; VIII.3.15
रामस् + पठति = रामः पठतिラーマは読む पितर् → पितः父よ（呼格。語末の र् も休止の前で Visarga） भ्रातुस् + कन्यका = भ्रातुः कन्यका兄弟の娘
Visarga ＝ 語末の स・र が硬音の前や文末で弱まったもの。

§46 Visarga ＋ 硬音 pp.29–31

Visarga の後に च्・छ्・ट्・ठ्・त्・थ् が続き、それ自体の後に歯擦音が来ないとき、Visarga は स् に変わる（さらに §28 により श्・ष् になる）。श्・ष्・स् が続くときは任意である。

विसर्जनीयस्य सः । शर्परे विसर्जनीयः । वा शरि ।Pāṇ. VIII.3.34–36
विष्णुः + त्राता = विष्णुस्त्राता守護者ヴィシュヌ हरिः + चरति = हरिश्चरतिハリは歩く रामः + टीकते = रामष्टीकतेラーマは行く（§28 参照） कः + त्सरुः = कः त्सरुःどの柄か（त् の後に歯擦音 स् が来るので変わらない） रामः + स्थाता = रामः स्थाता ／ रामस्स्थाता立つであろうラーマ हरिः + शेते = हरिः शेते ／ हरिश्शेतेハリは横たわる
(a)

不変化詞に属さない Visarga は、接尾辞 पाश・कल्प・क・काम्य が続くとき、अ の後では स् に、इ・उ（短・長）の後では ष् に変わる。

सोऽपदादौ । इणः षः ।Pāṇ. VIII.3.38–39Vārttika：पाशकल्पककाम्येष्विति वाच्यम् । अनव्ययस्येति वाच्यम् । काम्ये रोरेवेति वाच्यम् ।
पयस्पाशम्質の悪い乳 यशस्कल्पम्名声にもう少しのもの यशस्कम्名声を伴う यशस्काम्यति名声を欲する प्रातःकल्पम्ほとんど夜明け（प्रातः は不変化詞なので変わらない） सर्पिष्पाशम्・सर्पिष्कल्पम्・सर्पिष्कम्・सर्पिष्काम्यति質の悪いギー ほか（इ の後なので ष्） गीः काम्यति言葉が欲する（र् に由来する Visarga は काम्य の前で変わらない）
(b)

नमः と पुरः の Visarga は、不変化詞として क्・ख् または प्・फ् で始まる動詞の前に置かれるとき、स् に変わる。前者では任意、後者では必須である。

नमस्पुरसोर्गत्योः ।Pāṇ. VIII.3.40原注：नमः は साक्षात्प्रभृति 群に含まれるので、gati の資格は任意である。
नमस्करोति ／ नमः करोति礼拝する पुरस्करोति前に置く पुरः प्रवेष्टव्याः入るべき町々（पुरः は名詞「町」なので変わらない）
(c)

इ・उ の後にあり、接尾辞に属さない Visarga は、喉音類・唇音類の硬音が続くと ष् に変わる（मुहुः の場合を除く）。

इदुदुपधस्य चाप्रत्ययस्य ।Pāṇ. VIII.3.41
निः + प्रत्यूहम् = निष्प्रत्यूहम्妨げなく आविष्कृतम्あらわにされた दुष्कृतम्悪行 मुहुः कृतम्何度もなされた（मुहुः は除外） अग्निः करोति火がなす（Visarga が語尾に属するので変わらない）。同様に मातुः कृपा（मातुष्कृपा ではない） भ्रातुष्पुत्रः例外（§43 (d) の कस्कादि 群）
(d)

तिरस् は、क्・ख्・प्・फ् が続くとき任意で स् を保つ。頻度を表す副詞 द्विः・त्रिः・चतुः も、同じ条件で任意に Visarga を ष् に変える。

तिरसोऽन्यतरस्याम् । द्विस्त्रिश्चतुरिति कृत्वोऽर्थे ।Pāṇ. VIII.3.42–43
तिरस्करोति ／ तिरः करोति隠す、侮る द्विष्करोति ／ द्विः करोति2 度行う चतुष्कपालम्4 つの部分をもつ（चतुः は副詞ではない。(e) の複合語の規則による）
(e)

語末の इः・उः（इस्・उस्）は、文意の完成に後続語が必要なとき（意味上の結びつきがあるとき）、同じ条件で任意に Visarga を ष् に変える。複合語の前分の末尾にあるときは必ず変える。

इसुसोः सामर्थ्ये । नित्यं समासेऽनुत्तरपदस्थस्य ।Pāṇ. VIII.3.44–45
सर्पिष्करोति ／ सर्पिः करोतिギーにする धनुष्करोति ／ धनुः करोति弓を作る तिष्ठतु सर्पिः पिब त्वमुदकम्ギーは置いておけ、君は水を飲め（सर्पिः と पिब に意味上の結びつきがないので変わらない） सर्पिष्कुण्डिकाギーの壺（複合語なので必須） परमसर्पिःकुण्डिका大きなギー壺（सर्पिः が後分 उत्तरपद にあるので変わらない）
(f)

不変化詞でない語の अ の後にあり、複合語の前分を成す Visarga は、語根 कृ・कम् の派生語、および कंस・कुम्भ・पात्र・कुशा・कर्णी が続くと स् に変わる。

अतः कृकमिकंसकुम्भपात्रकुशाकर्णीष्वनव्ययस्य ।Pāṇ. VIII.3.46
अयस्कारः鍛冶屋 अयस्कामः鉄を欲する者 अयस्कंसम्・अयस्कुम्भः・अयस्पात्रम्鉄の鉢・鉄の甕・鉄の器 अयस्कुशा手綱 अयस्कर्णी一種の鉄の壺 गीःकारःブリハスパティ（अ の後ではない） स्वःकामः天界を欲する者（स्वर् は不変化詞） यशः करोति名声をなす（複合語ではない） परमयशःकारः大きな名声をもたらす者（यशस् が複合語の前分ではない）
(g)

अधः と शिरः は、上と同じ条件で पद が続くと Visarga を स् に変える。

अधःशिरसी पदे ।Pāṇ. VIII.3.47
अधस्पदम्・शिरस्पदम्足の下・頭の位置 अधः पदम्複合語でないとき परमशिरःपदम्शिरः が後分にあるとき
Visarga ＋ च・ट・त ➜ श्・ष्・स्（हरिश्चरति）。क・प の前では原則そのままだが、(a)–(g) の特定の語では स्・ष् になる。

§47 -अः ＋ अ・軟音 → -ओ p.31

短い अ の後にある（स् に由来し、र् に由来しない）Visarga は、短い अ または軟音の子音が続くと उ に変わる（そして अ + उ = ओ）。

अतो रोरप्लुतादप्लुते । हशि च ।Pāṇ. VI.1.113–114
शिवः + अर्च्यः = शिवोऽर्च्यःシヴァは崇められるべきである देवः + वन्द्यः = देवो वन्द्यः神は礼拝されるべきである तिष्ठतु पय अ३ग्निदत्त乳は置いておけ、アグニダッタよ！（後の अ が Pluta なので変わらず、§48 で脱落） प्रातः + अत्र = प्रातरत्रここで朝に（Visarga が र् に由来するので ओ にならない）。同様に प्रातर्गच्छ
-अः ＋ अ ➜ -ओऽ、-अः ＋ 軟音 ➜ -ओ（देवो वन्द्यः）。ただし प्रातः・पुनः など र् 由来なら -अर्。

§48 -आः・-अः の Visarga の脱落 p.31

आ の後の Visarga は、軟音の子音が続くと必ず脱落し、母音が続くと任意で脱落する。また अ の後の Visarga も、अ 以外の母音が続くと任意で脱落する。どちらの場合も、脱落しないときは य् に変わる。

भोभगोअघोअपूर्वस्य योऽशि । लोपः शाकल्यस्य । हलि सर्वेषाम् ।Pāṇ. VIII.3.17, 19, 22
देवाः + नम्याः = देवा नम्याः神々は礼拝されるべきである（軟音の前で必ず脱落） देवाः + इह = देवा इह ／ देवायिह神々はここに（母音の前で任意） रामः + आगच्छति = राम आगच्छति ／ रामयागच्छतिラーマが来る（अ の後、अ 以外の母音の前。補例）
注脱落の後に残った母音どうしは、さらに連声しない（§24 (a) の注を参照）。राम आगच्छति が *रामागच्छति にならないのはこのためである。
-आः ＋ 軟音・母音 ➜ -आ（देवा नम्याः）。-अः ＋ अ 以外の母音 ➜ -अ（राम आगच्छति）。

§49 अ・आ 以外の後の Visarga → र् pp.31–32

(a)

अ・आ 以外の母音の後にあり、母音または軟音の子音が続く Visarga は र् に変わる。

हरिः + जयति = हरिर्जयतिハリは勝つ भानुः + उदेति = भानुरुदेति太陽が昇る गौः + आगच्छति = गौरागच्छति牛が来る

例外：小辞 भोः・भगोः・अघोः の Visarga は §48 に従う。

भोः + अच्युत = भो अच्युत ／ भोयच्युतおお、アチュタよ भगो नमस्ते尊き方よ、汝に礼拝を अघो याहिおい、行け
(b)

अहन् の न् は、格語尾が続かないときは常に र्（→ Visarga）に変わる。ただし पति および गिर्・धुर् などの語が続くときは任意であり、रूप・रात्रि・रथन्तर が続くときは Visarga（→ §47 で ओ）が置かれる。

रोऽसुपि ।Pāṇ. VIII.2.69Vārttika：अहरादीनां पत्यादिषु वा रेफः । रूपरात्रिरथन्तरेषु रुत्वं वाच्यम् ।
अहः・अहरहः日・日ごとに अहःपतिः ／ अहर्पतिः日の主、太陽 गीःपतिः ／ गीर्पतिःブリハスパティ धूःपतिः ／ धूर्पतिः指導者 अहोभ्याम्具格両数（格語尾の前なので本則ではない） अहोरूपम्・गतमहो रात्रिरेषा昼の姿・昼は過ぎた、これは夜だ अहोरात्रः・अहोरथन्तरम्昼夜・昼に詠唱されるサーマン
(c)

र् の後に र्、ढ् の後に ढ् が続くと前者は脱落し、その前の अ・इ・उ が短ければ長くなる。

रो रि । ढ्रलोपे पूर्वस्य दीर्घोऽणः ।Pāṇ. VIII.3.14; VI.3.111
पुनर् + रमते = पुना रमते再び楽しむ हरिः + रम्यः → हरिर् + रम्यः = हरी रम्यःハリは魅力的である वृढ् + ढः = वृढःवृह्「成長する」の過去受動分詞（ऋ は長くならない）
-इः・-उः・-औः など ＋ 母音・軟音 ➜ -इर् 等（हरिर्जयति）。र् ＋ र ➜ 前の र が落ちて母音が長くなる（हरी रम्यः）。

§50 सः・एषः の Visarga p.32

(a)

तद् と एतद् の男性主格単数の स्（Visarga）は、子音の前で脱落する。ただし क を伴う形（एषकः など）であるときと、否定の Tatpuruṣa で用いられるときは除く。

एतत्तदोः सुलोपोऽकोरनञ्समासे हलि ।Pāṇ. VI.1.132
स शम्भुःそのシャンブ एष विष्णुःこのヴィシュヌ एषको रुद्रःこのルドラ（क を伴う形） असः शिवःシヴァでない者（否定の Tatpuruṣa） एषोऽत्र彼はここに（母音の前なので §47 による）
(b)

詩では、韻律の都合上、सः と एषः の स् が अ 以外の母音の前で無いものとみなされ、2 つの母音が融合することがある。

सोऽचि लोपे चेत्पादपूरणम् ।Pāṇ. VI.1.134
स + इमाम् = सेमाम्…सेमामविड्ढि प्रभृतिं य ईशिषे（Ṛg. II.24.1） स + एषः = सैष彼こそは
सैष दाशरथी रामः सैष राजा युधिष्ठिरः ।
सैष कर्णो महात्यागी सैष भीमो महाबलः ॥「彼こそはダシャラタの子ラーマ、彼こそはユディシュティラ王、彼こそは大いなる施主カルナ、彼こそは大力のビーマ」例詩
सः・एषः ＋ 子音 ➜ स・एष（स शम्भुः）。母音 अ の前では सोऽ・एषोऽ。
