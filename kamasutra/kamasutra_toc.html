ヴァーツヤーヤナ・カーマスートラ 対訳

Vātsyāyanakāmasūtram — サンスクリット原典・和訳・ジャヤマンガラー注抄

サンスクリット語（IAST 表記）原文と和訳の対訳。各章末にヤショーダラ作『ジャヤマンガラー』注釈からの重要事項を付記。底本は GRETIL 校訂テキストおよびチャウカンバー版（1929年、ダーモーダラ・シャーストリー編）。

7篇 adhikaraṇa
36章 adhyāya
64節 prakaraṇa
≈1250偈 sūtra/śloka
カーマスートラの構成
作者：Vātsyāyana Mallanāga（ヴァーツヤーヤナ・マッラナーガ）、紀元3〜4世紀頃。
注釈者：Yaśodhara（ヤショーダラ）、13世紀頃。注釈名『Jayamaṅgalā』（ジャヤマンガラー）。
伝承：Nandī（シヴァの従者）→ Śvetaketu Auddālaki → Bābhravya Pāñcāla（150章に拡大）→ 各篇が専門家により独立著作化 → Vātsyāyana が再統合・簡潔化。
三目的の教説（trivarga）：dharma（法）・artha（利）・kāma（愛）の調和ある追求が本書の根本理念。カーマの学問的考察であり、欲望の追求ではない。
第一篇
総論 Sādhāraṇam
1.1
論書の概要 Śāstra-saṃgrahaḥ
節1–4
カーマ学の起源と伝承系譜。シヴァ神の従者ナンディンからバーブラヴィヤを経てヴァーツヤーヤナに至る学統。全書の構成（7篇・36章・64節）の提示。dharma・artha・kāma 三目的の定義と優先順位。
1.2
学問の列挙 Vidyā-samuddeśaḥ
節5
教養人が習得すべき六十四芸（catuḥṣaṣṭi-kalā）の一覧。歌・舞・楽器・絵画・料理・建築・占星術・言語学・呪術まで。芸事に通じた女性の社会的地位。gaṇikā（高級遊女）の教育体系。
1.3
都会人の生活 Nāgaraka-vṛttam
節6–7
洗練された都会人（nāgaraka）の理想的な一日の過ごし方。住居の構造と内装。沐浴・食事・音楽鑑賞・文芸サロン。季節ごとの遊興と祭事。viṭa（洒落者）・vidūṣaka（道化）・piṭhamarda（仲介者）の役割。
1.4
相手の仲間と交わるべき女性 Nāyaka-sahāya-duṣṭā-strī-prakaraṇam
節8–9
男性の友人・仲間（sahāya）の四種。使者（dūtī）の類型と役割。交わるべき女性・避けるべき女性の分類。再婚女性（punarbhū）に関する規定。
1.5
男女の性格の判定 Strī-puruṣa-śīlāvasthāpanam
節10–11
女性の四種の愛情。女性が欲情を示す外的徴候。男性が試みるべきアプローチの段階。女性が拒絶する理由の分類。離反の原因。
第二篇
交合論 Sāṃprayogikam
2.1
寸法・種類・時間による分類 Sāṃprayogika-prakaraṇam
節12–17
男女の性器の三段階分類（śaśa/vṛṣabha/aśva、mṛgī/vadavā/hastinī）と九種の組み合わせ。情欲の強度による三分類。交合の持続時間の三分類。各分類の組み合わせから生じる二十七種の結合型。
2.2
抱擁法 Āliṅgana-prakaraṇam
節18
抱擁の八種類——接触型四種（spṛṣṭaka, viddhaka, udghṛṣṭaka, pīḍitaka）と密着型四種（latāveṣṭitaka, vṛkṣādhirūḍhaka, tilataṇḍulaka, kṣīranīraka）。身体各部位による抱擁。
2.3
接吻法 Cumbana-prakaraṇam
節19
接吻の部位と方法の分類。三種の基本接吻（nimittaka, sphuritaka, ghaṭṭitaka）。接吻の遊戯と賭け。口内接吻の諸形態。各地方の特色ある接吻法。
2.4
爪痕法 Nakha-daśana-prakaraṇam
節20
爪による愛痕の八種類——ācchuritaka（圧痕）、ardhacandra（半月形）、maṇḍala（円形）等。爪の手入れと理想的な形状。爪痕を残すべき時機と場所。地方による差異。
2.5
噛み痕法 Daśana-ccheda-prakaraṇam
節21
噛み痕の種類——guṇa（隠れた痕）、ucchūnaka（腫脹痕）、bindu（点痕）、bindu-mālā（点列痕）等。噛むべき部位。珊瑚と宝石の装飾品のような痕の美学。
2.6
交合の体位 Rata-prakaraṇam
節22–25
体位の基本分類——仰臥位の諸型（uttāna, vijṛmbhitaka, indraṇika 等）。寸法差を補う体位の工夫。立位・四つ這い・側臥位。各地方の習俗。動きの種類（upasṛpta）八種。
2.7
打擲法と叫喚法 Prahaṇana-sītkṛta-prakaraṇam
節26–27
交合時の打擲（prahaṇana）の四種——平手打ち・拳・楔形・掌底。適切な部位。情熱の叫び（sītkṛta）の種類。南方・西方の激しい習俗。ヴァーツヤーヤナによる暴力の戒め。
2.8
女性上位法 Puruṣāyita-prakaraṇam
節28–29
女性が上位となる場合の理論的根拠。女性上位の諸体位——saṃpuṭaka、pārśvasaṃpuṭaka、preṅkholita（揺籃式）等。女性の疲労回復のための男性による女性上位の模倣。
2.9
口による行為 Aupariṣṭaka-prakaraṇam
節30
口による行為（aupariṣṭaka）の八段階。第三の性（tṛtīyā-prakṛti）——男性型と女性型。samaya-virodha（規範との矛盾）に関する議論。各地方（サーケータ、ストラーシュトラ等）の習俗。
2.10
交合の開始と終了・愛の種類 Ratāvasānam / Rata-viśeṣa
節31
交合の前戯と後戯。終了後の振る舞い。月光の下での語らい。愛の四種類——習慣の愛（abhyāsikā）、想像の愛（ābhimānikā）、信仰の愛（saṃprayogajā）、自然の愛（svābhāvikā）。交合における口論の遊び（rata-kalaha）。
第三篇
処女論 Kanyā-saṃprayuktakam
3.1
求婚と婚姻の形式 Varaṇa-saṃvidhāna / Saṃbandha-niścaya
節32–33
花嫁選びの条件と吉凶の判断。同等の身分（tulya）との婚姻の原則。占星術的考慮。婚姻の八形式のうちの推奨される四形式。友人・親族・仲介者による交渉法。
3.2
処女の信頼獲得 Kanyā-visrambhaṇa / Saṃvanana
節34–35
婚姻後の最初の三夜間の行動規範。処女の心理的段階に応じた段階的アプローチ。信頼構築のための遊戯と贈物。花輪・香料による接近法。
3.3
少女への接近法 Bālā-upakramaṇam
節36–37
幼い花嫁との段階的親密化。子供の遊び・花摘み・人形遊びを通じた接近。少女の心理的な準備段階。家族の目を避けた秘密の接触法。少女の情緒的徴候の観察。
3.4
一人の求愛者の努力 Ekapuruṣābhiyogāḥ
節38–40
父親の仲介なしに一人で娘を追求する方法。出会いの場の作り方。幼馴染・乳母・侍女・友人を通じた接近法。少女の態度から好意を読み取る方法。成功の徴候と最終的な結合法。
3.5
婚姻の形式 Vivāha-yogāḥ
節41
婚姻の各形式の詳説——ブラーフマ婚・ガーンダルヴァ婚・ラークシャサ婚等。駆け落ち婚の手続き。夜間の侵入による秘密婚。各婚姻形式の法的・宗教的地位。シャクンタラーの物語への言及。
第四篇
人妻論 Bhāryādhikarikam
4.1
貞節なる妻の行い Ekacāriṇī-vṛttam / Pravāsa-caryā
節42–43
一人の夫に仕える妻（ekacāriṇī）の理想的な振る舞い。家政の管理——庭園・家畜・財務。夫の旅行中の行動規範。宗教的義務と誓願。夫の帰還時の迎え方。
4.2
年長妻・年少妻・再婚妻・後宮の妻 Jyeṣṭhā / Kaniṣṭhā / Punarbhū / Antaḥpurikā
節44–49
年長の妻と年少の妻の振る舞い。再婚女性（punarbhū）の処世法。寵愛を失った妻の対策。後宮（antaḥpura）の女性たちの生活。複数の妻を持つ夫の行動指針。
第五篇
他人の妻 Pāradārikam
5.1
性格の判定と交際すべき女性 Strī-puruṣa-śīlāvasthāpanam
節50–51
他人の妻への接近が許される場合についての dharma 的議論。ヴァーツヤーヤナの留保。成功しやすい女性の特徴。近づきやすい女性の分類。親しくなるきっかけの作り方。
5.2
接近の方法 Abhiyogāḥ
節52–54
段階的接近法の詳細。身振り・視線・暗示による意思疎通。侍女を通じた接近。秘密の合図と暗号。贈物の種類と方法。
5.3
心情の観察 Bhāva-parīkṣā
節55
相手の女性の心情（bhāva）を観察・判定する方法。好意の微細な徴候の読み取り方。態度の変化から推測される心理。接近の成否の判断基準。
5.4
使者の役割 Dūtī-karmāṇi
節56
使者（dūtī）の種類——双方を知る使者・片方のみの使者・自ら使者となる女性・風を使者とする方法・無言の使者。使者の選定基準と資質。伝言の技法。使者の報酬。
5.5
王の愛欲と後宮の女性 Īśvara-kāmitam
節57
王（īśvara）の特権と責任。後宮の女性への接近法。kāma-upadhā（欲望の試練）による臣下の忠誠検証。王の臣民の妻への接近の是非。歴史上の暴君の事例。
5.6
後宮の秘密 Antaḥpurikāvṛttam
節58
後宮の守護体制。女性たちが外部の男性と接触する方法。後宮内の秘密の伝達法。門番の買収。変装による侵入。他国の後宮の風習。後宮の女性たちの孤独と欲求不満。
第六篇
遊女論 Vaiśikam
6.1
客の選定と交際の理由 Veśyā-gamana / Gamana-kāraṇa
節49–50
遊女（veśyā）が客を選ぶ基準。客と交わる十六の理由——愛情・恐怖・金銭・快楽・敵意・好奇心等。好ましい客・避けるべき客の分類。遊女の仲介者（piṭhamarda, viṭa, vidūṣaka）の役割。
6.2
客との同棲 Kānta-anuvṛttam
節51
遊女が客と妻のように暮らす方法。信頼獲得のための行動——食事・入浴・就寝の共有。嫉妬の演出。相手の好みへの適応。金銭面の処世。客を「夫」のように扱う技法。
6.3
金銭の獲得と客の追い出し Artha-āgama / Vivāha-bheda
節52–53
遊女が客から金銭を引き出すための策略。債務の回収法。不要になった客の追い出し方の段階的方法。客を怒らせて自ら去らせる技法。金銭詐取の巧妙な手口。
6.4
去った客との復縁 Viśīrṇa-pratisandhānam
節54
別れた客を呼び戻す方法。復縁の動機の分析——金銭・愛情・復讐・将来の利益。遊女の母や仲間による仲介法。復縁を避けるべき場合。再結合のための心理的戦略。
6.5
利益の種類と特殊な利益 Lābha-viśeṣa
節55–56
利益（lābha）の体系的分類——金銭的利益・付随的利益・疑惑的利益。二人の客の間での選択基準。利益の大小を計る方法。将来の利益と現在の利益の比較衡量。特殊状況での判断法。
6.6
利益と不利益の考察・遊女の種類 Arthānarthānubandha-saṃśaya-vicāra / Veśyā-viśeṣa
節57–58
利益に随伴する不利益（anartha）の十の原因。利益と不利益の六種の結合型。純粋な疑惑（śuddha-saṃśaya）と混合的疑惑（saṃkīrṇa-saṃśaya）の分析。遊女の九種の分類——kumbhadāsī（壺女奴隷）から rūpajīvā（容姿で生きる者）まで。
第七篇
秘術篇 Aupaniṣadikam
7.1
魅力増進法・呪縛法・精力増強法 Subhagaṃkaraṇa / Vaśīkaraṇa / Vṛṣya-yoga
節59–61
通常の方法では目的を達しえない場合の秘術（upaniṣad）。魅力を高める薬草・塗香・点眼薬。呪縛法——dhattūra・manaḥśilā 等による秘薬。三種の神秘的塗香（devakānta, gandharvakānta, nāgakānta）。遊女の娘の婚姻法。精力増強の食餌療法と薬方。倫理的制約——疑わしきもの・有害なもの・殺生に関わるもの・不浄物の禁止。
7.2
情熱回復法・増大法・種々の秘方と結語 Naṣṭa-rāga-pratyānayana / Vardhana-yoga / Citra-yoga
節62–64
衰えた情欲の回復法——手技・口技・補助器具（apadravya）。補助器具の種類と素材。南方の穿孔法（vyadhana-yoga）の詳細。男根の物理的増大法。種々の雑方——独占の秘薬・情欲消失剤・染毛法・透明化の術・幻術。結語八偈——ヴァーツヤーヤナの宣言：「この書は梵行と集中によって著された。世間の営みのためであり、欲望の追求が目的ではない。」
