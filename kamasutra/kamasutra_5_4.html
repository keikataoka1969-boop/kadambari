第五篇 第四章 仲介女の仕事（Dūtī-karma）

Pañcamam Adhikaraṇam — Caturtho 'dhyāyaḥ ｜ 第46節（Prakaraṇa 46）
Kāmasūtra 5.4.1–5.4.66

仲介女の派遣と働きかけ（5.4.1–5.4.9）

5.4.1
darśiteṅgitākāraṃ tu pravirala-darśanām a:pūrvāṃ ca dūtyopasarpayet.
5.4.1
〔男が〕身振り（iṅgita）と様子（ākāra）を示したが、めったに会えない女、また初めて会う女には、仲介女（dūtī）を近づけるべきである。
5.4.2
saināṃ śīlato 'nupraviśyākhyāna-kapaṭaiḥ subhagaṃ-karaṇa-yogair loka-vṛttāntaiḥ kavi-kathābhiḥ pāradārika-kathābhiś ca tasyāś ca rūpa-vijñāna-dākṣiṇya-śīlānupraśaṃsābhiś ca tāṃ rañjayet.
5.4.2
その仲介女は、彼女のもとに品行をもって入り込み、物語の絵布（ākhyāna-kapaṭa）、美容術（subhagaṃ-karaṇa-yoga）、世間話（loka-vṛttānta）、詩人の物語（kavi-kathā）、不倫の物語（pāradārika-kathā）、そしてその女の容姿・知識・親切さ・品性の称賛によって、彼女を喜ばせるべきである。
5.4.3
katham evaṃ-vidhāyās tavāyam itthaṃ-bhūtaḥ patir iti cānuśayaṃ grāhayet.
5.4.3
「このようなあなたに、なぜこのような夫が」と、後悔（anuśaya）を抱かせるべきである。
5.4.4
na tava subhage dāsyam api kartuṃ yukta iti brūyāt.
5.4.4
「美しい方よ（subhage）、あなたに奴隷の仕事すらさせるのはふさわしくない」と言うべきである。
5.4.5
manda-vegatām īrṣyālutāṃ śaṭhatām a:kṛta-jñatāṃ cāsaṃbhoga-śīlatāṃ kadaryatāṃ capalatām anyāni ca yāni tasmin guptāny asyā abhyāśe sati sad-bhāve 'tiśayena bhāṣeta.
5.4.5
〔夫の〕緩慢さ（manda-vegatā）、嫉妬深さ（īrṣyālutā）、狡猾さ（śaṭhatā）、恩知らず（a:kṛta-jñatā）、享楽を知らぬこと（a:saṃbhoga-śīlatā）、吝嗇（kadaryatā）、浮気性（capalatā）、その他の秘めた欠点を、彼女の近くで信頼関係が生じたとき、ことさらに語るべきである。
5.4.6
yena ca doṣeṇodvignāṃ lakṣayet tenaivānupraviśet.
5.4.6
どの欠点に彼女が悩んでいるかを見抜き、まさにその欠点から付け入るべきである。
5.4.7–8
yadāsau mṛgī tadā naiva śaśatā-doṣaḥ. etenaiva baḍava-hastinī-viṣayaś coktaḥ.
5.4.7–8
もし彼女がmṛgī（鹿型）であれば、〔夫の〕śaśa（兎型＝小さすぎる）は欠点ではない〔逆にvṛṣa（牛型＝大きすぎる）やaśva（馬型）が欠点となる〕。同様にbaḍavā（牝馬型）やhastinī（象型）についても言われる。
5.4.9
nāyikāyā eva tu viśvāsyatām upalabhya dūtītvenopasarpayet prathama-sāhasāyāṃ sūkṣma-bhāvāyāṃ ceti goṇikāputraḥ.
5.4.9
ゴーニカープトラ曰く：女主人公（nāyikā）の信頼を得た上で、仲介女として近づくべきである。特に、初めて操を破ろうとする女（prathama-sāhasa）、また意志が微妙な女（sūkṣma-bhāva）の場合に。

仲介女による説得の技法（5.4.10–5.4.15）

5.4.10
sā nāyakasya caritam anulomatāṃ kāmitāni ca kathayet.
5.4.10
仲介女は男主人公（nāyaka）の素行（carita）、柔和さ（anulomatā）、そして愛の願望（kāmita）を語るべきである。
5.4.11
prasṛta-sadbhāvāyāṃ ca yuktyā kārya-śarīram itthaṃ vadet.
5.4.11
〔女の〕好意（sadbhāva）が広がったとき、巧みに事の本体（kārya-śarīra）を次のように述べるべきである。
5.4.12
śṛṇu vicitram idaṃ subhage tvāṃ kila dṛṣṭvāmutrāsāv itthaṃ gotra-putro nāyakaś cittonmādam anubhavati. prakṛtyā su:kumāraḥ kadā cid anyatrāparikliṣṭa-pūrvas tapasvī. tato 'dhunā śakyam anena maraṇam apy anubhavitum iti varṇayet.
5.4.12
「美しい方よ、不思議なことを聞いて。あなたを見て、あの某家の男主人公は心の狂乱（cittonmāda）を味わっている。生来繊細な方で、かつて他の女に苦しんだこともない。あの方は今や死すら覚悟している」と描写すべきである。
5.4.13
tatra siddhā dvitīye 'hani vāci vaktre dṛṣṭyāṃ ca prasādam upalakṣya punar api kathāṃ pravartayet.
5.4.13
そこで〔女が〕受け入れた場合——翌日、言葉（vāc）・表情（vaktra）・眼差し（dṛṣṭi）に好意を見て取り、再び話を進めるべきである。
5.4.14
śṛṇvatyāṃ cāhalyāvimāraka-śākuntalādīny anyāny api laukikāni ca kathayet tad-yuktāni.
5.4.14
〔女が〕聞き入っているなら、アハリヤー・アヴィマーラカ・シャクンタラーなどの物語、また同様の世間の話を語るべきである。
5.4.15
vṛṣatāṃ catuḥṣaṣṭi-vijñatāṃ saubhāgyaṃ ca nāyakasya. ślāghanīyatāṃ cāsya pracchannaṃ saṃprayogaṃ bhūtam a:bhūta-pūrvaṃ vā varṇayet.
5.4.15
男主人公の男性力（vṛṣatā）、六十四の技芸（catuḥṣaṣṭi）に通じていること、幸運（saubhāgya）を語り、また他の女からの称讃と、秘密の情交——実際にあったものか、でっち上げたものか——を描写すべきである。

女主人公の反応の徴候（5.4.16–5.4.29）

5.4.16
ākāraṃ cāsya lakṣayet.
5.4.16
〔仲介女は〕彼女の態度（ākāra）を観察すべきである。
5.4.17
sa:vihasitaṃ dṛṣṭvā saṃbhāṣate.
5.4.17
〔彼女は仲介女を〕微笑みながら見て、語りかける。
5.4.18
āsane copanimantrayate.
5.4.18
席に招く。
5.4.19
kvāsitaṃ kva śayitaṃ kva bhuktaṃ kva ceṣṭitaṃ kiṃ vā kṛtam iti pṛcchati.
5.4.19
「どこにいたの、どこで寝たの、どこで食べたの、何をしていたの、何をしたの」と尋ねる。
5.4.20
vivikte darśayaty ātmānam.
5.4.20
人目のない所で自分を見せる。
5.4.21
ākhyānakāni niyuṅkte.
5.4.21
物語を所望する。
5.4.22
cintayantī niḥśvāsīti vijṛmbhate ca.
5.4.22
物思いにふけって溜め息をつき、あくびをする。
5.4.23
prīti-dāyaṃ ca dadāti.
5.4.23
愛情のしるしの贈り物（prīti-dāya）を与える。
5.4.24
iṣṭeṣūtsaveṣu ca smarati.
5.4.24
望みの祝祭のとき〔仲介女のことを〕思い出す。
5.4.25
punar-darśanānubandhaṃ visṛjati.
5.4.25
再会の約束をして見送る。
5.4.26
sādhu-vādinī satī kim idam a:śobhanam abhidhatsa iti kathām anubadhnāti.
5.4.26
「善いことを言う人なのに、なぜこんな恥ずかしいことを言おうとするの」と言いつつ、話を続けさせる。
5.4.27
nāyakasya śāṭhya-cāpalya-saṃbaddhān doṣān dadāti.
5.4.27
男主人公の狡猾さ（śāṭhya）や軽薄さ（cāpalya）にまつわる欠点を挙げる。
5.4.28
pūrva-pravṛttaṃ ca tat-saṃdarśanaṃ kathābhiyogaṃ ca svayam a:kathayantī tayocyamānam ākāṅkṣati.
5.4.28
〔男との〕以前の出会いや会話の出来事を自分からは語らず、仲介女が語るのを待ち望む。
5.4.29
nāyaka-manoratheṣu ca kathyamāneṣu sa:paribhavaṃ nāma hasati. na ca nirvadatīti.
5.4.29
男主人公の空想（manoratha）が語られると、侮蔑するかのように笑う。しかし拒絶はしない。

📝 Jayamaṅgalā 注釈メモ

  • 5.4.2: ākhyāna-kapaṭaは物語が描かれた絵布。subhagaṃ-karaṇa-yogaは後述される美容術。pāradārika-kathāはGautama妻（Ahalyā）がIndraに奪われた話などを指す
  • 5.4.5: Yaśodhara は各欠点を対型（pratiyogin）で理解する。例：mandavegatā（緩慢）が欠点なのはcaṇḍavegā（激しい性の女）の場合。asaṃbhoga-śīlatāは享楽に関心がないこと、kadaryatāは吝嗇
  • 5.4.7–8: 体格の不適合（yoni-vipratipatti）を夫の「欠点」として語る。mṛgī（鹿型の女）にはśaśa型（兎型の男）は欠点にならないが、vṛṣa型（牛型）やaśva型（馬型）が欠点となる
  • 5.4.12: Yaśodhara はcittonmādaを「高貴な女性たちに望まれながらもあなただけを思う」と解釈。gotra-putraは「どこの誰かの子ではなく、良家の子弟」であることを示す
  • 5.4.14: Ahalyāは仙人Gautamaの妻、IndraがGautamaに変身して近づいた話。Avimārakaは狩人に育てられた王子の恋物語。ŚākuntalāはDuṣyanta王との有名な恋愛譚

面識のある女・面識のない女への仲介（5.4.30–5.4.35）

5.4.30
dūty enāṃ darśitākārāṃ nāyakābhijñānair upabṛṃhayet.
5.4.30
仲介女は、〔すでに〕態度を示した女を、男主人公との過去の出来事の証拠（abhijñāna）によって確信させるべきである。
5.4.31
a:saṃstutāṃ tu guṇa-kathanair anurāga-kathābhiś cāvarjayet.
5.4.31
面識のない女（a:saṃstuta）には、〔男の〕美点の語りと恋の物語で引き寄せるべきである。
5.4.32
nāsaṃstutādṛṣṭākārayor dūtyam astīty auddālakiḥ.
5.4.32
ウッダーラキ曰く：面識がなく態度も見えない二人の間には、仲介の余地はない。
5.4.33
a:saṃstutayor api saṃsṛṣṭākārayor astīti bābhravīyāḥ.
5.4.33
バーブラヴィーヤ派曰く：面識がなくとも態度が交わされた二人の間には、仲介の余地がある。
5.4.34
saṃstutayor apy a:saṃsṛṣṭākārayor astīti goṇikāputraḥ.
5.4.34
ゴーニカープトラ曰く：面識はあるが態度が交わされていない二人の間にも、仲介の余地がある。
5.4.35
a:saṃstutayor a:dṛṣṭākārayor api dūtī-pratyayād iti vātsyāyanaḥ.
5.4.35
ヴァーツヤーヤナ曰く：面識もなく態度も見えない二人の間にも、仲介女の力量（dūtī-pratyaya）によって〔仲介は可能である〕。

贈り物と逢引の手配（5.4.36–5.4.44）

5.4.36
tāsāṃ mano-harāṇy upāyanāni tāmbūlam anulepanaṃ srajam aṅgulīyakaṃ vāso vā tena prahitaṃ darśayet.
5.4.36
〔面識のない女たちには〕心を奪う贈り物——嚙みもの（tāmbūla）、塗り香（anulepana）、花環（sraj）、指輪（aṅgulīyaka）、衣裳（vāsas）——を、男から贈られたものとして見せるべきである。
5.4.37
teṣu nāyakasya yathārthaṃ nakha-daśana-padāni tāni tāni ca cihnāni syuḥ.
5.4.37
それらには、男主人公の爪跡（nakha-pada）や歯痕（daśana-pada）など、ふさわしい印がつけられているべきである。
5.4.38
vāsasi ca kuṅkumāṅkam añjaliṃ nidadyāt.
5.4.38
衣裳にはサフラン（kuṅkuma）で印をつけた合掌の跡を残すべきである。
5.4.39
patra-cchedyāni nānābhiprāyākṛtīni darśayet. lekha-pattra-garbhāṇi karṇa-pattrāṇy āpīḍāṃś ca.
5.4.39
さまざまな意図を形にした葉の切り細工（patra-cchedya）を見せるべきである。手紙を包んだ耳飾りの葉（karṇa-pattra）や髪飾り（āpīḍa）も。
5.4.40
teṣu sva-manorathākhyāpanam. pratiprābhṛta-dāne caināṃ niyojayet.
5.4.40
それらに自分の願望を告知する〔内容を込める〕。返礼の贈り物を与えるよう彼女を促すべきである。
5.4.41
evaṃ kṛta-paraspara-parigrahayoś ca dūtī-pratyayaḥ samāgamaḥ.
5.4.41
こうして互いに受け入れ合った二人の逢引は、仲介女の信頼（dūtī-pratyaya）に基づく。
5.4.42
sa tu devatābhigamane yātrāyām udyāna-krīḍāyāṃ jalāvataraṇe vivāhe yajña-vyasanotsaveṣv agny-utpāte caura-vibhrame janapadasya cakrārohaṇe prekṣa-vyāpāreṣu teṣu teṣu ca kāryeṣv iti bābhravīyāḥ.
5.4.42
バーブラヴィーヤ派曰く：その逢引は、神殿参詣・巡礼・庭園遊び・水浴び・婚礼・祭祀の宴・火事・盗賊騒ぎ・輿に乗っての国土巡行・見世物の催し、その他の諸行事の折に行うべきである。
5.4.43
sakhī-bhikṣukī-kṣapaṇikā-tāpasī-bhavaneṣu sukhopāya iti goṇikāputraḥ.
5.4.43
ゴーニカープトラ曰く：女友達・托鉢尼・ジャイナ尼・苦行女の住まいが、容易な手段である。
5.4.44
tasyā eva tu gehe vidita-niṣkrama-praveśe cintitātyaya-pratīkāre praveśanam upapannaṃ niṣkramaṇam a:vijñāta-kālaṃ ca tan nityaṃ sukhopāyaṃ ceti vātsyāyanaḥ.
5.4.44
ヴァーツヤーヤナ曰く：彼女自身の家が最善である。出入りの道を知り、危難の対策を考え、適切に出入りし、時刻を知られず、常に容易な手段となる。

八種の仲介女（5.4.45–5.4.62）

5.4.45
nisṛṣṭārthā[1] parimitārthā[2] patra-hārī[3] svayaṃdūtī[4] mūḍha-dūtī[5] bhāryā-dūtī[6] mūka-dūtī[7] vāta-dūtī[8] ceti dūtī-viśeṣāḥ.
5.4.45
仲介女の種類は次の通りである：①全権委任の使者（nisṛṣṭārthā）、②限定委任の使者（parimitārthā）、③手紙の運び手（patra-hārī）、④自ら使者となる女（svayaṃdūtī）、⑤愚かな使者（mūḍha-dūtī）、⑥妻の使者（bhāryā-dūtī）、⑦無言の使者（mūka-dūtī）、⑧風の使者（vāta-dūtī）。
#名称（Sanskrit）意味適用状況
1nisṛṣṭārthā全権委任の使者面識があり会話もある二人の間（saṃstuta-saṃbhāṣaṇa）
2parimitārthā限定委任の使者互いに態度を見たがめったに会えない二人（dṛṣṭa-parasparākāra）
3patra-hārī手紙の運び手深い好意があり交わりのある二人（pragāḍha-sadbhāva）の場所と時間の連絡用
4svayaṃdūtī自ら使者となる女他の女の使者のふりをして自分が男に近づく
5mūḍha-dūtī愚かな使者（男の妻）男の妻を無知のまま利用して情報伝達する
6bhāryā-dūtī妻の使者（男の妻）男が自分の素朴な妻を使って女に近づかせる
7mūka-dūtī無言の使者幼い召使いが花輪や耳飾りに秘密の手紙を忍ばせて運ぶ
8vāta-dūtī風の使者前に取り決めた暗号で、他人に分からない世間話を通じて伝える
5.4.46–47
nāyakasya nāyikāyāś ca yathāmanīṣitam artham upalabhya sva-buddhyā kārya-saṃpādinī nisṛṣṭārthā. sā prāyeṇa saṃstuta-saṃbhāṣaṇayoḥ.
5.4.46–47
男女双方の意図を理解し、自分の知恵で事を成し遂げる者が全権委任の使者（nisṛṣṭārthā）である。彼女は主として面識があり会話もある二人の間で働く。
5.4.48–49
nāyikayā prayuktā a:saṃstuta-saṃbhāṣaṇayor api. kautukāc cānurūpau yuktāv imau parasparasyety a:saṃstutayor api.
5.4.48–49
女主人公に遣わされた場合は、面識も会話もない二人の間でも〔働く〕。また好奇心から「この二人は互いにふさわしい」と〔思い〕面識のない二人の間でも〔働く〕。
5.4.50–51
kāryaikadeśam abhiyogaikadeśaṃ copalabhya śeṣaṃ saṃpādayatīti parimitārthā. sā dṛṣṭa-parasparākārayoḥ pravirala-darśanayoḥ.
5.4.50–51
事の一端と口説きの一端を把握して残りを成し遂げる者が限定委任の使者（parimitārthā）である。彼女は互いに態度を見たがめったに会えない二人の間で働く。
5.4.52–53
saṃdeśa-mātraṃ prāpayatīti patra-hārī. sā pragāḍha-sadbhāvayoḥ saṃsṛṣṭayoś ca deśa-kāla-saṃbodhanārtham.
5.4.52–53
伝言のみを届ける者が手紙の運び手（patra-hārī）である。彼女は深い好意があり既に交わった二人の間で、場所と時間の連絡のために働く。
5.4.54
dautyena prahitānyayā svayam eva nāyakam abhigacched ajānatī nāma tena sahopabhogaṃ svāpne vā kathayet. gotra-skhalitaṃ bhāryāṃ cāsya nindet. tad-vyapadeśena svayam īrṣyāṃ darśayet. nakha-daśana-cihnitaṃ vā kiṃ cid dadyāt. bhavate 'ham ādau dātuṃ saṃkalpiteti cābhidadhīta. mama bhāryāyā kā ramaṇīyeti vivikte paryanuyuñjīta sā svayaṃ-dūtī.
5.4.54
他の女の使者として遣わされながら、自ら男主人公のもとへ行く者——知らないふりをして、男との交わりを夢に見たと語る。一族の名を言い間違えて男の妻を貶す。その口実で自ら嫉妬を見せる。爪跡・歯痕のついた何かを与える。「あなたに最初に差し上げようと決めていたの」と言う。「私とあなたの妻と、どちらが美しい？」と密かに問う——これが自ら使者となる女（svayaṃdūtī）である。
5.4.55–56
tasya vivikte darśanaṃ pratigrahaś ca. pratigraha-cchalenānyām abhisaṃdhāyāsyāḥ saṃdeśāśravaṇa-dvāreṇa nāyakaṃ sādhayet tāṃ copahanyāt sāpi svayaṃdūtī.
5.4.55–56
〔男は〕彼女に密かに会い、贈り物を受け取るべきである。また、〔別の女が〕贈り物を受け取る口実で他の女を名目とし、その女の伝言を聞く機会を通じて男を手に入れ、その女を害する——これもまた自ら使者となる女（svayaṃdūtī）である。
5.4.57
etayā nāyako 'py anya-dūtaś ca vyākhyātaḥ.
5.4.57
これにより、男主人公が自ら使者となる場合と、別の使者〔となる男〕も説明される。
5.4.58
nāyaka-bhāryāṃ mugdhāṃ viśvāsyāyantraṇayānupraviśya nāyakasya ceṣṭitāni pṛcchet. yogāñ śikṣayet. sākāraṃ maṇḍayet. kopam enāṃ grāhayet. evaṃ ca pratipadyasveti śrāvayet. svayaṃ cāsyāṃ nakha-daśanapadāni nirvartayet. tena dvāreṇa nāyākam ākārayet sā mūḍha-dūtī.
5.4.58
男主人公の素朴な妻（mugdhā）に信頼を得て、気ままに付き合い、男の行状を尋ねる。〔愛の〕術を教える。意味ありげに化粧させる。妻に〔夫への〕怒りを抱かせる。「こうしなさい」と聞かせる。自ら妻の身体に爪跡・歯痕をつける。その手段で男主人公を引き寄せる——これが愚かな使者（mūḍha-dūtī）である。
5.4.59
tasyās tayaiva pratyuttarāṇi yojayet.
5.4.59
〔男の〕返事も、その〔愚かな使者＝妻〕自身を通じて整えるべきである。
5.4.60
sva-bhāryāṃ vā mūḍhaṃ prayojya tayā saha viśvāsena yojayitvā tayaivākārayet. ātmanaś ca vaicakṣaṇyaṃ prakāśayet. sā bhāryā-dūtī tasyās tayaivākāra-grahaṇam.
5.4.60
あるいは、男は自分の素朴な妻を〔女のもとに〕遣わし、妻を通じて信頼を結ばせ、妻自身に態度を伝えさせる。また自分の技芸の巧みさ（vaicakṣaṇya）を示させる。これが妻の使者（bhāryā-dūtī）である。〔女の〕態度の把握もこの妻自身を通じて行う。
5.4.61
bālāṃ vā paricārikām a:doṣa-jñām a:duṣṭenopāyena prahiṇuyāt. tatra sraji karṇapattre vā gūḍha-lekha-nidhānaṃ nakha-daśana-padam vā sā mūka-dūtī. tasyās tayaiva pratyuttara-prārthanam.
5.4.61
あるいは、幼い召使い（bālā paricārikā）で事情を知らない者を、無害な口実で遣わすべきである。花環（sraj）や耳飾りの葉（karṇa-pattra）に秘密の手紙を忍ばせ、あるいは爪跡・歯痕をつける——これが無言の使者（mūka-dūtī）である。返答もこの者自身を通じて求める。
5.4.62
pūrva-prastutārtha-liṅga-saṃbaddham anya-janā:grahaṇīyaṃ laukikārthaṃ vyarthaṃ vā vacanam udāsīnā yā śrāvayet sā vāta-dūtī. tasyā api tayaiva pratyuttara-prārthanam iti tāsāṃ viśeṣāḥ.
5.4.62
前に取り決めた事柄の暗号（liṅga）に結びつき、他人には理解できない、世間的な意味あるいは無意味な言葉を、無関心を装って聞かせる者——これが風の使者（vāta-dūtī）である。返答もこの者自身を通じて求める。以上が〔仲介女の〕区別である。

📝 Jayamaṅgalā 注釈メモ — 八種の仲介女

  • nisṛṣṭārthā：「これをせよ」（idaṃ karaṇīyam）とだけ言われ、あとは自分の才覚で三重の仕事（①二人を恋に落とす ②互いに受け入れさせる ③結合させる）を遂行する
  • parimitārthā：事の一端（kāryaikadeśa）を把握し、残りを補って完成させる。nisṛṣṭārthāの下位型
  • patra-hārī：事が確定しているため伝言（saṃdeśa）のみを運ぶ。手紙（patra）か口頭（vacas）のいずれかで届ける
  • svayaṃdūtī：二種類ある。①他の女の使者のふりで自分が男に近づく ②贈り物の受け渡しを口実に、本命の女を出し抜く。Yaśodhara は「自分自身の目的で動くため、nisṛṣṭārthā の一種とみなすべし」と注する
  • mūḍha-dūtī：男の妻が使者であることを知らずに情報を運ぶ。patra-hārī の変型とYaśodhara は分類する
  • vāta-dūtī：Yaśodhara は mlecchitaka-vikalpa-kalā（暗号のすり替えの技芸）をここで参照すべきと述べる。Bābhravīya派は「人形、絵、動物、鸚鵡・九官鳥も秘密の仲介の役を果たす」と補足する

結頌（5.4.63–5.4.66）

5.4.63
vidhavekṣaṇikā dāsī bhikṣukī śilpa-kārikā /
praviśaty āsu viśvāsaṃ dūtī-kāryaṃ ca vindati //
寡婦、占い女、女奴隷、托鉢尼、女職人——これらは速やかに信頼に入り込み、仲介女の仕事を得る。
5.4.64
vidveṣaṃ grāhayet patyau ramaṇīyāni varṇayet /
citrān surata-saṃbhogān anyāsām api darśayet //
仲介女は夫への嫌悪を抱かせ、〔男の〕魅力を描写し、他の女たちの華やかな情交を見せるべきである。
5.4.65
nāyakasyānurāgaṃ ca punaś ca rati-kauśalam /
prārthanāṃ cādhika-strībhir avaṣṭambhaṃ ca varṇayet //
男主人公の愛情、また情交の巧みさ、多くの女たちからの懇願、そして〔男の〕決意を描写すべきである。
5.4.66
a:saṃkalpitam apy artham utsṛṣṭaṃ doṣa-kāraṇāt /
punar āvartayaty eva dūtī vacana-kauśalāt //
思いもよらぬ事柄であっても、欠陥ゆえに放棄されたものであっても、仲介女は言葉の巧みさ（vacana-kauśala）によって再び引き戻す。

📝 Jayamaṅgalā 注釈メモ — 結頌

  • 5.4.63: Yaśodhara は本章で述べた三種の基本的仲介女（nisṛṣṭārthā, parimitārthā, patra-hārī）の具体的な担い手として、vidhavā（寡婦）、ikṣaṇikā（占い女）、dāsī（奴隷女）、bhikṣukī（托鉢尼）、śilpa-kārikā（女職人）を挙げる
  • 5.4.64–65: 仲介女の業務の要約。①夫への不満を煽る ②男主人公の美点を述べる ③他の女の情交を見せる ④男の愛情・技巧・人気・決意を描く
  • 5.4.66: vacana-kauśala（弁舌の巧み）は第一篇で述べた使者の資質（paṭutā）の主たるものであるとYaśodhara は注する。弁舌に長けた仲介女はどんな状況も覆しうる
