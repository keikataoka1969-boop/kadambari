第二篇 sāṃprayogikam — 性愛の実践

第五章　噛み痕の法と地方の風習

Daśana-cchedya-vidhayaḥ / Deśyāś copacārāḥ
adhyāya 2.5｜sūtra 2.5.1–2.5.43｜prakaraṇa 11–12
噛み痕の部位と歯の性質 — daśana-sthāna / daśana-guṇa
2.5.1
uttarauṣṭham antar-mukhaṃ nayanam iti muktvā cumbanavad daśana-radana-sthānāni.
上唇（uttara-oṣṭha）、口の内部（antar-mukha）、および眼（nayana）を除けば、噛み痕の部位は接吻の部位と同じである。
注（Jayamaṅgalā）： 上唇は噛むと不快であり、口の内部（舌など）は歯が届かず、眼は噛めず・痛みが強く・容貌を損なう。残る部位は額・下唇・頸・頬・胸・乳房。ラータ地方の人々の部位（股の付け根・腕の付け根・臍の下）も同様に適用されるが、万人向けではない。
2.5.2
samāḥ snigdha-cchāyā rāga-grāhiṇo yukta-pramāṇā niś-chidrās tīkṣṇāgrā iti daśana-guṇāḥ.
歯の良い性質（daśana-guṇa）は、揃っている（sama）、滑らかな光沢がある（snigdha-cchāya）、色がよく映る（rāga-grāhin）、適度な大きさ（yukta-pramāṇa）、隙間がない（niś-chidra）、先が鋭い（tīkṣṇāgra）。
2.5.3
kuṇṭhā rājy-udgatāḥ paruṣāḥ viṣamāḥ ślakṣṇāḥ pṛthavo viralā iti ca doṣāḥ.
歯の欠点（doṣa）は、鈍い（kuṇṭha）、筋が浮き出ている（rājy-udgata）、粗い（paruṣa）、不揃い（viṣama）、滑らかすぎる（ślakṣṇa）、幅広い（pṛthu）、隙間がある（virala）。
八種の噛み痕 — daśana-cchedana-vikalpāḥ
2.5.4
[1] gūḍhakam [2] ucchūnakaṃ [3] bindur [4] bindu-mālā [5] pravāla-maṇir [6] maṇi-mālā [7] khaṇḍābhrakaṃ [8] varāha-carvitakam iti daśana-cchedana-vikalpāḥ.
噛み痕の種類は八つ。[1] グーダカ（gūḍhaka＝隠れた痕）、[2] ウッチューナカ（ucchūnaka＝腫れた痕）、[3] ビンドゥ（bindu＝点）、[4] ビンドゥ・マーラー（bindu-mālā＝点の連なり）、[5] プラヴァーラ・マニ（pravāla-maṇi＝珊瑚と宝石）、[6] マニ・マーラー（maṇi-mālā＝宝石の首飾り）、[7] カンダーブラカ（khaṇḍābhraka＝千切れ雲）、[8] ヴァラーハ・チャルヴィタカ（varāha-carvitaka＝猪の噛み跡）。
2.5.5
nātilohitena rāga-mātreṇa vibhāvanīyaṃ [1] gūḍhakam.
[1] グーダカ（gūḍhaka）：あまり赤くならず、わずかな赤み（rāga-mātra）だけで認識できる痕。傷にはならない。
2.5.6
tad eva pīḍanād [2] ucchūnakam.
[2] ウッチューナカ（ucchūnaka）：同じものを強く押すと腫れが生じる。
2.5.7
tad ubhayaṃ bindur adhara-madhya iti.
その両方（gūḍhaka と ucchūnaka）、および [3] ビンドゥ（bindu＝点）は、下唇の中央（adhara-madhya）に行う。
2.5.8
ucchūnakaṃ pravāla-maṇiś ca kapole.
ウッチューナカと [5] プラヴァーラ・マニ（pravāla-maṇi＝珊瑚と宝石）は、頬（kapola）に行う。
2.5.9
karṇapūra-cumbanaṃ nakha-daśana-cchedyam iti savya-kapola-maṇḍanāni.
耳飾りの接吻（karṇapūra-cumbana）、爪痕と噛み痕——これらが左の頬の飾り（savya-kapola-maṇḍana）である。
注（Jayamaṅgalā）： 耳飾り（karṇapūra）が左耳に飾られて左頬を美しくするように、接吻・噛み痕・爪痕もまた左頬の飾りとなる。引用句に「噛み痕と嚙檳榔を伴う接吻は、赤い飾り（rāga-maṇḍana）である」とある。
2.5.10
dantauṣṭha-saṃyogābhyāsa-niṣpādanatvāt [5] pravāla-maṇi-siddhiḥ.
[5] プラヴァーラ・マニ（pravāla-maṇi）は、歯と唇の組み合わせ（danta-oṣṭha-saṃyoga）の繰り返し（abhyāsa）によって作られる。
注（Jayamaṅgalā）： 上の歯と下唇、あるいは上唇と下の歯で、捉えて押す（gṛhītvā pīḍana）行為を繰り返すことにより、珊瑚の宝石のような赤い痕（lohita）が傷（kṣata）なしに生じる。
2.5.11
sarvasyeyaṃ [6] maṇi-mālāyāś ca.
この方法はすべてに（適用され）、[6] マニ・マーラー（maṇi-mālā＝宝石の首飾り）にも同様である。
2.5.12
alpa-deśāyāś ca tvaco daśana-dvaya-saṃdaṃśa-jā [3] bindu-siddhiḥ.
[3] ビンドゥ（bindu＝点）は、小さな部分の皮膚を二本の歯で挟んで（daśana-dvaya-saṃdaṃśa）作る。
2.5.13
sarvair [4] bindu-mālāyāś ca.
[4] ビンドゥ・マーラー（bindu-mālā＝点の連なり）は、すべての歯で行う。
2.5.14
tasmān mālā-dvayam api gala-kakṣa-vaṃkṣaṇa-pradeśeṣu.
したがって、二種の連なり（maṇi-mālā と bindu-mālā）は、頸（gala）、脇（kakṣa）、鼠蹊部（vaṃkṣaṇa）に行う。
2.5.15
lalāṭe corvor bindu-mālā.
額（lalāṭa）と太腿（ūru）にはビンドゥ・マーラー（点の連なり）を行う。
2.5.16
maṇḍalam iva viṣama-kūṭaka-yuktaṃ [7] khaṇḍābhrakaṃ stana-pṛṣṭha eva.
[7] カンダーブラカ（khaṇḍābhraka＝千切れ雲）：円形のような、不揃いの突起を伴った痕。乳房の側面（stana-pṛṣṭha）にのみ行う。
2.5.17
saṃhatāḥ pradīrghā bahvyo daśana-pada-rājayas tāmrāntarālā [8] varāha-carvitakam. stana-pṛṣṭha eva.
[8] ヴァラーハ・チャルヴィタカ（varāha-carvitaka＝猪の噛み跡）：密接して長く多数の歯痕の列が、銅色の間隔をおいて並ぶ。乳房の側面にのみ行う。
2.5.18
tad ubhayam api caṇḍa-vegayoḥ. iti daśana-cchedyāni.
その両方（khaṇḍābhraka と varāha-carvitaka）は激しい情熱の者（caṇḍa-vega）にのみ適する。以上が噛み痕である。
注（Jayamaṅgalā）： khaṇḍābhraka は頸を抱えて（kaṇṭha-upagrahaṇa）行う。不揃いの歯痕（viṣama-kūṭaka）が全体として円形になる。varāha-carvitaka は乳房の一方の端から少しずつ皮膚を噛んで（carvayati）、もう一方まで連続して4列か6列の歯痕を作り、その間が充血して銅色になる。猪が噛んだような跡。これらの噛み痕の行為者は女性（nāyikā）でもありうる。最初の六種は性交時（sāṃprayogika）のもの。

2.5.19
viśeṣake karṇapūre puṣpa-pīḍe tāmbūla-palāśe tamāla-pattre ceti prayojyāgāmiṣu nakha-daśana-cchedyādīny abhiyogikāni.
ティラカ飾り（viśeṣaka）、耳飾りの花（karṇapūra）、花冠（puṣpa-pīḍa）、嚙檳榔の葉（tāmbūla-palāśa）、タマーラの葉（tamāla-pattra）など——恋人のもとに届けるものに、爪痕・噛み痕を付ける。これが接近の痕（ābhiyogika）である。
注（Jayamaṅgalā）： これらは saṃkrāntaka（転移の行為、2.3.29参照）の一種。白樺の皮（bhūrja-pattra）で作ったティラカ飾り、青蓮花の耳飾り、花冠、美しく整えた嚙檳榔の葉、香りの良いタマーラの葉——これらは恋人のもとに届けられるもの（prayojyā-gāmin）であり、それらに爪痕・噛み痕を付けることで、心情（ākāra）を間接的に示す。
地方の風習 — deśyāḥ upacārāḥ（prakaraṇa 12）
2.5.20
deśa-sātmyāc ca yoṣita upacaret.
地方の慣習（deśa-sātmya）に応じて、女性を扱うべきである。
2.5.21
madhya-deśyā ārya-prāyāḥ śucy-upacārāś cumbana-nakha-danta-pada-dveṣiṇyaḥ.
中央地方（madhya-deśa）の女性は、高貴で（ārya-prāya）、清浄な振る舞い（śuci-upacāra）を好み、接吻・爪痕・噛み痕を嫌う。
2.5.22
bāhlīka-deśyā āvāntikāś ca.
バーフリーカ（Bāhlīka＝北西地方）とアーヴァンティカー（Āvāntikā＝ウッジャイニー地方）の女性も同様である。
2.5.23
citra-rateṣu tv āsām abhiniveśaḥ.
ただし、彼女たちは多彩な体位（citra-rata）に執着（abhiniveśa）する。
2.5.24
pariṣvaṅga-cumbana-nakha-danta-cūṣaṇa-pradhānāḥ kṣata-varjitāḥ prahaṇana-sādhyā mālavya ābhīryaś ca.
マーラヴィヤー（Mālavya＝マールワー地方）とアービーリヤー（Ābhīrya＝アービーラ地方）の女性は、抱擁・接吻・爪・歯・吸い付きを主とし、傷は好まず（kṣata-varjita）、打擲によって（性的に）満たされる。
2.5.25
sindhuṣaṣṭhānāṃ ca nadīnām antarālīyā aupariṣṭaka-sātmyāḥ.
五河地方（Pañcanada＝パンジャーブ）——インダス河を六番目とする諸河の間——の女性は、口によるもの（aupariṣṭaka）に慣れている。
2.5.26
caṇḍa-vegā manda-sītkṛtā āparāntikā lāṭyaś ca.
アーパラーンティカー（Āparāntikā＝西海岸地方）とラーティヤー（Lāṭya）の女性は、激しい情熱（caṇḍa-vega）で、嘆息は微か（manda-sītkṛta）である。
2.5.27
dṛḍha-prahaṇana-yoginyaḥ khara-vegā eva apadravya-pradhānāḥ strīrājye kośalāyāṃ ca.
ストリーラージヤ（Strīrājya＝女人国）とコーシャラー（Kośalā）の女性は、強い打擲を好み、常に激しく（khara-vega）、人工具（apadravya）を主として用いる。
2.5.28
prakṛtyā mṛdvyo rati-priyā a-śuci-rucayo nir-ācārāś ca āndhryaḥ.
アーンドラ（Āndhra）の女性は、生来柔らかく（mṛdvī）、情交を好み（rati-priya）、不浄を厭わず（a-śuci-ruci）、礼法に拘束されない（nir-ācāra）。
2.5.29
sakala-catuḥṣaṣṭi-prayoga-rāgiṇyo 'ślīla-paruṣa-vākya-priyāḥ śayane ca sa-rabhasopakramā mahārāṣṭrikāḥ.
マハーラーシュトリカー（Mahārāṣṭrikā）の女性は、完全な六十四芸（catuḥṣaṣṭi）の実践を楽しみ、卑猥で粗い言葉（aślīla-paruṣa-vākya）を好み、寝所では激しく主導する（sa-rabhasa-upakrama）。
2.5.30
tathā-vidhā eva rahasi prakāśante nāgarikāḥ.
ナーガリカー（Nāgarikā＝パータリプトラの都市女性）は同様であるが、密かに（rahasi）のみそれを表す。
2.5.31
mṛdyamānāś cābhiyogān mandaṃ mandaṃ prasiñcante draviḍyaḥ.
ドラヴィダ（Draviḍa）の女性は、揉みほぐされると（mṛdyamānā）、求愛の段階（abhiyoga）から少しずつ（mandaṃ mandaṃ）潤う。
2.5.32
madhyama-vegāḥ sarva-sahāḥ svāṅga-pracchādinyaḥ parāṅga-hāsinyaḥ kutsitāślīla-paruṣa-parihāriṇyo vānavāsikāḥ.
ヴァナヴァーシカー（Vānavāsikā）の女性は、中程度の情熱で、あらゆることを受け入れ（sarva-saha）、自分の身体を隠し、他人の身体を笑い、卑猥・粗暴な者を避ける。
2.5.33
mṛdu-bhāṣiṇyo 'nurāgavatyo mṛdvaṅgyaś ca gauḍyaḥ.
ガウディヤー（Gauḍya＝東方）の女性は、柔らかな言葉を話し（mṛdu-bhāṣin）、愛情深く（anurāgavatī）、身体が柔らかい（mṛdu-aṅgī）。

体質と地方の優先 — prakṛti-sātmya
2.5.34
deśa-sātmyāt prakṛti-sātmyaṃ balīya iti suvarṇanābhaḥ. na tatra deśyā upacārāḥ.
地方の慣習（deśa-sātmya）よりも個人の体質（prakṛti-sātmya）が強い（balīyas）、とスヴァルナナーバは言う。その場合、地方の慣習は適用されない。
2.5.35
kāla-yogāc ca deśād deśāntaram upacāra-veṣa-līlāś cānugacchanti tac ca vidyāt.
時の流れ（kāla-yoga）によって、風習・装い・遊びは一つの地方から別の地方へ伝わる。このことも知っておくべきである。
注（Jayamaṅgalā）： スヴァルナナーバの見解：deśa-sātmya（地方の慣習）と prakṛti-sātmya（個人の体質）が対立する場合、個人の体質が優先する。それはより内的（antaraṅga）であるから。先師たちは地方の慣習を優先する見解を持つが、教典の著者（ヴァーツヤーヤナ）もスヴァルナナーバの見解を否定していないので、それが採用される。また、旅人が別の地方に移動すると、その地方の風習・装い・振る舞いを持ち帰るため、地方の特徴は時代とともに混交する。しかし判断は旅行による表面的な変化ではなく、恒久の地方の慣習（sthāyi-deśa-pracāra）に基づくべきであり、体質（prakṛti-sātmya）によって扱うべきである。
2.5.36
upagūhanādiṣu ca rāga-vardhanaṃ pūrvaṃ pūrvaṃ vicitram uttaram uttaraṃ ca.
抱擁（upagūhana）から始まる一連の行為において、情欲の増進（rāga-vardhana）は、前の行為から後の行為へ、また後の行為から前の行為へと、より多彩になる。
注（Jayamaṅgalā）： 六つの外的行為の順序：抱擁（āliṅgana）→接吻（cumbana）→爪痕（nakha-cchedya）→噛み痕（daśana-cchedya）→打擲（prahaṇana）→嘆息（sītkṛta）。前から後へ（pūrvam pūrvam）の多彩さ：嘆息より打擲が身体的刺激として強く、それより噛み痕、それより爪痕、それより接吻（繊細な刺激として）、それより抱擁（全身的な刺激として）、というように各々がそれぞれの仕方で情欲を増す。逆方向（uttaram uttaram）の多彩さ：抱擁は粗い行為であり、接吻は巧妙、爪痕はさらに巧妙、噛み痕はさらに、打擲は軽さで、嘆息は教えがたい（durgraha）ほどに巧妙。
結頌 — saṃhāra-ślokāḥ
vāryamāṇaś ca puruṣo yat kuryāt tad anu kṣatam /
a-mṛṣyamāṇā dvi-guṇaṃ tad eva pratiyojayet // 2.5.37
制止されても男が行うこと——その痕を、
女は我慢ならずに、二倍にしてやり返す。
bindoḥ pratikriyā mālā mālāyāś cābhrakhaṇḍakam /
iti krodhād ivāviṣṭā kalahān pratiyojayet // 2.5.38
点（bindu）へのお返しは連なり（mālā）、連なりへのお返しは千切れ雲（abhrakhaṇḍa）。
こうして怒りに満ちたかのように、争いを仕掛ける。
注（Jayamaṅgalā）： 二倍の応酬の体系：bindu → bindu-mālā → khaṇḍābhraka → varāha-carvitaka / gūḍhaka → ucchūnaka → pravāla-maṇi → maṇi-mālā → bindu と循環する。最初の四つは皮膚表面、残りは皮膚を超える。krodhād iva（怒りのように）とは、作り事の怒り（kṛtaka-kopa）による演出。
sakacagraham unnamya mukhaṃ tasya tataḥ pibet /
nilīyeta daśec caiva tatra tatra maderitā // 2.5.39
髪を掴んで顔を仰向かせ、その口を飲む（唇を吸う）。
酒の酔いに促されて、身を寄せ、あちこちを噛む。
unnamya kaṇṭhe kāntasya saṃśritā vakṣasaḥ sthalīm /
maṇi-mālāṃ prayuñjīta yac cānyad api lakṣitam // 2.5.40
恋人の首を引き寄せ、胸の上にもたれかかり、
宝石の首飾り（maṇi-mālā）をつけるべし。その他の美しい痕も。
divāpi janasaṃbādhe nāyakena pradarśitam /
uddiśya sva-kṛtaṃ cihnaṃ hased anyair a-lakṣitā // 2.5.41
昼間、人混みの中で、男が（夜の痕を）示したら、
自分が付けた印を指して、他の人に気づかれぬよう笑う。
vikūṇayantīva mukhaṃ kutsayantīva nāyakam /
sva-gātra-sthāni cihnāni sāsūyeva pradarśayet // 2.5.42
顔をしかめるふりをし、男を咎めるふりをして、
嫉妬するかのように、自分の身体の印を見せる。
parasparānukūlyena tad evaṃ lajjamānayoḥ /
saṃvatsara-śatenāpi prītir na parihīyate // 2.5.43
互いに思いやりながら、このように恥じらう二人の間では、
百年（saṃvatsara-śata）が経っても、愛は衰えない。
注（Jayamaṅgalā）： saṃvatsara-śata（百年）とは人の寿命の尺度。愛は衰えない（prītir na parihīyate）とは、安定する（sthirī-bhavati）の意。食事も一つの味だけを食べ続ければ飽きが来る（virāga）。多様性（vaicitrya）こそが愛を保つ。
iti śrīvātsyāyanīye kāmasūtre sāṃprayogike dvitīye 'dhikaraṇe
daśana-cchedya-vidhayo deśyāś copacārāḥ pañcamo 'dhyāyaḥ.
