第五篇 第六章 後宮の振る舞いと妻の守護

Pañcamam Adhikaraṇam — Ṣaṣṭho 'dhyāyaḥ ｜ 第48節 Antaḥpurikā-vṛtta（後宮の振る舞い）＋ 第49節 Sva-dāra-rakṣā（自らの妻の守護）
Kāmasūtra 5.6.1–5.6.48

【第48節】後宮女性の欲求不満と代替手段（5.6.1–5.6.5）

5.6.1
nāntaḥ:purāṇāṃ rakṣaṇa-yogāt puruṣa-saṃdarśanaṃ vidyate patyuś caikatvād an:eka-sādhāraṇatvāc cā:tṛptiḥ. tasmāt tāni prayogata eva paras-paraṃ rañjayeyuḥ.
5.6.1
後宮の女性たちには、厳重な守護のため、男性と会う機会がない。夫は一人であるにもかかわらず多くの女性に共有されるため、満足（tṛpti）が得られない。それゆえ、彼女たちは種々の手段（prayoga）によって互いに楽しませ合うべきである。
5.6.2
dhātreyikāṃ sakhīṃ dāsīṃ vā puruṣavad alaṃkṛtyākṛti-saṃyuktaiḥ kanda-mūla-phalāvayavair apadravyair vātmābhiprāyaṃ nivartayeyuḥ.
5.6.2
乳姉妹（dhātreyikā）、友人（sakhī）、あるいは召使い女（dāsī）を男のように装わせ、形の合った根茎（kanda）・根（mūla）・果実（phala）の部分、あるいは人工器具（apadravya）によって、自らの欲望を満たすべきである。
5.6.3
puruṣa-pratimā a:vyakta-liṅgāś cādhiśayīran.
5.6.3
男性に似て性徴が明確でない者〔＝まだ髭のない若者〕とも寝るべきである。
5.6.4
rājānaś ca kṛpā-śīlā vināpi bhāva-yogād āyojitāpadravyā yāvad artham ekayā rātryā bahvībhir api gacchanti. yasyāṃ tu prītir vāsaka ṛtur vā tatrābhiprāyataḥ pravartanta iti prācyopacārāḥ.
5.6.4
慈悲深い王たちは、愛情がなくとも人工器具（apadravya）を装着して、一晩に多くの女と満足するまで交わる。しかし愛情（prīti）のある女、順番（vāsaka）の女、あるいは受胎適期（ṛtu）の女には、心を込めて臨む。これが東方の習慣（prācyopacāra）である。
5.6.5
strī-yogeṇaiva puruṣāṇām apy a:labdha-vṛttīnāṃ viyoniṣu vijātiṣu strī-pratimāsu kevalopamardanāc cābhiprāya-nivṛttir vyākhyātā.
5.6.5
女性の方法と同様に、女性を得られない男性にとっても、異なる対象（viyoni）、異種の動物（vijāti）、女性の像（strī-pratimā）、あるいは単なる手での摩擦によって欲望の解消が説明される。

📝 Jayamaṅgalā 注釈メモ

  • 5.6.2: kandaはāluka（芋）やkadalī（芭蕉）、mūlaはtāla（椰子）やketakī（タコノキ）の根、phalaはalābu（瓢箪）やkaṇṭikā（棘果）の実を指す。切り削って整えてから使うべしとYaśodhara は注する
  • 5.6.3: avyakta-liṅgaは「まだ髭が生えていないため女性のように見える若者」を指す
  • 5.6.4: vāsakaは後宮における順番制（paripāṭī）に基づく夜の割り当て。ṛtuは月経後の受胎適期。東方（prācya）の習慣として、感情のない交わりにも王は人工器具を用いて義務を果たすとされる
  • 5.6.5: Yaśodhara はsiṃhākrānta（獅子の姿勢）による自慰法に言及し、夢の中の射精（svapnābhimāna）に対する贖罪（prāyaścitta）の規定との対比で、ここでも規定された行為であるから許されるとする

都市人が後宮に入る方法（5.6.6–5.6.27）

5.6.6
yoṣāveṣāṃś ca nāgarakān prāyeṇānta:purikāḥ paricārikābhiḥ saha praveśayanti.
5.6.6
後宮女性たちは通常、都市人（nāgaraka）を女性の姿に変装させ、召使い女とともに入り込ませる。
5.6.7–8
teṣām upāvartane dhātreyikāś cābhyantara-saṃsṛṣṭā āyatiṃ darśayantyaḥ prayateran. sukha-praveśitām apasāra-bhūmiṃ viśalatāṃ veśmanaḥ pramādaṃ rakṣiṇām a:nityatāṃ parijanasya varṇayeyuḥ.
5.6.7–8
彼ら〔都市人〕を引き入れるために、内部の事情に通じた乳姉妹たちが、将来の利益（āyati）を示して努力すべきである。入りやすいこと、退避場所（apasāra-bhūmi）、邸宅の広大さ、番人たちの不注意（pramāda）、随従の者の不在（a:nityatā）を語るべきである。
5.6.9
na cā:sad-bhūtenārthena praveśayituṃ janam āvartayeyur doṣāt.
5.6.9
しかし、真実でない事柄で人を誘い入れるべきではない。過失（doṣa）を招くからである。
5.6.10
nāgarakas tu su:prāpam apy antaḥ:puram apāya-bhūyiṣṭhatvān na praviśed iti vātsyāyanaḥ.
5.6.10
ヴァーツヤーヤナ曰く：都市人は、たとえ容易に入れる後宮であっても、危険（apāya）が多いゆえに入るべきではない。
5.6.11
sāpasāraṃ tu pramada-vanāvagāḍhaṃ vibhakta-dīrgha-kākṣyam alpa-pramatta-rakṣakaṃ proṣita-rājakaṃ kāraṇāni samīkṣya bahuṣa āhūyamāno 'rtha-buddhyā kakṣyā-praveśaṃ ca dṛṣṭvā tābhir eva vihitopāyaḥ praviśet.
5.6.11
しかし、退避路（apasāra）があり、遊園（pramada-vana）に囲まれて奥まり、区画（kakṣyā）が長く分かれ、番人が少なく不注意で、王が不在であるなどの条件を検討して——繰り返し呼ばれ、利益を見込み、区画への入り方を確認した上で——彼女たちの手配した手段によって入るべきである。
5.6.12–15
śakti-viṣaye ca prati:dinaṃ niṣkrāmet. bahiś ca rakṣibhir anyad eva kāraṇam apadiśya saṃsṛjeta. antaś:cāriṇyāṃ ca paricārikāyāṃ viditārthāyāṃ saktam ātmānaṃ rūpayet. tad-a:lābhāc ca śokam antaḥ:praveśinībhiś ca dūtī-kalpaṃ sakalam ācaret. rāja-pranidhīṃś ca budhyeta.
5.6.12–15
可能であれば毎日退出すべきである。外の番人とは別の口実で親しくなるべきである。内部を歩き回る事情を知った召使い女に対しては、〔その女に〕執着していると見せかけ、その女を得られぬ悲しみを示すべきである。後宮に出入りする女たちを通じて仲介女の術（dūtī-kalpa）のすべてを行うべきである。また王の密偵（rāja-pranidhi）を見破るべきである。
5.6.16–20
dūtyās tv a:saṃcāre yatra gṛhītākārāyāḥ prayojyāyā darśana-yogas tatrāvasthānam. tasminn api tu rakṣiṣu paricārikā-vyapadeśaḥ. cakṣur anubadhnantyām iṅgitākāra-nivedanam. yatra saṃpāto 'syās tatra citra-karmaṇas tad-yuktasya vyarthānāṃ gīta-vastukānāṃ krīḍanakānāṃ kṛta-cihnānām āpīnakānām aṅgulīyakasya ca nidhānam. praty:uttaraṃ tayā dattaṃ prapaśyet. tataḥ praveśane yateta.
5.6.16–20
仲介女が通えない場合——態度を示した対象の女（prayojyā）を見る機会のある場所に留まるべきである。そこでも番人がいれば、召使い女に用があるという口実を使う。彼女が視線を向けてくるとき、身振り（iṅgita）と態度（ākāra）で意思を伝える。彼女が通る場所に、彼女に関わる絵画（citra-karman）、意味ありげな歌の一節（gīta-vastuka）、印をつけた玩具（krīḍanaka）、髪飾り（āpīḍaka）、指輪（aṅgulīyaka）を置いておく。彼女からの返答を注視し、そこから入り込みに努めるべきである。
5.6.21–24
yatra cāsya niyataṃ gamanam iti vidyāt tatra prachannasya prāg evāvasthānam. rakṣi-puruṣa-rūpo vā tad-anujñāta-velāyāṃ praviśet. āstaraṇa-prāvaraṇa-veṣṭitasya vā praveśa-nirhārau. puṭā:puṭa-yogair vā naṣṭacchāyā-rūpaḥ.
5.6.21–24
彼女が必ず行く場所を知って、そこに先に隠れて待つべきである。あるいは、番人の姿に変装して、許可された時刻に入る。あるいは、敷布（āstaraṇa）や掛布（prāvaraṇa）にくるまれて出入りする。あるいは、蓋付きの箱（puṭā:puṭa）の術か、影も形も消す薬（naṣṭacchāyā-rūpa）で〔入る〕。
5.6.25
tatrāyaṃ prayogaḥ — nakula-hṛdayaṃ corakatumbī-phalāni sarpākṣīṇi cāntardhūmena pacet. tato 'ñjanena sama-bhāgena peṣayet. anenābhyakta-nayano naṣṭa-cchāyā-rūpaś carati.
5.6.25
そのための処方は次の通りである：マングースの心臓（nakula-hṛdaya）、盗人の瓢箪の実（corakatumbī-phala）、蛇の眼（sarpākṣi）を陰火（antardhūma）で煮て、目薬（añjana）と等量に砕く。これを目に塗ると、影も形もなく動ける。
5.6.26
rātri-kaumudīṣu ca dīpikā-saṃbādhe suraṅgayā vā.
5.6.26
月明かりの夜（rātri-kaumudī）には、灯りを持つ召使い女の群れに紛れて、あるいは地下道（suraṅga）を通って〔入る〕。
5.6.27
dravyāṇām api nirhāre pānakānāṃ praveśane /
āpānakotsavārthe 'pi ceṭikānāṃ ca saṃbhrame //
vyatyāse veśmanāṃ caiva rakṣiṇāṃ ca viparyaye /
udyāna-yātrā-gamane yātrātaś ca praveśane //
dīrgha-kālodayāṃ yātrāṃ proṣite cāpi rājani /
praveśanaṃ bhavet prāyo yūnāṃ niṣkramaṇaṃ tathā //
物資の搬出入、飲料の搬入、飲宴や祝祭の際、召使い女の忙殺、部屋の入れ替え、番人の交代、庭園への外出やその帰還、長期の遠征で王が不在のとき——そうした折に、若者たちの出入りが可能となる。
5.6.28
parasparasya kāryāṇi jñātvā cāntaḥpurālayāḥ /
eka-kāryās tataḥ kuryuḥ śeṣāṇām api bhedanam //
dūṣayitvā tato 'nyonyam eka-kāryārpaṇe sthiraḥ /
a:bhedyatāṃ gataḥ sadyo yatheṣṭaṃ phalam aśnute //
後宮の女たちは互いの秘密を知り、一つの目的に結束して、残りの者たちをも仲間に引き入れるべきである。互いに〔秘密の共犯で〕汚し合い、一つの目的のために堅く結びついた者たちは、裏切られることなく、望むままの果実を享受する。

各地方の後宮の慣行（5.6.29–5.6.38）

地方後宮への男性の入り方
Aparāntika（西方）王宮に出入りする女性たちが、見目よい男性を後宮に導入する。警護がさほど厳しくない（5.6.29）
Ābhīra（牧畜民）クシャトリヤの称号を持つ後宮番人たち自身が事を成す（5.6.30）
Vātsagulma召使い女が女装した都市人を自分たちと一緒に入り込ませる（5.6.31）
Vaidarbha（ヴィダルバ）王の息子たち自身が後宮で、母親を除く女性と自由に交わる（5.6.32）
Strairājaka（女王国）出入りを許された親族のみが後宮女性と交わる（5.6.33）
Gauḍa（ベンガル）バラモン、友人、従者、奴隷、召使いが交わる（5.6.34）
Saindhava（シンド）従者・労働者の後宮への出入りが禁じられず、同様の姿の者も同じ（5.6.35）
Haimavata（ヒマラヤ）金で番人を買収し、大胆な者が団結して入り込む（5.6.36）
Baṅga・Aṅga・Kaliṅga都市のバラモンが花の供え物を名目に後宮に入り、幕越しに語らい交わる（5.6.37）
Prācya（東方）九人十人の女が結束して一人の若者を隠匿する（5.6.38）

📝 Jayamaṅgalā 注釈メモ — 後宮の振る舞い

  • 5.6.9: Yaśodhara は偽りの口実で人を後宮に誘い入れることの二重の危険を説く：①真実の好意がないのに入った男への危害 ②仕掛けた女自身の入りやすさの確保不足
  • 5.6.11: kakṣyāは後宮の複数の区画（prakoṣṭhaka）。pramada-vana（遊園）に囲まれていれば出入りが隠蔽しやすい
  • 5.6.25: 隠身の術（naṣṭacchāyā-rūpa）の処方。Yaśodhara は「ある者は形のみ消して影は残し、この薬は両方を消す」と注する。この種の呪術的要素はKāmasūtra中でも異例
  • 5.6.28: ekakāryārpaṇa（目的の一致）による後宮女性の結束。互いの秘密（cāritrakhaṇḍana＝操の破綻）を知り合うことで裏切りが不可能になる（abhedyatā）とする
  • 5.6.32: jananī-varjam（母を除いて）——ヴィダルバ地方では王子が後宮の継母たちと交わることが認められていたとされる
  • 5.6.37: paṭāntaritaḥ ālāpaḥ（幕越しの会話）——バラモンが花を供えに入る口実で、幕（paṭa）を隔てて後宮女性と語らい、そこから交わりに至る。Baṅga はTiruhitā河の東、Aṅga はMahānadī河の東、Kaliṅga はGauḍa地域の南

【第49節】自らの妻の守護（Sva-dāra-rakṣā）（5.6.39–5.6.48）

5.6.39
ebhya eva ca kāraṇebhyaḥ sva-dārān rakṣet.
5.6.39
まさにこれらの理由から、自らの妻を守るべきである。
5.6.40
kāmopadhā-śuddhān rakṣiṇo 'ntaḥ:pure sthāpayed ity ācāryāḥ.
5.6.40
諸師（ācārya）曰く：欲望の試験（kāmopadhā）に合格した番人（rakṣin）を後宮に配置すべきである。
5.6.41
te hi bhayena cārthena cānyaṃ prayojayeyus tasmāt kāma-bhayārthopadhā-śuddhān iti goṇikāputraḥ.
5.6.41
ゴーニカープトラ曰く：彼ら〔欲望だけの試験に合格した番人〕は、恐怖（bhaya）や財物（artha）によって他の者を〔後宮に〕入れるかもしれない。それゆえ、欲望・恐怖・財物の三試験（kāma-bhaya-arthopadhā）に合格した者を〔配置すべきである〕。
5.6.42
a:droho dharmas tam api bhayāj jahyād ato dharma-bhayopadhā-śuddhān iti vātsyāyanaḥ.
5.6.42
ヴァーツヤーヤナ曰く：〔他者を〕害さないこと（a:droha）が法（dharma）であるが、恐怖からそれすら棄てるかもしれない。それゆえ、法と恐怖の試験（dharma-bhayopadhā）に合格した者を〔配置すべきである〕。
5.6.43
vākyābhidhāyinībhiś ca gūḍhākārābhiḥ pramādabhir ātma-dārān upadadhyāc chaucā:śauca-parijñānārtham iti bābhravīyāḥ.
5.6.43
バーブラヴィーヤ派曰く：〔他の男の〕言葉を伝える密かな態度の若い女たちによって、自分の妻を試して、貞潔（śauca）と不貞（a:śauca）を見定めるべきである。
5.6.44
duṣṭānāṃ yuvatiṣu siddhatvān nā:kasmād a:duṣṭa-dūṣaṇam ācared iti vātsyāyanaḥ.
5.6.44
ヴァーツヤーヤナ曰く：腐敗の原因（duṣṭa）が若い女たちに容易に成功するのであるから、理由もなく無垢な者を汚すこと（a:duṣṭa-dūṣaṇa）を行うべきではない。

女性の堕落の原因（5.6.45）

5.6.45
ati:goṣṭhī nir:aṅkuśatvaṃ bhartuḥ svairatā puruṣaiḥ sahā:niyantraṇatā pravāse 'vasthānaṃ videśe nivāsaḥ sva-vṛtty-upaghātaḥ svairiṇī-saṃsargaḥ patyur īrṣyālutā ceti strīṇāṃ vināśa-kāraṇāni.
5.6.45
女性の堕落の原因（vināśa-kāraṇa）は次の通りである：過度の社交（ati:goṣṭhī）、制約のなさ（nir:aṅkuśatva）、夫による放任（svairatā）、男性との無制限の交流、〔夫の〕旅行中の孤独、異国での生活、生計の破綻（sva-vṛtty-upaghāta）、放縦な女（svairiṇī）との交際、夫の嫉妬深さ（īrṣyālutā）。

📝 Jayamaṅgalā 注釈メモ

  • 5.6.40–42: 番人の資質をめぐる三段階の議論が展開される。諸師はkāmopadhā（欲望の試験）のみで十分とするが、Goṇikāputra は恐怖と財物の試験も加え、Vātsyāyanaは法（dharma）と恐怖の二重試験が最高とする。法に従う者は自ら他者を害さないが、恐怖に屈して法を捨てる可能性がある
  • 5.6.44: aduṣṭa-dūṣaṇa（無垢な者を汚すこと）への戒め。Yaśodhara は古い格言を引用する：「潔白な者を試すな。試して一度汚れた者には、もはや治療法がないかもしれない」（na śodhanam aduṣṭasya...kadā cid dhi praduṣṭasya nādhigamyeta bheṣajam）
  • 5.6.45: 九つの堕落原因のうち、sva-vṛtty-upaghāta（生計の破綻）は衣食の欠乏を指し、patyur īrṣyālutā（夫の嫉妬深さ）は逆説的に妻の堕落を招くとされる——嫉妬が妻に疑いをかけることで、実際に堕落を誘発する

結頌（5.6.46–5.6.48）

5.6.46
saṃdṛśya śāstrato yogān pāradārika-lakṣitān /
na yāti cchalanāṃ kaś cid sva-dārān prati śāstravit //
教典（śāstra）から他人の妻に関する手段を見て、学識ある者は自分の妻に対する欺きに陥ることがない。
5.6.47
pākṣikatvāt prayogāṇām apāyānāṃ ca darśanāt /
dharmārthayoś ca vailomyān nācaret pāradārikam //
手段の不確実さ（pākṣikatva）、危険（apāya）の存在、そして法（dharma）と利（artha）に背くゆえに、不倫を行うべきではない。
5.6.48
tad etad dāra-gupty-artham ārabdhaṃ śreyase nṛṇām /
prajānāṃ dūṣaṇāyaiva na vijñeyo 'sya saṃvidhiḥ //
これ〔第五篇〕はまさに妻の守護（dāra-gupti）のために、人々の福利（śreyas）のために説かれたのであり、人々を堕落させるための規定として理解されるべきではない。

📝 Jayamaṅgalā 注釈メモ — 結頌と第五篇の位置づけ

  • 5.6.46: 学識ある者（śāstravit）は他人の妻に対する手段を知ることで、自分の妻を守る方法を知る。攻撃の知識は防御のためにある
  • 5.6.47: pākṣikatva（不確実性）——不倫の手段は常に成功するわけではなく、結果は偏りがある。apāya（危険）はKoṭṭa王やJayasena王の殺害に例示される
  • 5.6.48: 第五篇全体（Pāradārikam＝他人の妻に関すること）の弁明。Vātsyāyanaは教典が人々の堕落を目的とするものではなく（na prajānāṃ dūṣaṇāya）、妻の守護と善のために書かれたとする。操を破った女は全ての法（dharma）の崩壊を招くと注釈は述べる
  • これにより第五篇（Pāradārika Adhikaraṇa）全6章・11節（prakaraṇa 39–49）が完結する
