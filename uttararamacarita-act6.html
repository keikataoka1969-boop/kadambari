Uttararāmacarita — Ṣaṣṭho 'ṅkaḥ

Act VI — Kumārapratyabhijñāna
第六幕 ── 王子認知
The Recognition of the Princes — Rāma, returning from the slaying of Śambūka, halts the battle between his nephew Candraketu and the young ascetic Lava. He meets Lava and Kuśa, and, observing their uncanny resemblance to himself and Sītā, is overwhelmed by emotion. The act closes with the arrival of Janaka, Vasiṣṭha, and Rāma's mothers.
王子認知の幕──シャンブーカ退治から戻ったラーマは、甥のチャンドラケートゥと若き苦行者ラヴァの戦いを止める。ラヴァとクシャに出会い、自身とシーターに驚くほど似た二人の姿に激しく心を揺さぶられる。幕末にジャナカ王、ヴァシシュタ仙、ラーマの母たちが到着する。
— miśra-viṣkambhakaḥ（混合序幕） —
(tataḥ praviśati vimānenojjvalaṃ vidyādharamithunam.)

Vidyādharaḥ—aho nu khalv anayor vikartanakutukumārayor akāṇḍa-kalaha-pracaṇḍayos tayodyotita-kṣatra-lakṣmīkayor aty-adbhutodhānta-devāsurāṇi vikrānta-caritāni. tathā hi priye paśya paśya.

【1】

jhaṇajjhaṇita-kaṅkaṇa-kvaṇita-kiṅkiṇīkaṃ dhanu-
rdhvanad-guru-guṇāṭanī-kṛta-karāla-kolāhalam /
vitatya kirataḥ śarān avirata-sphurac-cūḍayor
vinicitram abhivartate bhuvana-bhīmam āyodhanam //

（輝く飛行車に乗って、ヴィッディヤーダラの夫妻が登場する。）

ヴィッディヤーダラ——ああ実に、この太陽のごとき二人の王子が突然の争闘で猛り立ち、クシャトリヤの威光を輝かせつつ、神々やアスラさえも驚嘆するような武勇の技を見せている。愛しい者よ、見よ、見よ。

【1】

腕輪がじゃらじゃらと鳴り、鈴が響き、
弓弦の重い唸りが凄まじい喧噪をなし——
弓を引き絞り矢を放つ二人の冠飾りは絶え間なく揺れ、
世界を震撼させるような、目も覚めるばかりの戦闘が展開している。

【2】

vijṛmbhitaṃ ca divyasya maṅgalāya dvayor api /
stanayitnor ivāmandaṃ dundubhīndumāyitam //

【2】

二人の吉祥のために天上の軍鼓が鳴り響いた——
それは雷鳴のように力強い太鼓の音であった。

tat pravarttatām anayor pravīrayor anavaratam aviralalitvikacakanakamala-kamanīya-saṃhatir maratatruṇamaṇi-mukula-nikaramakara-ndasundaraḥ puṣpanipātaḥ.

Vidyādharī—tat kim iti punar akāṇḍa-visphurita-taḍic-chaṭā-kaḍāram ivāmbaraṃ jhaṭiti saṃvṛttam.

されば、この二人の勇者に絶え間なく降り注ぐがよい——咲き誇る金蓮のように美しく、瑞々しい宝石の蕾から滴る蜜のように麗しい花の雨が。

ヴィッディヤーダリー——あら、なぜ突然、空が不意に走る稲妻の閃光で赤褐色に変わったのかしら。

Vidyādharaḥ—tat kiṃ nu khalv adya

【3】

tvāṣṭryantra-bhrami-bhrānta-mārtaṇḍa-jyotir ujjvalaḥ /
puṭabhedo lalāṭastha-nīlalohita-cakṣuṣaḥ //

āṃ jñātam. jāta-kṣobheṇa candraketunā prayuktam āgneyam. yasyāyam agni-cchaṭā-saṃpātaḥ.

ヴィッディヤーダラ——今一体何が起こったのだ。

【3】

ヴィシュヴァカルマンの機械のように旋回する太陽の光で輝き、
額に置かれたシヴァの青赤の眼が開くかのようだ。

ああ、わかった。激昂したチャンドラケートゥが火の飛道具（āgneya）を放ったのだ。これはその炎の飛沫の落下である。

注: tvāṣṭrī（トゥヴァーシュトリー）はヴィシュヴァカルマン（Viśvakarman）の作った回転装置。puṭabheda は「眼を開く」こと——ルドラ（Rudra）の額の第三眼（lalāṭa-netra）が開くと世界を焼き尽くすという神話的イメージ。āgneya-astra は火神アグニを支配神とする神聖飛道具。
【4】

avadagdha-bburita-ketu-cāmarair
apayātam eva hi vimāna-maṇḍalaḥ /
dadhati dhvajāṃśuka-paṭāśleṣv imāḥ
kṣaṇa-kuṅkuma-cchuraṇa-vibhramaṃ śikhāḥ //

āścaryam. pravṛtta evāyam uccaṇḍa-vajra-khaṇḍāvasphoṭa-paṭur vasphuliṅga-guru-ttāla-tumula-lelihānojjvalaj-jvālā-saṃbhāra-bhairavaḥ bhagavān uṣbudhaḥ. pracaṇḍaś cāsya sarvataḥ saṃtāpaḥ. tat priyām aṅgenācchāya sudūram apasarāmi.

(tathā karoti.)
【4】

半ば焦げた旗と払子を持つ飛行車群が退いてゆく中、
旗と衣の裾にこの炎の舌がかかり、
一瞬のクンクマ色の輝きを帯びた戯れのように見える。

驚くべきことだ。猛烈な雷霆を砕くほどの轟音を立て、火花を激しく散らし、高く荒れ狂い舐め尽くす輝ける炎の集合が恐ろしき火神そのものだ。この火矢の熱は四方に猛烈だ。愛する妻を体で覆い、遠くへ退こう。

（そのようにする。）

Vidyādharī—diṣṭyā etena vimala-muktāphala-śītala-snigdha-masṛṇāṃsalena nātha-deha-sparśenānanda-manda-mukulita-ghūrṇamāna-locanāyā alpoditaevāntarito me saṃtāpaḥ.

Vidyādharaḥ—ayi kim atra mayā kṛtam. athavā.

【5】

na kiṃcid api kurvāṇaḥ saukhyair duḥkhāny apohati /
tat tasya kim api dravyaṃ yo hi yasya priyo janaḥ //

ヴィッディヤーダリー——ありがたいことに、清らかな真珠の玉のように冷たく、滑らかで柔らかな夫の体の触れ合いによって、歓びに瞳を細めつつ眩暈する私の苦悩は、ほんのわずかに浮かんだだけで鎮まりました。

ヴィッディヤーダラ——おや、私が何をしたというのだ。いや思えば——

【5】

何もしなくとも、幸福によって苦痛を除く——
誰であれ愛する者は、その人にとって言い知れぬ宝なのだ。

Vidyādharī—katham avirala-vilola-ghūrṇamāna-vidyullatā-vilāsa-māṇḍitair matta-mayūra-kaṇṭha-śyāmalair avastīryate nabhas-talaṃ jaladharaiḥ.

Vidyādharaḥ—hanta kumāra-lava-prayukta-vāruṇāstra-prabhāvaḥ khalv eṣaḥ. katham avirala-pravṛtta-vāri-dhārā-sahasra-saṃpātaḥ praśāntam eva pāvakāstram.

Vidyādharī—priyaṃ me priyaṃ me.

ヴィッディヤーダリー——あら、密集し揺れ動く稲妻の蔓で飾られ、発情した孔雀の首のように深い藍色の雲が、空一面を覆い尽くしているわ。

ヴィッディヤーダラ——おお、これは王子ラヴァが放った水の飛道具（vāruṇa）の威力だ。絶え間ない水流の何千もの滝のような落下で、火の飛道具は完全に消し止められた。

ヴィッディヤーダリー——嬉しいわ、嬉しいわ。

注: āgneya-astra（火の飛道具）はチャンドラケートゥが放ち、ラヴァはvāruṇa-astra（水の飛道具）で対抗する。チャンドラケートゥはさらにvāyavya-astra（風の飛道具）を放つ。これらは天上の武器（divyāstra）であり、マントラによって呼び出される。

Vidyādharaḥ—hanta hanta bhoḥ sarvam atimātraṃ doṣāya...sādhū candraketo sādhu. sthāne vāyavyam astram īritam. kutaḥ.

【6】

vidyākalpena marutā meghānāṃ bhūyasām api /
brahmaṇīva vivartanāṃ kāpi pravilayaḥ kṛtaḥ //

ヴィッディヤーダラ——おお、何事も過ぎたるは害となる……見事だ、チャンドラケートゥよ。風の飛道具（vāyavya）を放ったのは当然だ。なぜなら——

【6】

（真の）知識に等しい風によって、いかに多くの雲であっても、
ブラフマンにおける虚妄の現象のように、不思議な消滅がなされた。

注: 巧みな二重の意味（śleṣa）を持つ韻文。表面的にはvāyavya-astra（風の飛道具）が雲を吹き散らす描写だが、哲学的には「真知（vidyā）に等しい風が、ブラフマンにおける虚妄な現れ（vivartana）を消滅させる」というヴェーダーンタ哲学の概念を含む。Kale注によれば、これはアドヴァイタ（不二一元論）の教義——真知がmāyāによる虚妄を破壊する——を巧みに重ね合わせている。

Vidyādharī—nātha ka idānīm eṣa sa-saṃbhramot-kṣipta-kara-bhramitottarīyāvalo dūrata eva madhura-snigdha-vacana-pratiṣiddha-yuddha-vyāpāra etayoḥ kumārayor antare vimānavaram avatārayati.

Vidyādharaḥ—(dṛṣṭvā) aiṣa śambūka-vadhāt pratinivṛtto raghu-patiḥ.

【7】

śāntaṃ mahāpuruṣa-saṃgaditaṃ niśamya
tad-vairasāt samupasaṃhṛta-saṃprahāraḥ /
śānto lavaḥ praṇata eva ca candraketuh
kalyāṇam astu suta-saṃgamanena rājñaḥ //

tad itas tāvad ehi. (iti niṣkrāntau.)

miśra-viṣkambhakaḥ.

ヴィッディヤーダリー——夫よ、あの方は誰でしょう。慌てて手を挙げ上衣を振り回しながら、遠くから甘く優しい言葉で二人の王子の戦いを止め、その間に最上の飛行車を降ろしている方は。

ヴィッディヤーダラ——（見て）あれはシャンブーカ退治から戻ったラグ族の主（ラーマ）だ。

【7】

偉大なる人の穏やかな言葉を聞いて、
その威厳ゆえに戦闘を収めた——
ラヴァは静まり、チャンドラケートゥは恭しく拝した。
息子たちとの邂逅により、王に幸あれ。

さあ、こちらへ参ろう。（二人退場。）

混合序幕終わり。

注: ヴィッディヤーダラ（Vidyādhara）は超自然的存在であり、空中からの目撃者として序幕の語り手を務める。suta-saṃgamana（息子との出会い）という語は、ヴィッディヤーダラが二人の少年がラーマの実の息子であることを知っているため用いた。ラーマ自身はまだその事実を知らない。
— ṣaṣṭho 'ṅkaḥ（第六幕本編） —
(tataḥ praviśati rāmo lavaḥ praṇataś candraketunś ca.)

Rāmaḥ—(puṣpakād avataran.)

【8】

dinakarakula-candra candraketo
sarabhhasam ehi dṛḍhaṃ pariṣvajasva /
tuhina-kala-śītalais tavāṅgaiḥ
śamam upayātu mamāpi citta-dāhaḥ //

(utthāpya sasnehaṃ pariṣvajya.)

api nāma kuśalaṃ tava divyāstra-dhara-dehasya.

（ラーマ、ラヴァ〔拝礼の姿勢〕、チャンドラケートゥが登場する。）

ラーマ——（プシュパカ車から降りながら。）

【8】

太陽族の月よ、チャンドラケートゥよ、
急いでこちらへ来て、しっかりと抱きしめておくれ。
おまえの雪のように冷たい体で、
私の心の灼熱もまた鎮まるように。

（起こして、愛情を込めて抱擁する。）

神聖な飛道具を操る体は無事であったか。

注: dinakarakula-candra——「太陽族の月」という矛盾的修辞（virodha）。太陽族（sūryavaṃśa）の中にあって月のように清涼な存在、の意。citta-dāha（心の灼熱）はシーターとの別離の苦悩を指す。チャンドラケートゥの冷涼な体の抱擁でその苦痛が鎮まることを願う。

Candraketuh—kuśalam aty-adbhuta-kriyasya priyadarśanasya lavasya lābhābhyudayena. tad vijñāpayāmi mām iva viśeṣeṇa vā mattaḥ snigdhena cakṣuṣā paśyatv amuṃ mahāvīra-prakāṇḍaṃ tātaḥ.

チャンドラケートゥ——驚くべき武技の持ち主で、見るも麗しいラヴァを得たことにより、息災にございます。申し上げます——私と同様に、いえ私以上に親しいまなざしで、この大勇者の雄をお父様はご覧くださいませ。

Rāmaḥ—(lavaṃ nirūpya.) diṣṭyā atigambhīra-madhura-kalyāṇa-kṛtir ayaṃ vayasyo vatsasya.

【9】

trātuṃ lokān iva pariṇataḥ kāyavān ṛgvedaḥ
kṣātro dharmaḥ śrita iva tanuṃ brahmakośasya guptyai /
sāmarthyānām iva samudāyaḥ saṃcayo vā guṇānām
āvirbhūya sthita iva jagat-puṇya-nirmāṇi-rāśiḥ //

ラーマ——（ラヴァを見つめて。）喜ばしいことだ。極めて沈着にして甘美な、吉祥溢れる容姿のこの者は、わが子の友である。

【9】

世界を守るために肉体をまとったリグ・ヴェーダのようであり、
ブラフマンの宝庫を護るために体を得たクシャトリヤの法のようであり、
諸々の力の集合体のようであり、美徳の蓄積のようであり、
世界の功徳の堆積が顕現して立っているかのようだ。

Lavaḥ—(svagatam.) aho puṇyānubhāva-darśano 'yaṃ mahāpuruṣaḥ.

【10】

āśvāsa-sneha-bhaktīnām ekam ālambanaṃ mahat /
prakṛṣṭasyeva dharmasya prasādo mūrti-saṃcaraḥ //

ラヴァ——（独白。）ああ、功徳の力を目の当たりにさせるこの偉大なる方よ。

【10】

安心と親愛と帰依の、ただ一つの偉大なる拠り所——
あたかも崇高なる法（ダルマ）の恩寵が、
人の姿をとって歩いているかのようだ。

āścaryam.

【11】

virodho viśrāntaḥ prasarati raso nirvṛti-ghanas
tad auddhatyaṃ kāpi vrajati vinayaḥ prahlayati mām /
jhaṭity asmin dṛṣṭe kim api paravān asmi yadi vā
mahārghas tīrthānām iha mahatāṃ ko 'py atiśayaḥ //

驚くべきことだ。

【11】

敵意は消え、至福に満ちた味わいが広がり、
あの傲慢はどこかへ去り、謙虚さが私を包む。
この方を突然見た瞬間、何ゆえか私は従属の念に捕らわれた——
いや、聖地のように偉大なる人々には、何か計り知れない卓越さがあるのだ。

注: ラヴァは自分の敵意が自然に消えていくのを不思議に感じている。tīrthānām mahatāṃ atiśayaḥ——聖なる浄地（tīrtha）のように偉大な人物（mahant）には、理屈では説明できない超越的な力がある。Kale注によれば、この詩節は多くの評者が高く評価している（bahumaṇyante）。

Rāmaḥ—tat kim ayam ekapade eva me duḥkha-viśrāmaṃ dadāty upasnehayati ca kuto 'pi nimittād antarātmānam. athavā snehaś ca nimitta-savyapekṣaś ceti vipratiṣiddham etat.

【12】

vyatiṣajati padārthān āntaraḥ ko 'pi hetur
na khalu bahir upādhīn prītayaḥ saṃśrayante /
vikasati hi pataṅgasyodaye puṇḍarīkaṃ
dravati ca himaraśmau syandate candrakāntaḥ //

ラーマ——何ゆえこの子は一瞬にして私の苦しみに安らぎを与え、何か説明しがたい理由で内なる魂を慈しませるのだろうか。しかし「愛情」と「原因への依存」とは矛盾する概念ではないか。

【12】

何か内なる原因が事物を結びつける——
愛情は外的な条件に依存するものではない。
太陽が昇れば白蓮は開き、
月光が差せば月長石は溶け出す。

注: ラーマは我が子と知らずして湧く自然な愛情に困惑している。puṇḍarīka（白蓮）は太陽に反応して開花し、candrakānta（月長石）は月光で溶ける——外的な「理由」ではなく内在的親和性（āntara hetu）による不可思議な結びつきの譬え。サーンキヤ哲学のsatkāryavāda（因中有果論）が背景にある。ラーマの無意識の父性愛の暗示。

Lavaḥ—candraketo ka ete.

Candraketuh—priya-vayasya nanu tāta-pādāḥ.

Lavaḥ—mamāpi tarhi dharmatas tathaiva yataḥ priya-vayasya iti bhavatokam. kiṃ tu catvāraḥ khalu bhavatām evy-apadeśa-bhāginas tatrabhavanto rāmāyaṇa-kathā-puruṣāḥ. tad viśeṣaṃ brūhi.

Candraketuh—nanu jyeṣṭha-tāta-pādā ity avehi.

ラヴァ——チャンドラケートゥよ、あの方はどなただ。

チャンドラケートゥ——親友よ、あれは我がお父上だ。

ラヴァ——ならば、友情の法に基づき、私にとっても同様のお立場だ。ただし、「お父上」と呼ばれる方はラーマーヤナの物語に四人おられる。詳しく教えてくれ。

チャンドラケートゥ——すなわち、長兄たるお父上（ラーマ）とお知りなさい。

Lavaḥ—(sollāsam.) kathaṃ raghunātha eva. diṣṭyā su-prabhātam adya yad ayaṃ devo dṛṣṭaḥ. (sa-vinayautsyukyaṃ nirvarṇya.) tāta prācetasāntevāsī lavo 'bhivandate.

Rāmaḥ—āyuṣman ehi. (iti sasneham āliṅgya.) ayi vatsa kṛtaṃ kṛtam ativinayena. anekavāram apariślāthaṃ pariṣvajasva mām.

ラヴァ——（歓喜して。）なんと、ラグ族の主ご本人とは。今日はなんと幸先の良い日であることか、この王にお会いできたのだ。（恭しく好奇心を込めてラーマを見つめて。）お父上、プラーチェータサ（ヴァールミーキ）の弟子ラヴァが敬礼いたします。

ラーマ——長命の子よ、こちらへおいで。（愛情を込めて抱擁して。）おお、我が子よ、もう十分だ、その過度の遠慮は。何度でもしっかりと私を抱きしめておくれ。

【13】

pariṇata-kaṭhora-puṣkara-garbha-cchada-pīna-masṛṇa-sukumāraḥ /
nandayati candra-candana-niṣyanda-jaḍas tava sparśaḥ //

【13】

成熟した蓮の内側の花弁のように豊かで滑らかな柔らかさ、
月光や白檀の滴りのように冷やかな——
おまえの体の触れ合いは私を喜ばせる。

Lavaḥ—(svagatam.) īdṛśo māṃ praty amīṣām akāra-snehaḥ. mayā punar ebhya evābhidrugdham ajñena yad āyudha-parigrahaṃ yāvad adhyārūḍho duryogāḥ. (prakāśam.) mṛṣyantv idānīṃ lavasya bāliśatāṃ tāta-pādāḥ.

Rāmaḥ—kim aparādhaṃ vatsena.

Candraketuh—aśvānuyātrikebhyas taptata-prāviṣkaraṇam upaśrutya vīrāyitam anena.

Rāmaḥ—nanv ayam alaṃkāraḥ kṣatrasya.

ラヴァ——（独白。）このように私に対して理由もなき親愛を示してくださるとは。それなのに私は愚かにも、この同じ方に対して武器を取るほどの敵意をむき出しにしてしまった。（声に出して。）お父上、ラヴァの子どもじみた愚行をお許しください。

ラーマ——我が子にどんな過ちがあったというのだ。

チャンドラケートゥ——馬の随行者たちからお父上の武勇の宣言を聞いて、彼は勇者ぶりを発揮したのです。

ラーマ——むしろそれはクシャトリヤの誉れではないか。

【14】

na tejas tejasvi prasṛtam apareṣāṃ viṣahate
sa tasya svo bhāvaḥ prakṛti-niyatatvāt na kṛtakaḥ /
mayūkhaiś cāntaṃ tapati yadi devo dinakaraḥ
kim īpeyo dyāvā nikṛta iva tejāṃsi vamati //

【14】

威光ある者は他者の威光が優勢になるのを忍ばぬ——
それはその者の本来の性であり、天性として定まったもので作り物ではない。
もし太陽神が光線で絶え間なく照り輝くなら、
なぜ火水晶（sūryakānta）は侮辱されたかのように炎を噴くのか。

注: sūryakānta（火水晶）は太陽光に反応して発火する水晶。太陽の光が他を圧してもsūryakāntaが自ら発火するように、ラヴァの武勇は外部刺激に対する自発的反応であり、天性（prakṛti-niyata）であって作為（kṛtaka）ではない。ラーマは少年の戦闘行為を咎めるどころか、クシャトリヤの本質として讃える。

Candraketuh—amarṣo 'py asyaiva śobhate mahāvīryasya. paśyantu hi tāta-pādāḥ priya-vayasya-niyukta-jṛmbhakāstra-niṣkampa-stambhitāni sarvataḥ sainyāni.

Rāmaḥ—(vilokya.) vatsa lava saṃhiyatām astram. tvam api candraketo nirvyāpāra-vilakṣitāni sāntvaya balāni.

Lavaḥ—yathājñāpayati tātaḥ. (iti praṇidhānaṃ nāṭayati.)

Candraketuh—yathādiṣṭam. (iti niṣkrāntaḥ.)

Lavaḥ—tāta praśāntam astram.

チャンドラケートゥ——この大勇者には、憤怒さえも映えるのでございます。お父上、ご覧ください——親友が用いたジュリンバカ飛道具（jṛmbhaka-astra）で四方の軍勢は動けず硬直しております。

ラーマ——（見回して。）ラヴァよ、飛道具を引け。チャンドラケートゥ、おまえも行って、動けなくなり恥じている兵士たちを慰めよ。

ラヴァ——お父上の仰せのままに。（瞑想の姿を演じる。）

チャンドラケートゥ——ご命令のとおりに。（退場する。）

ラヴァ——お父上、飛道具は鎮まりました。

Rāmaḥ—vatsa sarahasya-prayoga-saṃhāraṇy astrāṇy āmnāyavanti.

【15】

brahmādyo brahma-hitāya taptvā
paraḥ-sahasrāḥ śaradhas tapāṃsi /
etāny apaśyan guravaḥ purāṇāḥ
svāny eva tejāṃsi tapomayāni //

athaitām astra-mantropaniṣadaṃ bhagavān kṛśāśvaḥ paraḥ-sahasra-saṃvatsarāntevāsine kauśikāya provāca. sa tu bhagavān mahyam ity eṣa guru-paramparā-kramaḥ. kumārasya kutaḥ saṃprādaya iti pṛcchāmi.

Lavaḥ—svataḥ-prakāśāny āvayor astrāṇi.

Rāmaḥ—(vicintya.) kiṃ na saṃbhāvyate. prakṛṣṭa-puṇya-paripākopādānaḥ ko 'pi mahimā syāt. dvivacanaṃ tu katham.

Lavaḥ—ātarāvāvāṃ yamau.

Rāmaḥ—sa tarhi dvitīyaḥ kaḥ.

ラーマ——我が子よ、発動と収束に秘密の真言を持つ飛道具は、伝承に基づくものだ。

【15】

ブラフマーを始めとする古の師たちは、
ブラフマンの利益のために千年を超える苦行を修め、
自らの苦行より生じた
己の光輝たるこれらの飛道具を見出した。

そしてこの飛道具の真言たる秘奥（upaniṣad）を、尊きクリシャーシュヴァ仙が千年以上の弟子であったカウシカ（ヴィシュヴァーミトラ）に伝え、カウシカ尊師は私に伝えた。これが師弟伝承の順序だ。王子の伝承はどこから来たのか。

ラヴァ——我々の飛道具は自ずから現れました（svataḥ-prakāśa）。

ラーマ——（沈思して。）あり得ぬことではない。優れた功徳の成熟を因とする、何か偉大な力であろう。しかし双数形（āvayoḥ「我々二人の」）とは何か。

ラヴァ——我々は兄弟で、双子です。

ラーマ——では、もう一人とは誰だ。

注: guru-paramparā-krama（師弟伝承の順序）——Kṛśāśva → Kauśika (Viśvāmitra) → Rāma。この伝承なしに飛道具が「自ずから現れた」（svataḥ-prakāśa）ことにラーマは驚く。ラーマの先祖であるマヌ以来の者さえ伝承なしには飛道具を得なかった（na hy asāṃpradāyikāni astrāṇi pūrveṣām api anuśruma）。dvivacana（双数形）はサンスクリット特有の文法形式で、ラヴァが「二人」と言ったことにラーマは鋭く反応する。
(nepathye.)

dāṇḍāyana dāṇḍāyana.

【16】

āyuṣmataḥ kila lavasya narendrasainyair
āyodhanaṃ nanu kim ātya sakhe tatheti /
adyāstam etu bhuvaneṣv adhirāja-śabdaḥ
kṣatrasya śastra-śikhinaḥ śamam adya yāntu //

（舞台裏より。）

ダーンダーヤナよ、ダーンダーヤナよ。

【16】

長命なるラヴァが王の軍勢と戦ったとは——
友よ、まことにそうなのか。
ならば今日限り、世に「帝王」の称号は絶えよ、
そしてクシャトリヤの武器の火も今日鎮まるがよい。

Rāmaḥ—

【17】

atha ko 'yam indra-maṇi-mecaka-cchavir
dhvanineva baddha-pulakaṃ karoti mām /
nava-nīla-nīradhara-dhīra-garjita-
kṣaṇa-baddha-kuḍmala-kadamba-ḍambaram //

ラーマ——

【17】

さて、サファイアのように深い青の光輝を持つ者は誰だ——
その声だけで私に鳥肌を立たせる。
まるで新しい紺碧の雲の重々しい雷鳴を聞いて、
一瞬にして蕾をつけるカダンバの木のように。

注: kadamba（カダンバの木）は雨季の最初の雷鳴で蕾をつけることで知られ、サンスクリット詩における常套的な自然描写。ラーマはクシャの声を聞いただけで全身に鳥肌が立つ——これもまた無意識の父子の絆の表れ。indra-maṇi-mecaka-cchavi——インドラニーラ（サファイア）のように深い藍色の肌、はラーマ自身の肌の色でもある。

Lavaḥ—ayam asau mama jyāyān āryaḥ kuśo nāma bharatāśramāt pratinivṛttaḥ.

Rāmaḥ—(sakautukam.) vatsa ita evāhayaitam āyuṣmantam.

Lavaḥ—evam. (iti parikrāmati.)

(tataḥ praviśati kuśaḥ.)

ラヴァ——あれは私の兄、クシャと申す者で、バラタの庵から戻ったところです。

ラーマ——（好奇心を込めて。）我が子よ、ここに長命の者を呼んでおくれ。

ラヴァ——はい。（歩き回る。）

（クシャが登場する。）

Kuśaḥ—(sākūta-harṣa-dhairyaṃ dhanur āsphālayan.)

【18】

dattendrābhaya-dakṣiṇair bhagavato vaivasvata-ādā mano-
hṛttānāṃ damanāya dīpita-nija-kṣatra-pratāpāgnibhiḥ /
ādityair yadi vigraho nṛpatibhir dhanyaṃ mamaitad tato
dīptestra-sphurad-ugra-dīdhiti-śikhā-nīrājita-jyaṃ dhanuḥ //

クシャ——（含みのある喜びと堂々たる態度で弓を鳴らしながら。）

【18】

インドラに恐れなき安全を施し、
尊きヴァイヴァスヴァタ・マヌ以来、傲慢者を調伏するために
己のクシャトリヤの武威の火を燃やし続けてきた太陽族の王たちと
もし闘いがあるならば、わが弓にとっては光栄——
その弦は燃え立つ飛道具の猛烈な炎の先端で照らされて輝く。

注: nīrājita-jya——弓弦がāratī（灯明の回し供養）のように飛道具の炎で照らされている。Kale注によればnīrājanaは通常、凱旋した王や出陣前の馬・象の前で灯火を回す儀式（Ragh. IV. 25参照）。クシャは弓そのものが聖なる供養を受けたかのように描写する。

(iti vikaṭaṃ parikrāmati.)

Rāmaḥ—ko 'py asmin kṣatriya-potake pauruṣātirekaḥ.

【19】

dṛṣṭi-tṛṇīkṛta-jagat-traya-sattva-sārā
dhīroddhata namayatīva gatir dharātrīm /
kaumārake 'pi girivad gurutāṃ dadhāno
vīro rasaḥ kim ayam ety uta darpa eva //

（猛々しく歩き回る。）

ラーマ——このクシャトリヤの若者には何か並外れた勇猛さがある。

【19】

その眼差しは三界の精力を草のごとく蔑み、
沈着にして傲然たる歩みは大地を撓ませるかのよう。
少年でありながら山のような重量感を備えている——
これは勇猛の味わい（vīra-rasa）が進み来るのか、それとも誇り（darpa）そのものか。

注: Kale注：この詩節はD-R（Daśarūpaka）およびS-D（Sāhitya-darpaṇa）にvilāsaの例として引用されている。tṛṇīkṛta——「草のように扱う」＝「蔑視する」。girivad gurutāṃ dadhānaḥ——山は生まれながらにして重いが、樹木は成長して初めて重くなる。クシャは少年でありながら生得的な重々しさを持つ。vīra-rasa（勇猛味）はインド美学のnava-rasa（九味）の一つ。

Lavaḥ—(upasṛtya.) jayatv āryaḥ.

Kuśaḥ—nanu āyuṣman kim idaṃ vārtā yuddha-yuddham iti.

Lavaḥ—yat kiṃcid etat. āryas tu dṛptaṃ bhāvam utsṛjya vinayena vartatām.

Kuśaḥ—kim artham.

Lavaḥ—yad atra devo raghu-patis tiṣṭhati. sa ca snihyāvayor tatkanthate ca yuṣmat-sannikarṣasya.

Kuśaḥ—(satarkam.) sa rāmāyaṇa-kathā-nāyako brahmakośasya gopāyitā.

Lavaḥ—atha kim.

Kuśaḥ—āśaṃsanīya-puṇya-darśanaḥ sa mahātmā. kiṃ tu katham asmābhir upagantavya iti na saṃpradhārayāmi.

Lavaḥ—yathaiva gurus tathopasadena.

Kuśaḥ—kathaṃ hi nāmaitatḥ.

Lavaḥ—atyudāttaḥ sujanaś candraketaur mileyaḥ priya-vayasyeti sakhyena mām upatiṣṭhate. tena tat-sambandhena dharmatāta evāyaṃ rājarṣiḥ.

Kuśaḥ—sampratya vacanīyo rājanye 'pi praśrayaḥ.

ラヴァ——（近づいて。）兄上に勝利あれ。

クシャ——長命の弟よ、戦闘があったという噂は何だ。

ラヴァ——些細なことです。それより兄上は誇り高い態度を改め、礼をもって振る舞ってください。

クシャ——なぜだ。

ラヴァ——ここにラグ族の主（ラーマ）がおられます。我々に慈しみを寄せ、兄上にお会いしたいと望んでおられます。

クシャ——（思案して。）あのラーマーヤナの物語の主人公、ブラフマンの宝の守護者か。

ラヴァ——そのとおり。

クシャ——その方のお姿を拝することは望むべき功徳だ。しかし我々がどのようにお近づきになるべきか、私には判断しかねる。

ラヴァ——師父に対するように、敬礼をもって。

クシャ——どうしてそうなるのだ。

ラヴァ——高貴にして善良なるチャンドラケートゥ、ウルミラーの子が、親友として私に親しんでくれている。その縁で、この王仙は法に基づく父（dharma-tāta）となるのだ。

クシャ——なるほど、クシャトリヤに対してでも謙虚にすることは非難されまい。

注: Kale注：クシャのこの言葉（saṃpraty avacanīyo rājanye 'pi praśrayaḥ）は彼の真の騎士道精神に適うものである。高潔なバラモンの前に身を低くするのは不名誉ではないが、真のクシャトリヤとして、別のクシャトリヤの前で屈するのは武力における優位を認めることになり本来ありえない。ここでは「法に基づく父」（dharma-tāta）という関係性により、謙虚さが正当化される。
(ubhau parikrāmataḥ.)

Lavaḥ—paśyatv enam āryo mahā-puruṣa-kārānubhāva-gambhīrya-saṃbhāvyamānāvividha-lokottara-sucaritātiśayam.

Kuśaḥ—(nirvarṇya.)

【20】

aho prāsādikaṃ rūpam anubhāvaś ca pāvanaḥ /
sthāne rāmāyaṇa-kavir devīṃ vācaṃ vyavīvṛdhat //

（二人とも歩みを進める。）

ラヴァ——兄上、この偉大なる方をご覧ください。大人物の行為の威力と深遠さから推し量られる、多様な世を超えた善行の卓越を。

クシャ——（じっと見つめて。）

【20】

ああ、なんと恵み深い容姿、なんと清浄な威厳であることか。
ラーマーヤナの詩人がサラスヴァティー女神の言葉を用いたのは当然のことだ。

(upasṛtya.) Kuśaḥ—tāta kuśaḥ prācetasāntevāsī abhivandate.

Rāmaḥ—ehi ehi cirāyuḥ.

（近づいて。）クシャ——お父上、プラーチェータサの弟子クシャが敬礼いたします。

ラーマ——おいで、おいで、長命の子よ。

【21】

tat-vatsasya kim api dravyaṃ
yo hi yasya priyo janaḥ /
utkanthate pariṣvaṅge
nīrada-snigdha-vigraham //

(pariṣvajya; svagatam.)

kiṃ nv ayaṃ vatso me syāt.

【22】

aṅgād aṅgāt sutaḥ sneha-
dehasāra iva sthitaḥ /
nijaḥ prāṇa iva sphūrtaḥ
kāyād bahir ivāparaḥ /
hṛdayasya dravato dhātoḥ
kṛto nirmāṇam ivāntaraḥ /
yad enaṃ pariṣvajataḥ
siñcatīva 'mṛtena mām //

【21】

この者は、水を湛えた雲のように麗しい体を持つ——
その者を、この父は父の愛情をもって抱きしめたいと切望する。

（抱擁して；独白。）

この少年は、もしや私の子ではあるまいか。

【22】

あたかも愛情ゆえに体の精髄が
肢体の一つ一つから流れ出たかのようであり、
あるいは自らの生命が目に見える形で
体の外に現れたかのようであり、
歓喜で溶けゆく心臓の元素から
造り出されたかのようだ——
なぜなら彼を抱擁するとき、
甘露の流れで私の体を注ぐようなのだから。

注: この詩節には四つのutprekṣā（空想的比喩）が含まれる。Kale注によれば、Śruti（聖典）の一節「aṅgād aṅgāt saṃbhavasi hṛdayād abhijāyase / ātmā vai putranāmāsi sa jīva śaradaḥ śatam（汝は肢体の一つ一つより生まれ、心臓より生じる。魂こそ『息子』と名づけられるもの。百秋を生きよ）」が背景にある。ラーマは無意識のうちに血縁を感じ取っている。

Lavaḥ—tāta sūryaḥ lalāṭa-tapa. tāta tat tat-priyātāṃ tāvac chālānāṃ chāye muhūrtam upaveśṭum.

Rāmaḥ—yathā vatso rocate.

(sarve parikramya yathocitam upaviśanti.)

ラヴァ——お父上、日差しが額に照りつけております。どうかしばらくサーラ樹の木陰でお休みください。

ラーマ——我が子の望むままに。

（一同、巡り歩いて身分に従い座る。）

Rāmaḥ—(svagatam.)

【23】

aho vinayasaṃyuktā api kuśalavayor
bhāvāḥ gati-sthāna-upaveśanādayaḥ /
sāmrājyam avihita-siddhāḥ
prakṛṣṭasyeva dharmasya sūcayanti //

ラーマ——（独白。）

【23】

ああ、謙虚さを備えながらも、クシャとラヴァの
歩き方、立ち方、座り方などの所作は、
作り物ではなく天性のものとして、
普遍的主権を予示している。

【24】

avihita-siddhāḥ lakṣmī-vilāsāḥ
kamanīyāṃ kāntim uddayanti /
maṇer iva ketayanti
padmasya madhucchidām iva //

【24】

天来の美の優雅さが、輝く光彩を発している——
清浄な宝石が光を放つように、
あるいは満開の蓮に蜜の滴が輝くように。

api cānayoḥ rāghava-kumāra-sādṛśyaṃ bhūyiṣṭham anurūpam upalakṣaye.

【25】

kaṭhora-suvaṃbura-vigraha
avandya-rāṃsayoḥ /
siṃha-saṃhanana-dṛṣṭi
dundubhi-dhīra-svana iva //

この二人の少年にラグ族の王子たちとのほぼ完全な類似を、私は認める。

【25】

体は成熟した鳩の首のように紺青で、肩は立派な牡牛のように整い、
眼差しは意気盛んな獅子のように不動で、
声は吉祥の場で打たれる太鼓のように深い。

注: Kale注：第24・25節はsamrāṭ（帝王）の身体的特徴を示す。これらの特徴——逞しい体格、獅子のごとき眼差し、太鼓のごとき声——はラグ族の王子の特質であり、ラーマはクシャとラヴァにそれを認める。

(nipuṇaṃ nirūpya.) aye na kevalam asmad-aṅga-saṃvādiny ākṛtiḥ.

【26】

api janaka-sutāyās tac ca tac cānurūpaṃ
sphuṭam iha śiśu-yugme naipuṇojyemāsti /
nanu punar iva tan me gocarībhūtam eko-
r abhinava-śatapatra-śrīmad āsyaṃ priyāyāḥ //

（注意深く観察して。）おお、彼らの姿は私の肢体に似ているだけではない。

【26】

ジャナカの娘の面影もまた——あれもこれもが——
明瞭にこの双子に見て取れる。
もう一度、あの愛しい者の
新しき蓮のように美しい顔が、私の眼前に現れたかのようだ。

【27】

muktāccha-danta-cchavi-sundareyaṃ
saivōṣṭha-mudrā sa ca karṇa-pāśaḥ /
netre punar yady api rakta-nīle
tathāpi saubhāgya-guṇaḥ sa eva //

【27】

真珠のように白い歯の輝きで美しいこの唇の印、
あの美しい耳の形も同じだ。
眼の色はたとえ赤と青で異なるとしても、
それでも佳麗の質は全く同じだ。

注: Kale注：シーターの眼はnīla（暗色）のみであったが、少年たちの眼はrakta-nīla（赤と青）——赤は武人の性質を示す。karṇa-pāśa は「美しい耳」の意。pāśa は keśa の後では「集合」を意味し、karṇa の後では「美しい」を意味する（ヘーマチャンドラのコーシャによる）。

Rāmaḥ—(vicintya.) tad etat prācevasādhyuṣitam araṇyaṃ yatra kila devī parityaktā. iyaṃ cānayoḥ ākṛtir vayo 'nubhāvaś ca. yad api svataḥ-prakāśāny astrāṇīti tatra vimṛśāmi. api khalu tac citra-darśana-prāsaṅgikam astrābhyanujñānam adbhutaṃ syāt. na hy asāṃpradāyikāny astrāṇi pūrveṣām apy anuśruma. ayaṃ ca saṃplavamānam ātmānaṃ sukha-duḥkhātiśayo hṛdayasya me visamabhayate. yamāv iti ca bhūyiṣṭham ātma-saṃvādaḥ. bhūyiṣṭhaṃ ca mayā dvidhā pratipanno devyā garbhiṇī-bhāve āsīt.

(sāśrum.)

ラーマ——（沈思して。）これはヴァールミーキの住む森であり、まさに王妃（シーター）が棄てられた場所だ。この二人の容姿、年齢、そして威厳。飛道具が自ずから現れたと言うが、ここでよく考えてみよう——もしやあの絵画を見た折に与えた飛道具の許可が効力を発したのではあるまいか。先祖たちでさえ伝承なくして飛道具を得たとは聞いたことがない。また、私の心に溢れんばかりの歓喜と悲哀が打ち寄せ、私自身を確信させる。「双子だ」という言葉も、私自身の経験とよく一致する。かつて王妃の身籠りが双子であると、私は多くの場合において感じていたのだ。

（涙ぐんで。）

kva tāvān ānando niratiśaya-vilambha-bahulaḥ

tadā kiṃcit kiṃcit kṛta-padam ahobhiḥ katipayais
